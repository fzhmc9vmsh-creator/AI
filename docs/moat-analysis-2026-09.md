## 1. モートの定義 — 13条件から逆算した5つの問い

条件1・8・9・11・12を、構造化の4要素(アクター/フロー/リスク所在/時間)で書き直すと、
モート判定は次の5問に還元される。

| # | 問い | 対応条件 | 不合格の兆候 |
|---|---|---|---|
| M1 | **誰が誰に依存しているか** | 11 | 顧客側でなく自社側が特定顧客に依存 |
| M2 | **顧客が離れるとき何を失うか** | 1・9 | 移行コストが1年分の支払額未満 |
| M3 | **値上げできるか** | 1・8 | 値上げ=解約。価格が競合との比較で決まる |
| M4 | **収益は使われるほど増えるか** | 12 | 売り切り・年次更新で上限がある |
| M5 | **モートを維持する原資は自前か** | 2 | 拡大に資本市場の継続アクセスが必須 |

**M1が最重要**である。モートとは「顧客が離れられない度合い」であって、
「大きな契約を持っている度合い」ではない。契約が大きくても依存の向きが逆なら、
それはモートではなく**エクスポージャー**である。

### 2-3. ORCL — モート C(前文書 A から格下げ)

ORCLのモートは2つに分かれる。**規模で判定する**というスキルの規律に従って、
「現在の規模」ではなく「これから成長する規模」で見る。

| | モートA: Oracle Database | モートB: OCI AIインフラ |
|---|---|---|
| 規模(FY2026) | ライセンス+サポート 約$33.4B | クラウド $34.0B(うちIaaS $18.1B) |
| 成長 | **新規ライセンス −2%($6.8B)**、サポートはほぼ横ばい | IaaS **+77%**、Q4は+93% |
| RPO $638Bへの寄与 | ほぼゼロ | **ほぼ全部** |
| M1 依存の向き | 顧客がOracleに依存。40年のスキーマ・PL/SQL資産 → **S** | **OracleがOpenAIに依存** → **D** |
| M2 移行コスト | 数年〜十年。事実上不可能 | OpenAIはMicrosoft/CoreWeave/AWS/Google/Broadcomにも発注済 → 低い |
| M3 価格決定力 | S(サポート料は毎年値上げ) | C(ベアメタル+RDMAの技術優位はあるが、AWS/Azureが追随可能) |
| M4 従量課金 | S(Multicloud Universal Credits で消費型化) | S |
| M5 原資 | 自前 | **資本市場依存** |

**技術優位の実体(公平に評価する)**: OCIはGPUをベアメタルで露出し、RDMAクラスタネットワーク
(コードネーム Acceleron、RoCE)で接続する。AWS/GCPがGPUをインスタンスタイプで抽象化するのに対し、
ハイパーバイザーのオーバーヘッドがない。Stargate(Abilene, テキサス)の計算基盤はOCI Zettascale10で、
4.5GW・約$3,000億規模。これは本物の技術差である。
マルチクラウド(Oracle Database@Azure/AWS/GCP)も**収益+1,529%**で、
「クラウドを移ってもOracle DBからは移れない」構造を作った点は評価に値する。

**しかし結論を変えるのはM1である。**

| 指標 | 値 | 出所 |
|---|---|---|
| RPO | $638B(+363%) | FY26 Q4決算 |
| **うちOpenAI** | **約半分。$300Bのコミット単独で約47%** | S&P Global Ratings推計 |
| 格付 | **BBB→BBB−**(7/9格下げ、投機的等級の1つ上) | S&P。**格下げ理由はOpenAI集中** |
| CDSスプレッド | 8/4に過去最高 | Bloomberg |
| FY2026 FCF | **−$23.7B**(営業CF $32.0B) | FY26 Q4決算 |
| 有利子負債 | $100B超、D/E 3〜4倍 | 同上 |
| 訴訟 | 投資家が「OpenAIの財務リスクを隠した」として提訴 | 報道 |

**判定**: ORCLの成長は100%モートBから来る。そのモートBのRPOの約半分が1社である。
**ORCLの「これから」を買うことは、OpenAIの支払い能力を買うことと同義である。**
これはモートではなくエクスポージャーであり、条件11をCとする。
条件7も「リスクの過大評価」ではなく「別種の実在リスク」なのでCとする。

スキルの「条件6と条件7は対で評価する(安い理由の構造が悪ければ条件6のSは無効)」を適用し、
**条件6のPEG 0.54(会社シナリオ)は無効**とする。
C以下が4条件(1・2・7・11)あるため、構造評価は **C**。最終判断は**監視**。

## 4. 2銘柄の選定

### 選定軸と評価

| 軸 | AMZN+ORCL | **AMZN+SOFI** | AMZN+NVDA |
|---|---|---|---|
| モートの絶対水準 | A + C | **A + B** | A + B |
| 失敗モードの独立性 | **×** 両方AI capex回収 | **○** AI capex vs 米消費者信用 | **×** 両方AI capex(かつ相互に食い合う) |
| 価格(条件6) | 0.77〜0.95 + 無効 | **0.77〜0.95 + 0.57** | 0.77〜0.95 + 0.45 |
| 判定 | 却下 | **採用** | 却下 |

**失敗モードの独立性が決め手である。** 70%を2銘柄に置く以上、2つが同じ事象で同時に
壊れてはならない。ORCLとNVDAはどちらもAMZNと同じ「AI capexの回収懐疑」で落ちる。
実際に2026年6〜8月に3銘柄とも同時に叩かれている。

### AMZNの価格の再計算(EPS品質フォレンジック)

Q2 2026のGAAP EPS $5.75・純利益$62.6B(前年比3倍超)には、
**Anthropic出資の再評価による非現金・非営業の税引前利益 $53.4B** が含まれる。
会社の調整後EPSは **$1.97**(コンセンサス$1.82)。

| 基準 | EPS | PER | 成長率 | PEG |
|---|---|---|---|---|
| GAAP(FY2026コンセンサス) | $13.10 | 20.0倍 | 約30% | 0.67 |
| **正規化**(Anthropic益を控除) | **$9.16** | **28.6倍** | 約30% | **0.95** |

## 6. 69%集中のドローダウン耐性

| シナリオ | 総資産 | 目標¥5,315,900までに必要なリターン |
|---|---|---|
| コア2銘柄 −20% | ¥4,104,444(−13.8%) | +29.5% |

| コア2銘柄 −40% | ¥3,445,724(−27.7%) | **+54.3%** |

2027年1月4日の目標に対し、コアが−30%になると必要リターンが+40.8%に跳ね上がり、
16か月では事実上到達不能になる。**これが2銘柄集中の対価である。**
モートAとBを選んだのは、この対価を払う以上「壊れにくい2つ」でなければ
割に合わないため。

### 証券担保ローンについて

余力があること自体は、現金クッションを不要にする正当な理由である。ただし
**69%集中とレバレッジの併用は、追証リスクが非線形に増える**。
借入を実行する場合に必要な情報:

- 掛目(担保評価率)と適用金利。2026年は日銀の利上げ観測で調達金利が上昇している
  (日本10年債は1996年8月以来の高水準)
- 追証発生の担保維持率と、コア−30%時のLTV

これらが分かれば、資本コスト(借入金利)と期待リターン(PEGから逆算した年率)を
突き合わせて、借入が正当化される上限額を計算できる。
