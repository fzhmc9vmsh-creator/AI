# SOFI バリュエーション前提の事前登録(2026-10-18、Opus)

intrinsic-valuation-credit.md §1 に従い、本源的価値を出す前に前提を固定する。

## 正直な記録
- 株価($14.55、2026-10-16終値)とコンセンサスは、1周目の調査(市場データ収集)の時点で既に見ている。
  見なかったことにはできないため、前提は「規則で決まる値」に限定し、株価に合わせて動かせる裁量の余地を減らす。
- 以降、前提を変えた場合は、変更前の値・理由・(すべて株価を見た後である)ことをこの表に追記する。

## 固定する前提(規則)
| 項目 | 規則 | 値(2周目のデータで埋める。埋めた後は固定) |
|---|---|---|
| 株主資本コスト r | CAPM: 米10年国債利回り(2026-10中旬) + 株式β × 株式リスクプレミアム。β は 5年月次の公表値(出典を記録)と、銀行・フィンテックの同業の中央値の平均。ERP は 4.5%(Damodaran の暗黙ERP の近年レンジ 4〜5% の中央) | 2周目のR7/R8後に記入 |
| 金利シナリオ | ベース=市場の織り込み(2年金利と政策金利の差)、低下・上昇の各 ±100bp を感応度 | 同上 |
| シナリオ確率 | 強気 25% / ベース 50% / 弱気 25%(対称。growth-and-capex-valuation §10-4)。変数は同じ幅だけ逆に動かす | 固定 |
| 年度の重み | 年度別理論株価は 近い年度から 40/30/20/10%(§10-2) | 固定 |
| 妥当 PER | 3経路の平均: (a) 同業の予想PER の参照クラス、(b) 翌年度から3年の EPS 成長率 × PEG(下限は 1/r)、(c) エンジンの価値が示す倍率 | 固定 |
| 金融の交差確認 | 価値 = TBVPS ×(ROTCE − g)÷(r − g)。ROTCE は必要資本ベース(超過資本は別建て) | 固定 |
| 二重計上の禁止 | 信用コストはEPS経路とシナリオ確率で1回、希薄化は株数で1回、資本集約度は必要資本(TBV)で1回。倍率では割り引かない | 固定 |
| 構造評価 → 出発 PEG | valuation-model §3-3 経路c の表(S 1.6〜2.0 / A 1.3〜1.6 / B 1.0〜1.3 / C 0.8〜1.0) | 固定 |
| 安全余裕率 α | scenario-strategy §6 の表(構造評価から) | 固定 |

## 変更履歴(第2版、2026-10-18)— 利用者の指摘「成長企業を見る尺度として構造評価が足りない」を受けて

株価(14.55 ドル)を見た後の変更であることを明記する。変更前の値は out/val.json(第1版)に残す。

| 変更 | 理由 | 変更前 → 変更後 |
|---|---|---|
| 構造評価 → 許容 PEG | 固定の対応表(B 1.0〜1.3)に従う。構造評価が C → B に変わったため(条件2 を成長段階の尺度で判定し直した。分析メモ A2) | PEG 0.90/0.85/0.80/0.80 → 1.15/1.10/1.05/1.00(年度で中央 → 下限) |
| シナリオ確率 | スキル第4.5版 §9: 固定値をやめ、節点ツリー(4 節点、振れ幅は対称、確率は「基準より良い側に振れる確率」を先行指標で補正、N1・N2 は N3 に条件付き)で出す | 25/50/25 → 強気 21.7%・ベース 48.3%・弱気 29.9%(強気 = 獲得効率と資本の転換がともに良い側) |
| エンジンの入力 | 資本で持てない分を LPB で組成し直す割合(spill_conv)と新しい収益線(extra_rev)を引数化。既定値は第1版と同じで、第1版の出力が変わらないことを確認 | — |
| 安全余裕率 α | 構造評価 B の表(20〜25%)の中央 | 30% → 22.5% |

## 変更履歴(第3版、2026-10-18)— 利用者の指摘(フェーズ・二層の構造・KPI の率・EPS の要因・フライホイール・金利の両面・業界比較・条件6)を受けて

## 変更履歴(第3版の追補、2026-10-18)— 妥当 PER の出し方をスキルどおりに直す

利用者の指摘「EPS 成長率は年 32〜40% なのだから PEG 1.0 でも理論株価はそんなに低くならない。経営陣とその裏付けを分析したはず」。

| 変更 | 理由 | 変更前 → 変更後 |
|---|---|---|
| 妥当 PER | 第1版から「3 経路(同業の PER 13.6 倍・PEG × g・エンジンの DCF 倍率)の平均」と登録していたが、スキル(valuation-model §3-3)は「機械的な平均はしない」と定め、同業の PER と DCF は PEG の導出と交差確認に使うもの。登録自体がスキルに反していた | 平均 → **許容 PEG × g だけ**(同業の PER・DCF・TBV×ROTCE は交差確認として並べる) |
| 成長率 g | スキル §3-4 は「当該年度から先の 3〜5 年 CAGR」。第1〜3版は翌年度から 3 年(減速後)を当てていた | 年度末 t: PER × EPS(t+1)、g は t+1 → t+4 → **年度 t: PER × EPS(t)、g は t → t+3**。2026 年はエンジン 31.1%・会社 34.9%・コンセンサス 30.1% |
| 採用経路 | 2028 年までは経営陣の計画(2025→2028 EPS CAGR 38〜42%、公約の達成と 2025 年の 3 回の引き上げで裏付け)とエンジンが一致(2028 年 1.10 対 1.12)。計画の先はエンジンの減速 | エンジン(変更なし。理由を明記) |
| 信用・資本 | 倍率で割り引かず、EPS 経路(損失率)・節点ツリー・B/S の伸びの上限・株数で数える(二重計上の禁止) | DCF 倍率(β 1.93)の平均への混入をやめる |
| 条件7 | 信用と資本の制約を同業と比べて数量化(growth-stage-evaluation §6-2)。株価が示す恒常の損失率 +2.3pt は同業の過去のピークを上回り、資本は下限まで 23 億ドルの余裕 | B → **A**。点数 3.25 → 3.33、許容 PEG 1.225 → **1.25**(2029 年 1.10)、α 21.25% → **20.8%** |
| 結果 | 上記を合わせた再計算 | エンジン 15.4 → **21.9**、期待値 15.3 → **21.4**、判断 監視 → **買い(分割)**。分割エントリー圏 14.3 超〜19.6 以下、即時 14.3 以下 |
