# SoFi(SOFI)決算・市場の数字の台帳(Q3 2026 の差し替え用)

対象: `reports/SOFI/work/deck/slides/*.js`(52 件)と `meta.js`(`ORDER` の順)。作成日 2026-10-28。Q3 2026 決算(2026-10-27)の数字で差し替えるための台帳。
## 読み方
- **現在の値**は JS に書かれた文字列のまま引用した。改行(`\n`)は空白に置き換えた。グラフの系列は配列の値をそのまま並べた。
- **種類**は指定の 13 区分のどれか。見出し(meta.js の `title`)に出る数字は、種類の前に「タイトル・」を付けた行で示した。見出しを直すときは本文の行と同時に直す。
- **時点**は文中の記述から推定した。読み取れないものは「不明」。「第3版」は 2026-10-19 版。「エンジン」は事業エンジン(calc/out/growth_v3.json)の予想。
- **除外**: 目次(agenda)の 5 枚(s03・s07・s15・s16・s30)は章とページ番号だけで、数字の出どころはない(lib.js の agenda が meta.js から生成)。等級(S/A/B/C)や判定語(作動・停滞など)は数字ではないので原則省いた。動かない事実(設立年・免許年・経歴の年)も省いた。
- **判定閾値**(up/down の条件、KPI 帯、検査の基準、撤退の条件)は種類「その他」の行として残した。Q3 の数字で判定し直すときに使う。
- **図の数値**: s09 のサンキー図は画像(`assets/sankey_q2_2026.png`)内にある。入力は `assets/data/f19_sankey_nodes.csv` と `assets/data/f19_sankey_links.csv`。本台帳では値を確認していない。
- 末尾に「表記ゆれ・不整合」と集計を付けた。
