## 0. 先に読む注意

1. SoFi の Q2'26 資本比率は、総自己資本比率 18.8% が複数の出所で一致している。CET1 18.7% と Tier1 レバレッジ 16.5% は、SEC の 8-K 抜粋を要約した結果から読み取った値で、表の列見出しが確認できていない(要検証)。総自己資本 18.8% と CET1 18.7% の差が 0.1pt しかなく、連結かバンク単体か、あるいは別の列(最低所要など)を拾った可能性がある。報告書で使う前に 8-K の原文を確認すること。
2. 検索で拾えた同業の 2026 年値は、Capital One(Q2'26)、Ally(Q2'26)、LendingClub(Q1'26 と Q2'26 の一部)、Nu(Q2'26 の損益と資産のみ)。LendingClub の Q2'26 の CET1 は取れていない。
3. 借り手の FICO・年収(B2)は、現行の値がほとんど取れなかった。取れた数字は古いか二次情報で、信頼度が低い(該当表に注記)。
4. SoFi の貸倒引当率・公正価値の損失前提(B3)は今回の検索では確認できなかった。依頼文に書かれた既知の値(年 4.8% 前後、生涯 7〜8%)をそのまま使うこと。

## C. 同業との比較で読める点(数字から言えることだけ)

- 総自己資本比率の水準: SoFi 18.8%(Q2'26)は、Capital One の CET1 13.7%、Ally の CET1 10.1%、LendingClub の CET1 17.0%(Q1'26)と比べて高い側にある。ただし比率の種類が違う(総自己資本と CET1)ため、同じ指標では並べられていない。SoFi の CET1 は要検証。
- SoFi の資本比率は、Q4'25 22.9% から Q1'26 21.3%、Q2'26 18.8% へと 2 四半期で約 4pt 低下している。経営陣の運用目標は low-to-mid teens で、現在値はまだ目標より上。目標に向けて下がる余地は 3〜5pt 程度あるが、これは経営陣の発言からの読みで、RWA の伸びが続けば下がる速度は速くなる。
- 還元性向の対比: Capital One は Q2'26 に純利益を超える還元(約 107%)を行い、CET1 を 13.7% まで下げている。LendingClub は Q1'26 に自社株買い $38M。SoFi は 2025 年に増資した側で、還元ではなく資本調達の側にいる。
- 個人ローンの純償却の水準: LendingClub は 2023 年通期 5.0%(Q3 が 5.1%)から Q2'26 の 3.2%(HFI)へ改善。Discover の個人ローンは 2023Q4 約 3.39% から 2024Q4 4.24%、2025Q1 4.21% と悪化方向だった。SoFi の個人ローン(報告 2.62%、all-in 約 3.7%)は、LendingClub の HFI 3.2% と近い水準。ただし定義(報告ベースか all-in か、HFI 全体か個人ローンのみか)が違うので、並べる際は定義を明記すること。
