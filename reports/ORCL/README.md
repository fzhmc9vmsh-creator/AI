## work/ の中身(再現用)
| フォルダ | 内容 |
|---|---|
| `report/` | 報告書の Markdown 原稿(part1〜4)、Word 変換スクリプト(md2docx.js)、校閲結果(audit.md) |

| `charts/` | 図表 PNG、作図スクリプト、図表データ CSV |
| `data/` | 収集データ(財務・コンセンサス・負債/リース・貸借対照表) |
