  - WebFetch は sec.gov、s23.q4cdn.com、investor.oracle.com が DNS 解決エラーで取得できなかった(各1回試行し、再試行なし)。

### 表A 備考

1. Q1 FY27 から Oracle は新区分(Cloud / Software / Hardware / Services)を採用。Software は US$5.5B(−3%)。旧区分との対応が未確認のため、旧区分の欄は NA とした。
2. Q1 FY27 の OCI は一次の引用値 US$7.4B(+121%)を採用。二次情報の一つは US$4.9B(+84%)を示すが、これは Q3 FY26 の OCI 値と一致しており、誤帰属の可能性がある。
3. Q1 FY27 SaaS は一次値 US$4.2B(+10%)を採用。二次情報の US$4.0B(+13%)は Q3 FY26 の SaaS 値と一致。
4. Q1 FY24 の総売上は公表値 12.5 だが、報道では 12.4 と 12.45 の記載もある(食い違い)。
5. Q1 FY24 の RPO(約65)と 12 か月計上比率(49%)は決算通話の記述に基づく [T3]。Q2 FY24 の RPO(65超)は要確認。
6. Q2 FY26 の RPO は一次値 +438% を採用。決算通話の記述は +433%。
7. Q4 FY26 の RPO は YoY 未取得。前期末 US$138B からの計算では約 +362%(計算値、未確認)。
8. Q1 FY27 の RPO の YoY は一次記述 "+US$209B" のみ。% は 209/455 の計算値。
9. Q1 FY27 の Non-GAAP 営業利益率 42.5% は 8.2/19.3 の計算値。
10. Q1 FY27 の Oracle Cloud Database(IaaS)は +35%、Multicloud DB は +531%(USD)。いずれも二次情報 [T3]。
