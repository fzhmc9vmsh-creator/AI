- N1 (株主資本): Oracle 帰属の株主資本。非支配持分(NCI)は別。NCI は 2025-05-31: 518、2025-08-31: 512、2025-11-30: 506、2026-02-28: 556、2026-05-31: 548 (計算: 総計 43,056 − 株主資本 42,508)、2026-08-31: 424。

- N3 (PP&E の定義差): 2026-05-31 の純額 99,957 は 10-K の数値。金融リース使用権資産 7.5 bn(2026) と 2.9 bn(2025) を含む。別の集計サイトの 129,647 は、純額に営業リース使用権資産 29,690 を加えた値とみられ、採用していない。
- N4 (四半期減価償却費): 出典は $0.1 bn 単位で丸められている。FY2026 年間 7.6 bn、FY2025 年間 3.9 bn (S5)。
- N5 (表B の計算値): 2025-05-31 の総額 59,554 と累計 16,032 は、S5 の内訳(計 59,554)と純額 43,522 からの算出。2026-05-31 の内訳は合計 122,651 と一致を確認。
- N6 (有形自己資本): 株主資本 − のれん − 無形資産。入力値は表 C の出典に従う。
- N7 (2026-08-31 の無形資産 3,027): S6 の決算表の列ラベルが乱れており、10-Q との日付照合は未実施。有形自己資本 1,478 はこの値に依存する。
- N8 (2025-11-30 のれん 62,207): 要約は「2025-05-31 と変わらず」と記載するが、2025-08-31 は 62,211。要確認。
- N9 (買掛金の候補): S7 (Q1 FY2026 決算表) に買掛金 8,203 と 5,113 が載るが、列の日付は特定できず採用していない。
- N10 (顧客前払い): 報道要約に「前払いおよび顧客提供の GPU コミットメント 750 億ドル」との記載あり。残高ではなくコミットメントであり、時点も不明。表には入れていない。

- N14 (表D の Azure): 報道要約に「Azure 33 リージョン」との記載があるが、Oracle Database@Azure か Azure 全体かが不明なため採用していない。
