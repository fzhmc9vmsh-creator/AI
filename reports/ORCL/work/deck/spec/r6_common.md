## 2. 関係図の基準(条件スライド・事業の関係・会社の筋書き)

## 3. 文字と改行
- フォントは部品が Meiryo UI に決める。8pt 未満を使わない。
- 箱の副題・注記の改行は "\n" で明示し、末行が 1〜2 文字にならないようにする(例: `税引後 約 230 億ドル/年` が「/年」で折れるなら `税引後\n約 230 億ドル/年`)。数字と単位を別の行に分けない。
- 文の中身(数値・固有名詞・評価)は指示書のとおり。字数が収まらないときは、意味を変えずに語を削る。削った箇所は報告に書く。
