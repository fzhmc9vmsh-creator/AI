## 1. 最重要の発見

1. **Q1 FY27 は費用・利益の全行が揃い、行和が一致する。** 費用合計 12,617、営業利益 6,728、支払利息 1,428、営業外 307、税引前 5,607、普通株主帰属純利益 約 4,680、希薄化後 EPS 1.56。出典は決算表・10-Q の検索要約(Tier 1、原本未開封)。法人税 847 だけが Tier 3 のみ。
2. **FY26 の費用は主要項目を取得できた。** 営業費合計 46,751(10-K 要約)の内訳は S&M 8,331 / R&D 10,272 / G&A 1,618 / 無形償却 1,671 / 再編 1,838(いずれも Tier 3 の年度費用表)。ただし Cloud and software・Hardware・Services 費用の年度値は取得できず、3 項目の合算 23,021 のみ算出できた。
3. **Q4 FY26 は利息・営業外・税が欠損。** 費用の内訳は決算表の検索要約で揃った(合計 13,051、営業利益 6,133)。利息は Q2 と Q4 の合計 2,496 しか算出できない。純利益は合計 4,304 と普通株主帰属 約 4,227(算出)で食い違う(§4-1)。
4. **出典間の食い違いが 4 件ある。** Q1 FY26 再編費用 415 対 402、FY25 再編費用 374 対 300、FY26 営業利益 20,606 対 20.78bn、Q4 FY25 純利益と Q1 FY26 税引前がともに 3,427。
5. **「合計」と「普通株主帰属」の差が毎期約 80〜100 ある。** Q1 FY27 は約 80(算出)、FY26 は 103(Tier 3 の表示)。非支配持分などが候補だが未確認。
6. **旧区分(cloud services & license support / cloud license & on-prem)の売上は取得不能。** 新区分(Cloud / Software / Hardware / Services)で統一した。費用の旧区分は FY25 のみ Tier 3 で取得(§2-2 注)。買収関連費用(Acquisition related and other)は全期間 NA。

## 4. 出典間の食い違い(要確認)

1. **Q4 FY26 の純利益。** 検索要約の合計 4,304(前年 3,427、+25.6%)と、決算発表の見出し「普通株主帰属 4.2bn、+23%」が食い違う。1.45 × 2,915 = 4,227 は後者と整合する。合計 4,304 と普通株主帰属 4,227 の差 77 は、Q1 FY27 の差 80 や FY26 の差 103 と同程度。4,304 の出典は特定できていない。
2. **Q1 FY26 の再編費用。** 415(Q1 FY27 10-Q の比較列、Tier 1 の要約)対 402(別の検索要約、出典 URL 未特定)。本表は 415 を採用した。理由は、税引前 3,427 と利息 923・営業外 73 から求めた営業利益 4,277 と整合するため(402 だと営業利益 4,290 になり、比較列の数値と合わない)。
3. **FY26 の営業利益。** 20,606(StockAnalysis、決算発表の 20.6bn と整合、本表で採用)対 20.78bn(TickerLeague)。20.78 は税引前の算術と合わないため不採用。
4. **FY25 の再編費用。** 374(年度費用表、Tier 3)対 300(tracenable の "Restructuring" 0.30bn)。後者は再編のみ、前者は "restructuring and other" の可能性がある。定義を統一できていない。
5. **Q4 FY25 の純利益 3,427 と Q1 FY26 の税引前 3,427 が一致。** 偶然の可能性はあるが、転記ミスの疑いもある。Q4 FY25 の値は Q4 FY26 の増減率(+23% / +25.6%)から大きくはずれていないが、原本未確認。
6. **Q1 FY27 の法人税 847。** Tier 3 の Beancount.io のみ。同じ記事の「その他、純額 1.12bn」は本表の営業外 307 と定義が違うとみられる。
7. **Q1 FY27 の無形償却 202(前年 420、Q4 FY26 は 431)。** 四半期で半減しており不自然。償却終了や区分変更の可能性がある。要確認。
8. **Q1 FY27 の S&M(−12%)と R&D(−4%)、売上 +30%。** 検索要約どおりだが、売上の伸びと費用の動きが逆向きで、要約の誤読の可能性もある。原本で確認が必要。
9. **Q1 FY27 の SBC 科目別内訳の列配置。** 行和が 1,127 / 1,124 と一致するため、大枠は正しい可能性が高い。ただし C&S の SBC は前年比で減少(156 → 134)しており、列の取り違えを否定できない。
10. **Q1 FY27 の普通株主帰属と合計の差(約 80)。** 算出値。Oracle の開示にある非支配持分などの項目とみられるが、未確認。FY26 の差 103 は Tier 3 の StockAnalysis が「優先配当」と表示しているが、Oracle に優先株の発行実績は未確認のため、その説明は採用していない。
11. **Q2 FY26 の営業外損益 2,668。** 検索要約で 1 件のみ(出典 URL 未特定、Tier 3)。Ampere 売却益 2.7bn(税引前)と符合するが、原本で未確認。本表では採用していない。

## 7. 補足

- 既存の H5 の年度 Software 値(FY25 24.724 など)は、FY26 の新区分との整合は未確認。
- FY26 の償却 1,671(本表)と、既存 H5 の計算値 1,694(D&A 9.294 − 減価償却 7.600)は 23 の差。定義差の可能性がある。
- FY26 の損益計算書の科目別費用は、10-K 原本で確認すれば Tier 1 に上げられる。優先順は (1) FY26 C&S・HW・Services 費用、(2) Q4 FY26 の利息・税、(3) Q1 FY27 の税。
