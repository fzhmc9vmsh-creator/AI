# サンプルB社 報告書

## 1. 事業の概要

サンプルB社は、仮想のネットワークセキュリティ企業である。事業の最小単位(原子単位)は「保護される
エンドポイント1台あたりの年間契約」であり、売上は「保護対象数 × 1台あたり単価 × 更新率」の
積として分解できる。1台あたり単価は製品の追加(クロスセル)によって上昇し、更新率は解約率の
低下によって改善する。

事業の経済性は次の式で捉える。

```
売上 = 保護対象数 × 単価 × 更新率
営業利益 = 売上 × (粗利率 − 販管費率)
```

### 1.1 増収の源泉と制約

増収の源泉は三つある。第一に新規顧客の獲得であり、これは営業人員の増加と市場の成長に依存する。
第二に既存顧客内でのアップセルであり、製品群が増えるほど効果が高まる。第三に価格改定であり、
競争環境により余地は限られる。

制約としては、次の三点が重要である。
- 営業人員の採用・育成速度(新人の戦力化に平均3四半期)
- 大型顧客での導入サイクルの長さ(6~18か月)
- 競合の無償バンドル攻勢

#### 自己強化ループ

製品が増える → 1社あたりの支出が増える → 統合の価値が高まる → 解約が減る → 開発投資の原資が
増える → 製品が増える、というループが働く。このループは、顧客の予算上限に達した時点で飽和する。
