### KPI 別記事項

- **RPO の定義**: 10-Q/10-K の「残存履行義務(RPO)」の総額。cRPO は開示されていない(表示は「12 か月以内に認識される割合」のみ)。cRPO は RPO × 割合の**派生値**。
- **NNARR 合計(FY26)**: 193.8 + 221.1 + 265.3 + 331 = 1,011.2【派生】。会社発表の「FY26 純新規ARR 1.01B」と整合(S14)。
- **NNARR 合計(FY25)**: 211.7 + 217.6 + 153.0 + 224.3 = 806.6【派生】。
- **ARR 整合チェック**: 前四半期末 ARR + 当四半期 NNARR ≈ 当四半期末 ARR(丸め範囲内)。FY27 Q2: 5,510 + 333 = 5,843 ≈ 5,840。
- **Flex の定義変更**: FY26 Q1 までは「総取引額(deal value)」、FY26 Q3 以降は「Flex 採用顧客の期末 ARR」。時系列の直接比較は不可。FY26 Q3・Q4 と FY27 Q2 の値は下限値(「超」表記)。
- **Next-Gen SIEM の定義変更**: FY25 Q2 は「LogScale Next-Gen SIEM・Identity・Cloud の合算 ARR(1,000 超)」、FY27 Q2 は「Next-Gen SIEM 単独の ARR(695 超)」。直接比較は不可。
- **CCP(2024年7月障害後の顧客コミットメントパッケージ)**: 個別の ARR・売上影響額は**欠損**。FY25 Q2 のガイダンスで「販売サイクル延長と CCP を合わせて約 6,000 万ドルの ARR 逆風」と記載(S25、合算値)。
- **GRR・NRR の単独値**: FY27 Q1 の GRR 97%・NRR 115% は、決算前のプレビュー記事の記述のみ(S29、単独)。
- **RPO の増減**: FY26 末 9.0B → FY27 Q1 末 8.8B → FY27 Q2 末 10.7B(前期末比 +21.6%【派生】)。
