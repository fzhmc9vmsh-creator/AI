# Cloudflare(NET)図表仕様(図表担当 Sonnet 向け)

作成: Opus 分析担当 / 2026-10-11 / データの出所はすべて `analysis/NET_calc.py` の出力(CSV)と `analysis/NET_summary.json`。
共通: 日本語ラベル、単位を軸ラベルに明記、図の下に「出所: 会社開示(8-K・10-Q・10-K)、統括のコンセンサス表、独自計算。取得日 2026-10-11」。
系列は最大4本。予測値(2026年下期以降)は実績と線種で区別(実績=実線、予測=破線)。色は経路ごとに固定:
コンセンサス=灰色、会社シナリオ=緑、事業エンジン=青、弱気=赤、現在株価=黒の水平線。

---

## F13 年度別適正株価パス(3経路+弱気) → `charts/NET_F13.png`

- データ: `analysis/NET_F13.csv`(列 fy_end, path, business_eps, g_3y, peg_low, peg_high, fair_per_low, fair_per_high, fair_price_low, fair_price_high, …, is_extension)
- 図の型: 折れ線+帯。横軸 = 会計年度末(2026-12-31〜2033-12-31、ラベルは「FY2026」〜「FY2033」)。縦軸 = 適正株価(ドル、0〜400)。
- 系列: path ごとに fair_price_low〜fair_price_high を半透明の帯、中央値((low+high)/2)を線で描く。4経路(consensus/company/engine/bear)。
- is_extension = True の年度(FY2030 以降)は線を破線にし、背景を薄い灰色で塗って「延長部分(コンセンサス最終年度 FY2029 より先)」と注記。
- 水平線: 現在株価 360.93 ドル(黒、ラベル「現在株価 360.93(2026-10-09)」)。
- 点: 12か月目標(定常状態経由、2027-10-11 時点)を FY2027 と FY2028 の間(2027-10 の位置)に4つのマーカーで置く:
  事業エンジン 130.4、会社シナリオ 144.8、コンセンサス 78.1、弱気 29.4(summary.json の targets_12m)。
- 強調したい点(図中の注記で1行): 「FY2033 の事業エンジン経路の適正株価(215〜248ドル)でも現在株価に届かない」。
- タイトル: 「図F13 年度別適正株価パス: どの経路も2033年まで現在株価360.93ドルに届かない」

## F18 根幹KPIの加速度 → `charts/NET_F18.png`

- データ: `analysis/NET_F18.csv`。kpi 列で系列を選ぶ。
- 2段のパネル(上下に並べる、横軸は共通の四半期 2023Q4〜2026Q2)。
  - 上段: 「DNR(%)」の value を折れ線(青、左軸 105〜125%)と、「売上前年比(四半期)」の value(%表示、緑、右軸 20〜40%)。
    注記: 2022Q1 の DNR 127%(10-Q)を左上に文字で「参考: 2022Q1 127%、2023Q1 117%」。
  - 下段: 2階差分(second_diff)を棒グラフ。「売上前年比(四半期)」の second_diff(pt、0.0121 は +1.2pt と表示)を緑の棒、
    「DNR(%)」の second_diff(pt)を青の棒。0 の水平線を引く。
- 注意: 「売上(四半期, 百万ドル)」の qoq_annualized は季節性(Q1 が弱い)を含むので、この図には使わない。
- 強調したい点: 「DNR は 2024Q3 の 110% を底に 120% へ戻り、売上成長は 26.5%(2025Q1)→35.9%(2026Q2)へ加速。2階差分は 2026Q1 に一度ゼロ近くまで縮んだ後、再びプラス」。
- タイトル: 「図F18 根幹KPIの加速度: DNR の回復と売上成長の再加速」

## F10 収益ミックスの時系列(増収の源泉) → `charts/NET_F10.png`

- データ: `analysis/NET_F10.csv`(period, line, revenue_usd_mn)。期間 2025Q1〜2026Q2 の6四半期。
- 図の型: 積み上げ棒。横軸 = 四半期、縦軸 = 売上(百万ドル、0〜750)。積み上げの順(下から):
  「前年同期の既存顧客売上」(薄い灰色)→「既存顧客の拡張(DNR−100%)」(青)→「新規コホート(過去12か月の獲得)」(オレンジ)。
  3つの合計が報告売上(2026Q2 = 696.1)になる。棒の上に合計値を表示。
- 各棒の青とオレンジの部分にラベル(百万ドル)。2026Q2: 拡張 102.5、新規 81.3。
- 注記: 「新規コホート売上 = 売上 − 前年同期売上 × DNR(独自計算。DNR はプロフェッショナルサービス等を除くため近似)」。
- 強調したい点: 「増収の約55%が既存顧客の拡張。新規コホート売上は 2026Q2 に前年比 +47%」。
- タイトル: 「図F10 増収の源泉: 既存顧客の拡張と新規コホート(四半期、百万ドル)」
- 任意の補助図 `charts/NET_F10b.png`: `analysis/NET_F10b.csv` で「大口顧客(年10万ドル超)」と「その他の有料顧客」の積み上げ棒(4時点: 2024Q3、2025Q2、2025Q3、2026Q2)。
  強調: 大口顧客の売上比率 67%→73%。

## F7 エントリー価格ゾーンと現在株価 → `charts/NET_F7.png`

- データ: `analysis/NET_summary.json` の entry_zones(Z1 = 32.3、Z2 = 117.4、alpha 0.20)と targets_12m(弱気 29.4、コンセンサス 78.1、事業エンジン 130.4、会社シナリオ 144.8)、price 360.93。
- 図の型: 横向きの1本の帯(横軸 = 株価、0〜400 ドル)。
  - 0〜32.3: 「即エントリー圏」(濃い緑)/ 32.3〜117.4: 「分割エントリー圏」(薄い緑)/ 117.4〜400: 「見送り圏」(薄い赤)。
  - 帯の上に縦の目盛り線とラベル: 弱気 L = 29.4、コンセンサス 78.1、事業エンジン B = 130.4、会社シナリオ U = 144.8。
  - 現在株価 360.93 を黒の太い縦線と「現在 360.93(見送り圏)」のラベルで示す。
- 強調したい点: 「現在株価は分割エントリー圏の上限(117.4)の約3.1倍」。
- タイトル: 「図F7 エントリー価格ゾーン: 現在株価は見送り圏」
