# 業界の構造 — セキュリティ支出は年率11〜13%で伸び、統合とAIが利益の溜まり場所を動かしているが、2026年の株価はその伸びを大きく上回って上昇した

本章は、6社の評価に共通する業界の前提を整理する。数値は Web 検索で取得したもので、出典の確度(Tier)を併記する。Tier 1 は会社開示、Tier 3 は主要報道・調査会社、Tier 4 はブログ・まとめサイトである。

## セキュリティ支出は2026年に約2,400〜2,500億ドルへ、IT予算より速く伸びている

| 項目 | 数値 | 出典(Tier) |
|---|---|---|
| 2025年の世界の情報セキュリティ支出 | 2,130億ドル | Gartner プレスリリース 2025-07-29(3) |
| 2026年の予測(2025年7月版) | 約2,400億ドル(ソフトウェア約1,210億、サービス約930億、ネットワーク約260億) | 同上(3) |
| 2026年の予測(2025年第3四半期更新) | 2,442億ドル、為替一定で +11.6% | Gartner 文書名と二次ブログ(3〜4) |
| 2026年の予測(2026年第2四半期更新) | 2,489億ドル、+12.7%。2030年に3,726億ドル | 二次ブログ(4、単独出典) |
| AIを守るための支出(securing AI) | 2026年28億ドル → 2027年48億ドル(+69%) | 二次ブログが引用した Gartner 予測(4、単独出典) |

- 予測は改定のたびに上方修正されている。支出の伸び(年率11〜13%)は、6社の売上成長率(OKTA の約11%から NET の約36%)の下限に近い。**6社の多くは市場全体より速く伸びており、その差は他社からのシェア奪取と、新しい領域(AIエージェントの保護、SOC の自動化)への拡張から来る。**
- AIを守るための支出は伸び率が高いが、2026年時点の規模は支出全体の約1%にすぎない。各社の「AIセキュリティ」の売上が全社に占める比率も小さい(例: Zscaler の Security for AI は総ARRの約1.9%、Okta は「AIはまだ売上に実質的な影響がない」と自ら説明)。**AIは2026年時点では需要の物語であって、まだ売上の柱ではない。**

## 統合(プラットフォーム化)は大型買収の完了で実行段階に入った

| 買収 | 状態 | 金額 | 出典(Tier) |
|---|---|---|---|
| Google による Wiz(クラウドセキュリティ) | 2026年3月に完了と報道 | 320億ドル | 報道(3〜4) |
| Palo Alto による CyberArk(特権アクセス・アイデンティティ) | 2026-02-11 完了 | 約250億ドル(現金約23億ドル+株式約1.12億株) | 会社発表・SEC 提出書類(1) |
| ServiceNow による Armis(資産の可視化) | 2026年4月完了 | 77.5億ドル | 会社発表(1) |
| Zscaler による Red Canary(検知と対応の運用) | 完了 | 取得時 ARR 約1.4億ドル | 会社発表(1) |
| CrowdStrike による SGNL(アイデンティティ) | 2026年1月発表 | 7.4億ドル | 報道(4、単独出典) |

統合が進む理由は2層ある。第1層は、**顧客が管理するセキュリティ製品の数を減らしたい**(製品ごとの運用人員・連携の手間が大きい)こと。第2層は、**AIで運用を自動化するには、検知データを1か所に集める必要がある**(製品が分かれていると、AIが横断して判断できない)ことである。この2層目が、2025年以降に統合の速度を上げた。統合の受益者は、データの集約点を握る企業(SOC・ログ基盤を持つ PANW・CRWD、通信の中継点を持つ ZS・NET、アイデンティティを持つ OKTA と PANW)である。

## AIの影響は両方向に出ており、2026年の株価は「代替の懸念」から「防御需要の増加」へと物語が反転した

**下振れ方向(代替の懸念)**: 2026年2月、AIエージェントが業務ソフトの作業を置き換えるとの懸念からソフトウェア株が急落した。ソフトウェア株のETF(IGV)は2026年第1四半期に −24% と、2008年以来最悪の四半期になった(Yahoo Finance、3)。AIによるコード検査ツールの登場時には、CrowdStrike −19%、Zscaler −17%、Okta −17%、Palo Alto −10% と報じられた(Stocktwits、3)。懸念の中身は、**AIが SOC の人員を減らせば人員数(シート)で課金する製品の課金単位が縮む**こと、**AIが脆弱性の検出を安価にすれば一部の製品が不要になる**ことである。

**上振れ方向(防御需要の増加)**: 攻撃側のAI活用が増え、CrowdStrike の年次脅威報告は「AIを使う攻撃者による攻撃が前年比 +89%」「侵入から横展開までの平均時間が29分」と報告した(会社発表、1。ただしベンダー自身の数字である)。2026年8月のブラックハット(セキュリティ会議)後、「AIエージェントが脅威の状況を根本的に変えた」との見方が広がり、CrowdStrike と Palo Alto は最高値を更新した。8月27日の決算後には、CrowdStrike が上場来最大の上昇日、Okta が約 +22〜29% となった(CNBC、3)。

**統括の読み**: 物語の反転は、業績の加速を一部伴っている(CRWD の純新規ARR +51%、NET の売上成長の加速、FTNT の製品売上 +52%、OKTA の cRPO の加速)。一方で、株価の上昇幅は業績の加速を大きく上回った(次節)。AIが防御需要を増やすという仮説そのものは、各社の数字に表れ始めた段階であり、その持続を確かめる指標(各社報告書の判別KPI)を四半期ごとに追う必要がある。

## Microsoft は最大の競合であり、バンドルの圧力は6社すべてに及ぶ

- Microsoft のアイデンティティ製品 Entra の月間利用者は10億人、SIEM の Sentinel は4万社(2025年10月の決算説明会、1)。セキュリティ事業の売上は「200億ドル超」との記述があるが、最新の開示は確認できなかった。
- Microsoft の上位ライセンス(E5)にはエンドポイント防御・アイデンティティ・SIEM が含まれ、追加費用なしに近い形で提供される。**専業ベンダーは、Microsoft の「十分によい」製品に対して、検知性能・運用の自動化・マルチクラウド対応で上回り続ける必要がある。** この圧力は OKTA(Entra との競合)と CRWD(Defender との競合)に最も強く、FTNT(機器)と NET(ネットワーク)には相対的に弱い。

## 株価は2026年に業績を大きく上回って上昇し、6社すべてが成長に対して割高な水準にある

| 指標 | 値 | 出典 |
|---|---|---|

| 同 ETF の実績PER | 36.5倍 | 同上 |
| 6社の調整後PER(来期) | ZS 47.6倍、FTNT 55.5倍、OKTA 59.1倍、PANW 99.9倍、CRWD 218倍、NET 287倍 | `data/peer_peg_table.md`(統括計算) |
| 6社の調整後PEG | ZS 3.4、FTNT 4.6、OKTA 5.1、PANW 7.1、CRWD 7.9、NET 9.9 | 同上 |
| 低成長の同業(参考) | CHKP 調整後PER 13.1倍、AKAM 16.1倍 | 同上 |

![図 6社の成長率とバリュエーション(調整後PEG)](../charts/X_scatter_peg.png)

- メソッドの解釈アンカーでは、PEG が1.5を超えると「高評価」であり、持続年数と質への強い信認がある場合にだけ正当化される。**6社はすべて3を超え、業界全体が同時に高い期待を織り込んでいる。** 同業の中で相対的に安い銘柄はあっても、絶対的に安い銘柄はない。
- この状況では、許容PEGの経路a(ピアの実勢)は「業界全体の期待の高さ」を示すだけで、高い倍率を正当化する根拠にはならない。各社の許容PEGは、経路b(慣行上の位置)と経路c(事業の質と競争優位期間)を主として決めた。

## 規制と大規模事件は需要の底を支えるが、2026年に需要を大きく動かした証拠は見つからなかった

- 米国では SEC のサイバー開示規則(重大な事案を4営業日以内に開示)と、重要インフラの事案報告法(CIRCIA)の規則策定が続く。EU では NIS2(重要事業者向け)と DORA(金融機関向け)が施行段階にある。いずれもセキュリティ支出の「やめられない部分」を増やす方向に働く。
- 2025年8月の Jaguar Land Rover への攻撃では生産が約5週間止まり、被害は約19億ポンドと報じられた。こうした事件は経営層の関心を高めるが、個社の受注への影響を示す出典は得られなかった。
- 6社のうち3社は、自社製品の障害や脆弱性の当事者でもある(CrowdStrike の2024年7月の世界的障害、Cloudflare の2025年11月・12月と2026年2月の障害、Fortinet と Palo Alto の製品の悪用された脆弱性)。**セキュリティ製品は顧客の業務の「止まってはいけない部分」に組み込まれているため、障害は信頼と価格決定力を直接傷つける。** 各社報告書のリスクマトリクス(F14)で、障害を効果として評価した。

## 6社はバリューチェーンの異なる段階にいて、利益の溜まり場所への近さが違う

| 段階(守る対象) | 主な企業 | 課金単位 | 6社の位置 |
|---|---|---|---|
| ネットワーク境界(拠点・データセンター) | Fortinet、Palo Alto、Cisco、Check Point | 機器+保守・サブスク | FTNT(中心)、PANW(機器事業) |
| クラウド経由の通信(SSE・SASE) | Zscaler、Palo Alto、Netskope、Cloudflare | ユーザー数・帯域 | ZS(中心)、PANW、NET |
| 端末と検知・対応(EDR・XDR・SIEM) | CrowdStrike、Palo Alto、Microsoft、SentinelOne | 端末数・データ量・モジュール | CRWD(中心)、PANW |
| アイデンティティ(人と AI エージェントの本人確認・権限) | Okta、Microsoft、Palo Alto(CyberArk)、SailPoint | ユーザー数・月間利用者・機能 | OKTA(中心)、PANW、CRWD |
| インターネットの配信・防御・開発者基盤 | Cloudflare、Akamai、AWS | 従量・契約 | NET(中心) |

- **利益の溜まり場所は、データの集約点と、止められない運用の中心に移っている。** 統合の第2層(AIの自動化にはデータの集約が要る)が働くため、ログと検知データを集める SOC 基盤(PANW・CRWD)と、全通信が通る中継点(ZS・NET)は、利益プールの上流に位置する。
- 機器(FTNT)は利益プールの段階としては成熟しているが、自社半導体による原価優位で高い営業利益率を維持している。アイデンティティ(OKTA)は、AIエージェントという新しい「本人」の登場で課金単位が増える可能性がある一方、Microsoft のバンドルと PANW の CyberArk 統合という2方向の圧力を受ける。
