### 2-1 事業の本質と市場との差分

**事業の本質(3文)**: Cloudflare は、330都市超・外部接続容量500Tbps(毎秒500テラビット)の自社網の上に、Web と API の防御・高速化(アプリケーションサービス)、社員の通信の防御(Zero Trust/SASE=通信とセキュリティを一体で提供する形態)、開発者の実行基盤(Workers・Workers AI)を同じサーバーで重ねて売る。顧客は DNS(ドメイン名の案内)とプロキシ(通信の中継)を一度 Cloudflare に向けると、追加製品を同じ経路上で設定だけで使えるため、増収の約55%が既存顧客の拡張から生まれる。課金は定額プラン・従量・プール型の前払いコミットの混合で、顧客の通信量と AI エージェントの利用が増えるほど売上が自動的に増える。

**市場との差分の宣言(§4 書式)**:

> 市場は「非人間トラフィックが初めて50%を超えた(2026Q2)」「DNR 120%・売上 +36%」「2027年に Rule of 50+(売上成長30%超+営業利益率約20%)、2028年末に年換算売上50億ドル」を見て、30%超の成長が長く続くと考えている(株価は 2027〜33年に年40%の売上成長を織り込む)。構造上は、成長の約55%を担う DNR が 2022年127%→2024年110%→2026年120% と循環し、直近の水準にはプール型契約の前倒し消費が含まれる。事業エンジン経路(DNR 117%→113%、新規コホート比率 10.5%→9%)の 2033年売上は 137億ドルで、株価が要する 301億ドルの半分に届かない。これは 2026年Q3決算(10月末〜11月上旬の見込み)から 2027年Q2決算にかけて、DNR が 122%超を保つか 115%未満に落ちるか、新規コホート売上の前年比が +40% 超を保つかで確認できる。差が解消したときの1株当たり価値は 130.4ドル(事業エンジン経路の12か月目標)。

- 優位の種類は**分析**(コホート分解・SBC 控除後の利益からの逆算)。ただし差分は「株価が高すぎる」方向であり、買いのエッジではない。
- 短期の差分は逆向き(上向き)である: 事業エンジン経路の 2027年売上 3,838百万ドル・調整後EPS 1.91 は、コンセンサス(3,690・1.67)を 4%・14% 上回る。根拠は DNR 120% と新規コホート売上 +47%、人員削減後の費用水準(Q4 2026 の含意営業利益率 18.3%)。コンセンサスは 2027年の DNR を約116%、営業利益率を 17.1% と置いている【計】。
- **成長の値段**: 定常状態利益 816百万ドル ÷ 資本コスト9% = 定常状態価値 91億ドル。時価総額 1,350億ドルとの差 1,259億ドル(93.3%)が成長の値段。価値の時間分布は、3年以内(2027〜29年の事業実態EPSの現在価値 3.50ドル)が株価の 1.0%、それ以降が 99.0%。

### 2-2 原子単位とエンジン式: 報告売上を ±1% で再構成できる

- **原子単位**: 有料顧客(アカウント)。二層に分ける。①大口顧客(年換算売上10万ドル超)4,698社が売上の73%、1社当たり年換算 43.3万ドル(前年 39.2万ドル、+10.4%)【T1/計】。②長い尾(その他の有料顧客)が売上の27%。有料顧客数は前年比 +74%(総数は未開示)【T3】。
- **エンジン式**: 売上_q = 売上_{q−4} × DNR_q ÷(1 − 新規コホート比率 s_q)。DNR は前年同期に有料だった顧客の売上の継続・拡張率(会社開示)、s は過去12か月に獲得した顧客の売上が全体に占める比率。
- **照合(合格基準 ±5%)**: 前年同期の s を使って当期を予測すると、2026Q1 は 644.5(報告 639.8、+0.7%)、2026Q2 は 688.9(報告 696.1、−1.0%)【計】。DNR は独立の開示値であり、照合は合格。大口層は 4,698社 × 43.3万ドル = 年換算20.3億ドル(売上の73%、会社開示の比率と恒等)。

### 2-3 価値の起点: 顧客が払うのは「止まらない・攻撃されない・速い」の三つを一つの経路で得るためである

- **顧客の仕事**: ①公開している Web・API を DDoS(大量通信でサービスを止める攻撃)・不正ボット・AI クローラーから守り、速く届ける。②社員と端末の社内システムへの接続を、VPN と専用機器なしで守る(Zero Trust=通信ごとに本人と端末を確認する方式)。③サーバーを管理せずに、利用者の近くでコードと AI 推論を動かす。
- **代替手段と費用**: ①は Akamai・Fastly・AWS CloudFront+Shield、②は Zscaler・Palo Alto Networks、③は AWS Lambda・Vercel・ハイパースケーラーの GPU。複数ベンダーと機器を組み合わせる場合、契約・運用・遅延の費用が重なる。Cloudflare は無料プランから入れ、同じ経路で三つを束ねる点で代替より安い。
- **支出比率×重要度**: Web が止まれば顧客の売上が止まる(重要度が高い)一方、Cloudflare への支出は顧客の IT 支出の小さな比率にとどまる。価格決定力の条件はそろう。
- **未行使の価格決定力(定量)**: AI 事業者がサイトを読む回数と、利用者を元サイトへ送る回数の比は、2026年7月時点で Anthropic 約1,917対1、OpenAI 約251対1、Perplexity 約289対1(Cloudflare Radar の集計の二次引用【T4】)。コンテンツ所有者は見返りなく読まれており、Pay per crawl(AI 事業者がページを読むたびに課金する仕組み)と Monetization Gateway は新しい課金単位になりうる。規模は未開示のためオプションとして扱う(2030年に売上3億ドルなら12か月目標 +14.8ドル【計】)。
- **下振れ機構**: 最大級の顧客は WAF(Web アプリの防御)やエッジ機能を自前で作る経済合理性がある。ハイパースケーラーは開発者基盤でリーダー(Gartner のクラウドネイティブ・アプリ基盤で AWS・Google がリーダー、Cloudflare はチャレンジャー【T4】)。SASE・SSE では「ビジョナリー」でリーダーではない(2026-07、会社ブログ【T1】)。

### 2-5 自己強化ループと制約: 拡張ループは作動中、開発者ループは数で作動し金額は未確認、律速は大企業向けの販売能力

- ループの各リンクと証拠は F15 のとおり。**ループ1(拡張)は定量の証拠で閉じている**(DNR・更新率・単価)。ループ2(規模)は単位原価の時系列が非開示のため、粗利率の配賦の変化と網の規模で間接的に確かめた。ループ3(開発者)は数で作動しているが、金額への転換は仮説の段階。
- **ループの速度**: プール型契約は年単位で更新され、消費が速いほど更新が前倒しになる。1周は約12か月、1周の増幅率は DNR(約1.2倍)。
- **制約**: 需要はパイプライン生成が5年ぶりの速さで、供給(GPU)は「汎用 GPU を借りて規模を競う投資競争を避け、稼働率を70〜80%に上げる」方針【T3】で律速ではない。律速は大企業向けの販売・導入の能力であり、人員削減でも営業担当を残した事実と、パートナー比率を 31% から 50〜60% に上げる構想がそれを裏付ける。
- **収穫逓増**: 規模の経済(固定費の網に利用量を載せる)と範囲の経済(同じ網で新製品)が働く。粗利率の低下は有料トラフィックの増加による配賦の変化で、規模の不経済の証拠ではない。逆方向の兆候として、AI 推論の GPU 原価と「長期粗利率 70〜77%」への下限引き下げを記録する(機構台帳 M7)。
- **バランスループ(成長を抑える働き)**: プール型の前倒し消費の反動(2026Q1 の DNR 118%)、障害による信頼の低下、SBC による希薄化。

### 2-6 需要の連鎖と受注残: 最終需要は企業のIT・セキュリティ予算と AI 事業者の支出で、契約済みの比率は高まっている

- **派生需要の連鎖**: 顧客(Web・アプリの所有者、企業の IT 部門、開発者、AI 事業者)→ その先の利用者(人間と AI エージェント。2026Q2 に非人間トラフィックが初めて50%超【T3】、エージェントのトラフィックは11か月で約1,700%増【T3】)。資金源は企業の IT・セキュリティ予算(Gartner の世界の情報セキュリティ支出は 2026年に約2,400〜2,490億ドル、前年比 +11〜13%【T3/T4】)と、AI 事業者の支出(多くは資本市場からの調達)。
- **需要の層**: 契約済み(RPO=残存履行義務 2,543.5百万ドル、うち12か月以内 64%、2026-03-31【T1】。cRPO=12か月以内に計上予定の RPO の前年比 +35%、2026Q2【T1】)、習慣的(月額・年額のサブスクリプション)、裁量的(従量の超過分・Workers の利用)。プール型契約は ACV の約20%で、契約済みの比率を上げている。
- **受注残の質(両面)**: 量は cRPO +35% と売上成長(+36%)がそろい、受注残が売上を先導している。需要の強さの証拠は前払い(繰延収益 852.5百万ドル、2026-06-30【T1】)。集中は低い: 過去最大の ACV 案件は年4,250万ドル(2025Q4)で年売上の約1.5%。
- **サイクルの感応度**: 2023〜24年の DNR 低下(115%→110%)は企業の IT 予算の最適化局面と重なり、拡張は景気に感応する。これが弱気パスの起点である。

### 2-8 時間構造と定常状態利益: 成長投資を止めれば非GAAP営業利益率は約44%、SBC を引いても35%で、報告利益(15.5%)は稼ぐ力の下限である

- **フロー→ストックの転換**: 新規コホート(フロー)の売上は、翌年以降 DNR の倍率で積み上がるストックになる。転換係数は「新規1ドル → 翌年 約1.2ドル」(DNR 120%)。
- **コホートのJカーブ**: S&M は獲得時に費用計上されるため、新規獲得が速いほど報告利益は小さく見える(マジックナンバー0.94・回収 約1.5年)。
- **定常状態利益(成長投資を止めた場合)**: 非GAAP粗利率 73% − 維持のための S&M 12% − 維持のための R&D 8% − 管理費 9% = 非GAAP営業利益率 約44%。ここから定常状態の SBC 9% を引くと税引前 35%、税引後で 2026年の事業エンジン経路の売上 2,919 に対し **816百万ドル**【計】。維持費用の比率は Cloudflare が開示しない推定値であり、35〜50% の幅で定常状態価値は 68〜106億ドル(成長の値段の比率 92〜95%)と動くが、結論は変わらない。
- **S字カーブ上の位置**: アプリケーションサービスは急成長期の後半、Zero Trust と開発者基盤は急成長期の入口、AI 課金は導入期。
- **受注→売上の時間差**: RPO の64%が12か月以内に計上。プール型契約は消費の速さで売上計上の時期が変わる。
- **契約期間と義務期間**: 網とGPUの容量を先に持つ(固定費)一方、顧客の契約は1〜3年。下振れは固定費の残存、上振れは容量を持つ者だけが取れる推論需要。

### 2-9 持続性と成長余地: 競争優位期間は約12年、浸透率は会社定義の市場の約1%

**7 Powers の判定**

| Power | 有無と強さ | 証拠 |
|---|---|---|
| 規模の経済 | あり・強 | 500Tbps・330都市の固定費の網。単位当たりの原価は非開示 |
| カウンターポジショニング | あり・強 | 無料プランと単一経路の統合は、機器を売る既存ベンダー(機器の買い替え収入を失う)や Akamai(配信の従量収入を失う)が真似ると自社の収益を傷つける。Akamai の配信売上は −6%(2026Q2【T1】) |
| スイッチングコスト | あり・中 | DNS・プロキシの設定、Workers のコード、プール型契約の残高 |
| ネットワーク効果 | 弱〜中 | 通過するトラフィックが脅威データになり防御を良くする(間接的) |
| ブランド・独占的資源・プロセスパワー | 中 | 開発者の支持、相互接続、製品の投入速度(Gartner はビジョンを評価、実行はリーダーに届かない) |

- **再現コストテスト**: 十分な資金を持つ競合(ハイパースケーラー)は網を作れるが、無料プランで世界の Web の入口を押さえるには数年と数十億ドルを要し、自社クラウドへの囲い込みと矛盾する(顧客は「どのクラウドにも中立な入口」を求める)。
- **敵対的検証(赤チーム)**: 競合CEO=ハイパースケーラーが WAF・CDN を自社クラウドの利用者に無料で束ねる(Bernstein は「AI の競争」を中立の理由に挙げる【T3】)。顧客CFO=最大級の顧客が複数の CDN に分散し、WAF を内製する(障害の反復が引き金)。サプライヤ=GPU 供給者の値上げ、通信事業者の相互接続料。規制当局=海賊版サイトの責任(イタリアの制裁金1,420万ユーロ=1株0.04ドル、日本の出版社訴訟、EU 司法裁判所の Universal Music の主張【T3】)。いずれも、網の規模と中立性という構造に対しては部分的な攻撃にとどまる。
- **二次の効果**: 会社シナリオが成功すると、①ハイパースケーラーがエッジ機能の価格を下げる、②AI 事業者が Pay per crawl を避けて直接契約に移る、③規制当局が「通行の判定者」としての責任を広げる。①②は単価を、③は費用を押し下げ、機構台帳 M8〜M10 に載せた。
- **競争優位期間(CAP)の推計: 約12年**(規模の経済とカウンターポジショニングが強く、スイッチングコストは中。ハイパースケーラーの開発者基盤での優位と障害の反復が上限を抑える)。出口PEG 1.6 の根拠。
- **成長余地**: 会社定義の市場規模は 2026年2,380億ドル → 2029年3,840億ドル(年率17%、Investor Day【T3】)。2026年売上 約29億ドルは約1.2%。天井を上げる仕掛けは、AI 推論、エージェントの決済(Wallets・cloudflare.pay)、Pay per crawl という新しい課金単位である。
