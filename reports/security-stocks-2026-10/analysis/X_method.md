# 分析の方法と前提 — 6社を同じ物差しで測るため、株式報酬を費用とみなす「事業実態EPS」と12か月後の利益で目標株価を揃えた

本書は、世界の主要なサイバーセキュリティ専業企業6社を、銘柄分析メソッド(以下「メソッド」)で個別に審査し、同じ物差しで順位付けしたものである。本章では、対象の選び方、6社に共通して適用した評価規約、順位付けの方法、作業体制と品質管理、情報取得の制約を示す。個別の評価の根拠は第II部の各社報告書にある。

## メソッドは、事業本体を土台に、経営陣のシナリオを軸として、市場との差分を価格に落とす

メソッドの手順は Phase 0(入口審査)から Phase 7(報告書)までの8段階であり、各社報告書の章立てはその Phase 7 の様式に従う。要点は次の5つである。

1. **評価の基準は事業本体に置く。** 顧客がなぜ払い、事業がどう広がり、何年続くか。会計数値とキャッシュフローは、事業について立てた仮説が数字に表れているかを確かめる「確認層」として扱う。
2. **芯に集中する。** 1株当たり価値を最も動かす1〜3個の変数(芯)を価値感度分析で特定し、調査の過半をそこに投じる。
3. **結論は市場との差分として書く。** 市場(コンセンサス・株価)が暗に置いている前提と自分の見積りの差、その差を生む優位の種類(情報・分析・時間軸・行動)を明記する。差分がなければ「エッジなし」と書く。
4. **リスクは存在ではなく効果で測る。** 希薄化・借入・株式報酬・顧客集中は、1株当たり価値への純効果と反実仮想(その施策をしなかった場合)で評価する。
5. **最終判断は「構造評価 × 価格乖離」の2軸で行う。** 構造評価は長期保有13条件(Appendix D)による S〜F、価格乖離は目標株価と現在株価の差である。

## 6社に共通して適用した評価規約は7つある

各社の分析者が独自の物差しを使うと、順位付けができない。そこで次の規約を全社に共通で適用し、計算は共通の関数群(`build/valuation_lib.py`)で行った。

| # | 規約 | 内容 | 理由 |
|---|---|---|---|
| 1 | 事業実態EPS | 調整後EPS(会社定義の非GAAP)から、株式報酬(SBC)の税引後相当額を差し引く。買収無形資産の償却は除外したまま | SBC は人材への対価であり、現金で払わないだけで株主の負担である。調整後EPSは SBC を足し戻すため、SBC の重い企業ほど利益を過大に見せる |
| 2 | 株数の扱い | SBC を費用として控除するので、SBC による将来の希薄化は株数に入れない。買収の株式対価・転換社債などの希薄化は入れる | 同じ負担の二重計上を避ける |
| 3 | 目標株価の時点 | 12か月目標株価 = 2027-10-11 時点の向こう12か月(NTM)の事業実態EPS × 妥当PER | 6社の決算期末が1月・7月・12月と異なるため、会計年度ではなく暦の時点で揃える |
| 4 | 妥当PER | 妥当PER = 許容PEG × 先3年の事業実態EPS成長率(%)。成長率は50%で頭打ち | メソッドの PEG 評価。成長率が極端に高い年度で PEG の線形性が崩れるのを防ぐ |
| 5 | 許容PEG | 同一基準ピアの実勢(経路a)、慣行上の位置(経路b、1未満=著しく低い/1〜1.5=一般/1.5超=高評価)、質とシナリオの因果(経路c)の3経路の収束で決める | 表の機械適用を避ける |
| 6 | 定常状態経由の目標株価 | 5年後の事業実態EPS × 出口PER を資本コスト9%で割り引いた値を、規約3の値と並べて計算し、どちらを採るかを事業本体との整合で判断する | 事業実態EPSが近い年度でほぼゼロになる企業(後述)では、規約3だけでは価値を測れない |
| 7 | 資本コスト・判断表 | 資本コスト 9%(感応度 8%・10%)。エントリー価格帯は構造評価に応じた安全余裕率αから機械的に算出。最終判断は2軸マトリクス(構造評価×価格乖離)。市場との差分がない場合は「買い」にせず「買い検討」を上限とする | メソッドの規定 |

**規約1が結論を大きく動かす。** 調整後EPSに対する事業実態EPSの比率(来期、SBC比率を一定とした簡易値)は、FTNT が約90%、PANW が約53%、OKTA が約33%、CRWD が約16%、ZS が約8%、NET が約1%である(`data/peer_peg_table.md`)。つまり、市場が見ている「調整後の利益」の大半が、CRWD・ZS・NET では株式報酬で相殺されている。この差を各社がどう埋めるか(SBC比率の低下、成長による固定費の分散)が、6社のうち4社で芯の候補になった。

## 順位は「投資魅力」と「事業の質」の2本で示す

メソッドの目的は割安な優良企業の見極めであるため、主たる順位は投資魅力の順位とし、事業の質の順位を別に示す。

**投資魅力の順位(主)**は次の順に比較して決めた。
1. 最終判断の区分(買い > 買い検討 > 監視 > 見送り)
2. 確率加重の期待リターン(弱気・コンセンサス・事業エンジン・会社シナリオの各目標株価に確率を付けた加重平均と現在株価の差)
3. 構造評価(S〜F)
4. 非対称性(上値幅÷下値幅)

**事業の質の順位(副)**は、構造評価と競争優位期間(CAP: 平均以上の収益性が続く年数の推計)で決めた。価格を含まない、事業そのものの順位である。

## 作業はモデルの役割を分けて進め、統括が全数値と判断を検証した

利用者の指示に従い、判断の重さに応じて3種類のモデルに作業を分担した。判断の質を左右する工程は、すべて Opus が担当した。

| 工程 | 担当 | 内容 |
|---|---|---|
| 設計 | Opus(統括) | 対象の選定、共通規約、計算関数、分析者への指示書 |
| 定量データの収集 | Haiku ×7 | 6社とピア企業の財務・KPI・ガイダンス・コンセンサス・株価を出典つきで表にする(判断を含まない転記) |
| 定性情報の収集 | Sonnet ×7 | 経営陣の発言、市場の仮説(アナリストの強気・弱気論)、一次情報、異常値の候補、業界動向 |
| データの検証 | Opus(統括) | 株価・コンセンサスの照合、同一基準ピアPEG表の作成 |
| 個別分析と判断 | Opus ×6 | 各社の Phase 0〜7(事業本体、芯、シナリオ採点、13条件、バリュエーション、最終判断) |
| 図表・組版 | Sonnet | 図表ツールキット、Markdown から Word への組版パイプライン |
| 数値の突合 | Haiku | 報告書の数値と計算結果の照合(機械的な照合) |
| 横比較・順位・品質ゲート | Opus(統括) | 6社の報告書のレビューと差し戻し、順位付け、第I部の執筆、Word の目視確認 |

## 情報取得には制約があり、結論への影響を各社報告書の「既知の制約」に書いた

1. **外部ページの直接取得ができなかった。** 実行環境のネットワーク方針により、TradingView・SEC EDGAR・各社 IR サイトのページ本文を直接開けず、利用できたのは Web 検索(検索結果の要約と出典URL)だけである。メソッドが定める「TradingView で全予想年度のコンセンサスを取得する」は実行できず、Yahoo Finance・Zacks・StockAnalysis 等の集計値を検索経由で取得した。3年度目以降のコンセンサスは出典が少なく、出典間で値が割れる。
2. **検索回数に上限があった。** 1回の作業単位あたり200回(全エージェント共有)の上限があり、調査を複数回に分けた。各社の一次情報(顧客の声・価格表・求人など)は、メソッドが求める件数に届かなかった社がある。
3. **会社発表の原文照合は検索要約経由である。** 決算発表(8-K 別紙99.1)や 10-Q の数値は、検索結果が引用した値で確認した。重要な数値は2出典以上で照合し、食い違いは各社データ表に両論併記した。
4. これらの制約は、数値の精度(特に3年度目以降のコンセンサスと一次情報)を下げるが、結論の方向(各社が成長に対して割高か割安か)を変えるほどではないと統括は判断した。判断の根拠は各社報告書の感応度分析(F12)にある。
