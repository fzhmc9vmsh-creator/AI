## 2. 事業本体 — Okta は「特定のクラウドに属さない中立の本人確認・権限の台帳」を座席課金で貸し、既存顧客への追加製品で伸びる事業であり、AIエージェントはまだ課金単位ではなく座席への上乗せである

### 2-1 Okta の本質は中立の権限台帳であり、市場はそれを AIエージェントの急成長株に分類し直した

**事業の本質(3文)**: Okta は、2万社超の企業が従業員(Workforce Identity)と自社アプリの顧客(Customer Identity、旧 Auth0)の「誰が何にアクセスしてよいか」を、Microsoft・Google・AWS のどれにも属さない中立の立場で一元管理する基盤を、座席(ユーザー)または月間アクティブユーザー単位の年額課金で売る。売上の約85%を ACV 10万ドル超の 5,255社が占め(FY27 Q2、会社開示)、成長は既存顧客への IGA・PAM・ITDR などの追加製品のクロスセルで生まれる(NRR 107%)。AIエージェントの統制は製品として一般提供済みだが、課金は人間の座席への上乗せか同梱(Agent SSO は SSO プランに追加料金なしで含まれる)が中心で、会社自身が「売上への影響は実質ゼロ」と述べている。

**市場との差分の宣言(business-core §4 の書式)**:
> 市場は、FY27 Q2 の過去最高の契約獲得と Oktane 2026 の「エージェント向けセキュリティ市場は現在の IAM 市場を上回りうる」という経営陣の発言を見て、Okta を AIエージェントの数に比例して伸びる急成長株と考えている(Morgan Stanley・Scotiabank・BMO の目標株価245ドル、年初来約2.8倍)。構造上は、再加速の実体は既存顧客への IGA・PAM のクロスセルであり、エージェントは座席への上乗せ・同梱として値付けされているため、課金の原子単位はまだ「人間の座席」のままである。これは FY27 Q3(2026年12月初旬)〜FY28 Q2(2027年8月)の決算で、NRR が110%に届くか、エージェント製品の独立した価格表と売上が開示されるかで確認できる。差が解消したとき(エージェントが座席の上乗せにとどまる場合)の1株当たり価値は約103ドル(事業エンジン経路、規約どおり。DCF では145ドル)。

- **見落としの原因の分類**: 分類の誤り(ピーター・リンチの6分類。中核は「安定成長」、利益率とSBCは「業績回復」、エージェントは数字に出ていないオプションなのに、全社を「急成長」で見ている)+片側の物語(上振れの物語だけが流通し、Microsoft の Agent 365 が人間1人当たり月15ドルでエージェントのIDを同梱する事実が価格に入っていない)。
- **優位の種類**: 分析。同じ公開情報から、成長源をクロスセルとエージェントに分解し、課金単位(何に対して払われているか)を確かめ、SBC を費用として扱った利益で評価している。情報の優位は持たない。
- **成長の値段**: 定常状態価値(成長投資を止めた場合の稼ぐ力 ÷ 9%)は1株79ドル(142億ドル)、時価総額の66%(273億ドル)が成長の値段。2026年2月の安値(68.77ドル、報道)は定常状態価値とほぼ同水準であり、**市場は8か月で「成長ゼロ」から「成長に時価総額の3分の2」へ評価を移した**。

### 2-1b 芯は「中核の成長持続」「エージェント課金の時期」「SBCと利益率の転換」の3変数で、最も価値を動かすエージェント課金は予測可能性が低い

価値感度分析(事業エンジン経路を基準に各変数を現実的な幅で動かし、1株当たり価値の変化を測定。`OKTA_calc.py` §9):

| 変数(動かした幅) | 定常状態経由の目標への影響 | DCFへの影響 | 予測可能性 | 位置づけ |

| 出口PEG=競争優位期間(1.2〜1.8) | ±18.4ドル | — | 中 | 芯①②の結果として決まる(独立の変数ではない) |

### 2-2 原子単位は「顧客組織」で、受注残×転換係数のエンジン式は報告売上を +1.3% の誤差で再構成できる【図F15】

**原子単位**: 顧客組織(2万社超。うち ACV 10万ドル超 5,255社が ACV の約85%)。その内側の課金単位は、Workforce Identity が従業員の座席(Starter 月6ドル、Core Essentials 月14ドル、Essentials 月17ドル、年額・最低1,500ドル。価格は第三者の価格サイト、Tier 4)、Customer Identity が月間アクティブユーザー、エージェント製品は早期アクセス契約で「エージェントとIDの接続数(月)」(Okta の早期アクセス契約書、Tier 1)。

**エンジン式(2本)**:

| 式 | 内容 | 照合 |
|---|---|---|
| ストック式 | サブスク売上(TTM)_t = サブスク売上_t−1 × NRR + 新規顧客の売上 | TTM 2,703 → 3,014百万ドル(+11.5%)= 既存の純拡張 +189(7.0pt、NRR 107%)+ 新規顧客 +122(4.5pt、残差) |
| 受注残式 | 翌12か月のサブスク売上 = cRPO × 転換係数 k | Q2 FY26 の cRPO 2,265 × k 1.349(前年の実績値)= 3,055 vs 実績 3,014 → **差 +1.3%(±5%以内で合格)** |

- 平均ACV(推計): サブスク年換算 3,172百万ドルの85%を5,255社で割ると、大口顧客1社当たり約51万ドル、その他(約1.5万社)は約3.2万ドル。総顧客数は「2万社超」の開示のみで、新規顧客数の時系列は非開示(既知の制約)。
- 受注残式の先行き: Q2 FY27 の cRPO 2,585 に k 1.30〜1.35 を掛けると翌12か月のサブスク売上は 3,360〜3,486(TTM比 +11.5〜+15.7%)。**k が前年並み(1.331)なら +14.1% で、コンセンサスの FY28 売上 +10.2% を上回る**(コンセンサスの上方修正余地)。

### 2-3 顧客は「数百のアプリへの安全なログインと権限の証明」に払い、価格の天井は Microsoft のバンドルが決めている

- **顧客の仕事**: 従業員が数百の SaaS・社内アプリ・AIエージェントに一度の認証で入れること、退職・異動のときに全アプリの権限を一括で外すこと、監査で「誰が何にアクセスできるか」を証明すること。Customer Identity では、自社アプリの顧客ログインを自前で作らずに安全に提供すること。
- **代替手段とその費用**: Microsoft Entra ID(P1 は Microsoft 365 E3・Business Premium に、P2 は E5 に含まれる。単体価格 P1 約6〜7ドル、2026年7月に約16%値上げ)。Google、Ping Identity、自社開発(顧客向けでは AWS Cognito 等)。乗り換えの費用は、数百のアプリの SSO 設定・プロビジョニング・ポリシーの移行(大企業では数四半期)と、移行中のログイン障害リスク。
- **支出比率×重要度**: 1人月6〜17ドルは従業員1人当たり費用のごく一部である一方、止まれば全社の業務が止まる。重要度は高く支出比率は低い。価格決定力は理論上強いが、Microsoft 中心の企業では E3/E5 に含まれる Entra の「限界費用ゼロに見える」価格が天井になる。
- **未行使の価格決定力**: Microsoft が2026年7月に Entra P1 を約16%値上げした(Tier 4 の価格サイト、Microsoft 公式で未確認)ことは、Okta の値上げ余地(価格の傘)を広げる上振れ機構である(機構台帳 M6)。ただし Okta の値上げ実績は今回確認できず(既知の制約)。
- **下振れ機構**: Microsoft Agent 365(2026年5月一般提供、人間1人当たり月15ドル、E7 に同梱)が Entra Agent ID を含む。エージェントのIDが「Microsoft の上位ライセンスに含まれるもの」として定着すると、Okta のエージェント製品の価格の天井が下がる(M8)。

### 2-4 増収の6割は既存顧客の拡張で、新製品を含む案件は ACV が約40%上乗せされ、増分ROICは推計26%である

**増収の源泉分解(TTM サブスク売上、FY26 Q2 → FY27 Q2)**:

| 源泉 | 金額(百万ドル) | 寄与 | 根拠 |
|---|---|---|---|
| ①新規顧客 | +122 | +4.5pt | 残差(推計) |
| ②既存顧客の純拡張(アップセル・クロスセル − 縮小・解約) | +189 | +7.0pt | NRR 107%(会社開示) |
| ③離脱 | ②に含む | — | 総継続率(GRR)は非開示。第三者要約は「健全」と記述 |
| 合計 | +311 | +11.5% | IR |

- ②の内訳の手がかり: 新製品(IGA・PAM・ITP・ISPM)が契約獲得に占める比率は FY27 Q1 約25% → Q2 約30%(説明会要約、Tier 3)。新製品を含む案件の ACV 上乗せは平均約40%。ACV 100万ドル超の顧客は600社超・+20%超(Tier 3、単独)に対し、10万ドル超の顧客は +6%。**拡張は大口顧客に集中している**。
- **ユニットエコノミクス(推計)**: non-GAAP S&M 年換算 9.64億ドルに対し、総新規ACV(純増 + 解約の補充。解約率5〜8%と仮定)は 4.46〜5.27億ドル、総新規ACV/S&M 0.46〜0.55、マジックナンバー(純増ARR×粗利率÷S&M)0.26。成長向けS&Mを6割と置くと、成長S&M 1ドルが ACV 0.84ドルを生み、寄与率49%(粗利82% − 維持S&M 10% − 維持R&D 10% − G&A 7% − 定常SBC 6%)、顧客寿命の減耗6.5%で、**増分ROIC は約26%(前提の幅で20〜35%)**。資本コスト9%を大きく上回るので、成長投資は1株価値を増やしている。回収期間は約2.4年。
- **増分S&Mと増分粗利**: FY27 Q2 の non-GAAP S&M は前年比 +17.6%(2.41億ドル)で売上 +11% を上回る。「販促に頼らずクロスセルできている」確認テスト(増分S&M÷増分粗利の低下と②の拡大の同時発生)は、②は拡大したが S&M 比率は上がったため**未充足**。経営陣はエージェントと新製品の営業体制に先行投資していると読める(意図の解読)。
- **収益の多重性**: 1つの顧客テナント(ディレクトリ)から、SSO・MFA・ライフサイクル管理・IGA・PAM・ITP・ISPM・Okta for AI Agents・Customer Identity の最大9本の収益線を引ける。追加製品は同じ基盤上で動くので追加の原価は小さく(サブスク粗利率 83.9%)、追加の費用は主に営業とR&Dの人件費である。

### 2-5 自己強化ループは「中立性→統合の網→標準」と「SSOの足場→権限の可視化→追加製品」の2本で、いまの律速は需要側の「混乱」である【図F15】

| ループ | リンク | 定量の証拠 | 状態 |
|---|---|---|---|

## 8. 13条件による構造評価 — 中立性・前払いのストック収益・潤沢なFCF が評価を支え、エージェントの成果と経営陣の長期の公約が評価を抑え、構造評価はBである

### 8-1 評価分布は S1・A1・B6・C3・D2 で、拒否権も C×4 上限も発動せず、構造評価はBと確定する

| 区分 | 条件 |
|---|---|
| S | 4(米国株) |
| A | 2(コア事業のキャッシュフロー) |
| B | 1(価格決定力・競争優位)、8(非コモディティ)、10(無形資産の陳腐化)、11(模倣困難)、12(継続課金)、13(アーキタイプ) |
| C | 3(AIへの転用の成果)、5(CEO)、9(AIの停めない運用、適用) |
| D | 6(PEG<1)、7(PEG が低い理由) |
| E 以下 / 対象外 | なし / なし(条件9は適用) |

**ルールの適用(導出過程)**:
1. 対象外(N/A)の除外: なし(Okta は AIエージェントの統制製品を提供するため条件9を適用)。
2. 致命条件の拒否権(E以下が1つでもあれば上限): **非発動**(E以下なし)。
3. 条件6・7の対評価: 6=D(どの経路でも5年 EPS CAGR 30%以上・PEG<1を満たさない。事業実態EPS の5年 CAGR は事業エンジン経路で26.3%、PEG は約3〜5)、7=D(PEG が低くないため前提が成り立たず、プレミアムの理由はリスクの過大評価ではなく AIエージェントへの再分類)。D/D で整合し、条件6の S を無効にする問題は生じない。
4. C×4 上限: **非発動**(C は3つ)。
5. 総合: 事業の質(条件1・2・8・10〜13)は A〜B、AI の成果と経営(3・5・9)は C、価格(6・7)は D。価格は2軸マトリクスの価格乖離で別に扱う(二重に減点しない)ため、**構造評価は B**(概ね充足、軽微な留保あり)。

- **アーキタイプ照合**: ORCL 型(継続課金・陳腐化リスクを自社が設備で負わない・運用基盤として止められない)に近いが、従量課金ではなく座席課金で、顧客の利用拡大が自動では売上にならない。SSO/MFA の層では Microsoft の同梱による AVGO 型(コモディティ化)の圧力がある。MU 型(循環的な陳腐化 capex)・VRT 型(売り切り・供給過多)の要素はない。ビジネスモデル型は A(ストック型 SaaS)、エージェント製品は A→B(利用量課金)の候補。

### 10-3 規約の目標(103ドル)と DCF(145ドル)の差は「3年より先の価値」の扱いの違いで、事業本体との整合は DCF の前提の方が高いが、どちらでも結論は変わらない

**交差確認の方法**: 同じ事業実態EPS の経路(FY28〜FY38、FY33 以降は延長)を資本コスト9%で割り引き、FY38 以降は永続成長3%とした DCF(2027-10-11 時点、純現金を加算)。結果: コンセンサス 115.6、事業エンジン 145.2、会社シナリオ 201.7、弱気 81.3ドル。

**どちらの前提が事業本体と整合するか(判断)**: 事業エンジン経路では、**DCF(145ドル)の前提の方が Okta の事業本体と整合する**と判断する。理由は3つ。
1. **価値の84%が3年より先にある**(価値の時間分布、2-8)。規約の方法は3年の g と PEG で PER を決めるため、中核の競争優位期間(約10年)と、その間に続く SBC 比率の低下・営業レバレッジを表現できない。PEG は成長の持続年数を表現できない(valuation-model §3-3 の注記)。
2. **規約の方法はコンセンサス経路で定常状態価値(79.3ドル)を下回る70.8ドルを出した**。成長が続く経路に成長ゼロの価値以下を付けるのは、方法が長い利益の流れを系統的に過小評価している証拠である。
3. **近い年度の事業実態EPS は成長投資と移行期の SBC で押し下げられている**。報告ベースの事業実態利益率は約11%、定常状態は42%で、その差を近い年度の EPS に倍率を掛ける方法は反映できない(§5-3 の「急成長SaaS: 定常状態利益率を併記」の趣旨)。

**DCF の弱点(同じ粒度で)**: 終価(FY38 以降)が価値の59%を占める。資本コスト8%なら175.2ドル、10%なら124.0ドル、永続成長2%なら132.3ドル。FY33 以降の延長(売上成長10%→6%、営業利益率35%、SBC 6%)は当方の仮定であり、事業エンジン経路の FY32 までの前提にも楽観の余地がある(営業利益率32.5%、SBC 8%)。

**扱い**: 横比較の規約(00_standard §4)に合わせ、本体(summary.json の `targets_12m` と2軸マトリクス)には規約値103.0ドルを置き、DCF 145.2ドルを代替値として併記する。**DCF でも乖離は −37.4% で、判断(見送り)は変わらない**。実務上のエントリーの目安には、事業本体との整合が高い DCF 基準のゾーン(即エントリー ≤90.5ドル、分割 ≤128.9ドル)を併記する(12-3)。
