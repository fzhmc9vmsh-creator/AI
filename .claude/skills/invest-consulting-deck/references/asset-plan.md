# ②資産運用計画デッキ仕様

前工程で完了した資産運用分析(前提・シナリオ・提言)を、提言資料としてスライド化する。
**分析はしない。受領した前提と提言を、1枚完結型の高密度スライドに落とし込むのが仕事**。

## 1. 最重要原則: 「そのスライドだけですべてわかる」

主要テーマは**各1枚で完結**させる。読者がそのスライド単体を見て、前提→根拠→結論まで
理解できること。実現のための密度規定:

- 文字量はBCG資料並みに**多め**でよい(本文10.5〜12pt、1枚あたり本文150〜300字+
  図表内テキスト)。ただし必ず構造化する: 平文の段落は禁止、すべて
  「ラベル+短文」「表」「図中ラベル」のいずれかに収める。
- 各スライドの下部または右端に「このスライドの結論」を薄緑背景の一文コールアウトで置く。
- 前提数値はそのスライド内に明記する(「Appendix参照」で逃げない。Appendixには
  計算過程の詳細のみを置く)。
- はみ出し・重なりは密度より優先して解消する(フォント10.5pt→表の分割→
  それでも入らなければ2枚に分割、の順)。

## 2. 必須スライドセット(各1枚・省略不可)

ゴール定義は常に「**ユーザー設定年齢での目標純資産**」で統一する(全スライドの
到達判定・ラベルはこの定義に揃える)。

| テーマ | レイアウト | 1枚に必ず含める要素 |
|---|---|---|
| (a) 収入前提 | T5比較表+T7 | 収入源別の現在額→将来推移(昇給/変動の前提)、確度ラベル(確定/蓋然/希望)、年次テーブルまたは推移チャート、前提の出所 |
| (b) 支出前提 | T5+T11 | 生活費/住居/教育/イベント支出(車・住宅等)の年次計画、一時支出は◆マイルストーンで時間軸に配置、貯蓄可能額=収入-支出の導出 |
| (c) 借入条件 | T5比較表 | 利用可能な借入手段×金利×枠×増額可否×担保/追証条件×柔軟性、推奨手段のハイライト、「借入コスト=金利 < 自己資金の資本コスト(機会費用=期待運用リターン)」のスプレッド明記 |
| (d) 資本構成比較 | T7積み上げ棒 | 現在の資本構成(自己資金/借入の内訳・レバレッジ)と将来(目標年齢)の資本構成を左右対比の積み上げ棒で図示。中間年を1〜2本追加。各棒にレバレッジ倍率と純資産額をラベル。許容レバレッジ帯(例: 1.3〜1.5)を帯で重ねる |
| (e) 具体的提言 | T4フレームワーク | 提言を6レバー別(収入増/支出減/支出の資産化/税最適化/前提の現実化/投資的支出)に番号付きで列挙: 各行に「何を/いくら/いつまでに/なぜ(根拠数値)」。純資産方程式のどの項に効くかのタグと優先度バッジ付き。投資的支出は投下額・回収期間・撤退基準を明記 |
| (f) スケジュール | T10ロードマップ | フェーズ矢羽、四半期〜年次のマイルストーン◆、各フェーズのKPI目標値と見直しトリガー |
| (g) 施策インパクト | T11ウォーターフォール | ベースライン(前提現実化後の現状延長)→各施策の寄与→施策後の目標年齢時点純資産。目標ラインを点線で重ね、達成率を大型数値で表示 |
| (h) フェーズ別To Do・注意点 | T5または T6 | フェーズ×To Do(担当は本人だが手続き先を明記)×注意点(規定・税務・心理の罠)×完了判定基準。台帳のWhy Not Yet?で特定した障害の除去策を必ず反映 |
| (i) 外部環境 | T4分類 | 金利動向/市場リターン実績帯/税制の現況/労働市場の4象限で要点+計画への含意(追い風/向かい風ラベル)+出所 |
| (j) 習得スキル・顧客想定 | T6の2カラム | ※収入増施策に副業・独立が含まれる場合のみ必須。左=習得スキル計画(現有→不足→習得手段・期間・費用)、右=顧客想定(セグメント/提供サービス/単価と根拠/チャネル)+注意点(副業規定・競業避止) |

このセットの前後に、エグゼクティブサマリ/シナリオ比較/ストレステスト/KPI定義を配置する。

## 3. 分析内容の受領チェック(Phase 0-1で使用)

標準入力は**資産運用計画メソッドの報告書(evidence台帳②を内包)**。
以下が揃っているか確認し、不足のみ質問する(不足が大きい場合は分析スキルへの差し戻しを提案):
- ゴール定義: ユーザー設定年齢での目標純資産(現在年齢・現在純資産も)
- 前提条件一覧(Excel由来の値と現実化修正後の値、修正根拠)
- 収入前提・支出前提、借入条件(手段・金利・枠・増額可否・担保/追証条件)
- 現在→中間→目標年齢の資本構成推移と許容レバレッジ帯
- 施策一覧(6レバー別・インパクト幅・実行時期・To Do・注意点・反証、
  副業/独立がある場合は習得スキル計画と顧客想定、投資的支出は投下額・回収期間・撤退基準)
- シナリオ(ベースライン/修正後/施策後、ストレス3本と対応ルール)
- フェーズ別スケジュール、KPI定義(警戒閾値含む)、外部環境の要点と出所

## 4. 標準ストーリーライン(構成案のたたき台)

```
#1  表紙(T1): 「資産形成戦略 20XX-20YY: [目標年齢]歳で純資産[X]円への道筋」
#2  エグゼクティブサマリ(T3): 推奨戦略、施策インパクト合計、必要条件、最重要リスク
#3  目次(T2、トラッカー型): 1.前提と現状 / 2.ベースラインと施策 / 3.実行計画
--- 第1章 前提と現状 ---
#4  中扉
#5  現状のB/S・資本構成(dの前半): 現在の資産・負債・純資産・レバレッジ実績
#6  収入前提(a)
#7  支出前提(b) ※貯蓄可能額の導出まで
#8  借入条件(c) ※資本コストのスプレッド構造、増額の可能性と大きさを含む
#9  外部環境(i)
--- 第2章 ベースラインと施策 ---
#10 中扉
#11 ベースラインと前提の現実化(T7): 現行前提 vs 現実化後の到達額、
    「甘い前提が隠していた遅れ」の定量表示
#12 具体的提言(e): レバー別サマリ
#13〜 主要施策の深掘り(施策数に応じ1〜4枚、T6/T15): 構造・インパクト・反証。
    副業/独立提言があれば 習得スキル・顧客想定(j)をここに1枚。
    投資的支出(事業投資・自己投資・収益資産)の提言があれば、投下額→回収→
    純資産寄与のフローと撤退基準をT15構造図で1枚
#17 施策インパクト(g): ウォーターフォールで目標達成率を可視化
#18 資本構成比較(d): 現在→中間→目標年齢、許容レバレッジ帯との関係
#19 ストレステスト(T8): 3ストレス×生存性×対応ルール
--- 第3章 実行計画 ---
#20 中扉
#21 スケジュール(f): ロードマップ
#22 フェーズ別To Do・注意点(h)
#23 KPIダッシュボード(T9): 先行/遅行KPI、警戒閾値、測定頻度
#24 サマリと示唆(T12)
#25 Appendix: 計算過程、前提と出所一覧
#26 クロージング(T14)
```

## 5. 計算の作法

- 受領した前提から資産推移を再現する際は必ずコードで計算する(暗算・概算禁止)。
  受領済みの計算結果と食い違ったら、スライド化を止めてユーザーに差分を報告する。
- 税金と借入金利支払を控除した手取りベース、目標判定は純資産(資産-負債)ベース
  (ユーザー指定があればそれに従う)。
- レバレッジ表示は常にLTV(借入/総資産)で統一。
