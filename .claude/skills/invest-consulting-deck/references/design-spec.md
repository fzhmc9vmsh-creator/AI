# デザイン規定(BCG水準・戦略コンサル様式)

参考資料(BCG「生成AIに対する各国政府の対応」経産省提出資料)から抽出した設計原則。
このファイルの規定はデッキ全体に一貫して適用する。

## 1. カラーパレット

| 役割 | 色 | HEX | 用途 |
|---|---|---|---|
| プライマリ | ディープグリーン | `197A56` | タイトル文字、強調、チャート主系列 |
| プライマリ濃 | ダークグリーン | `0E4D33` | 表紙・中扉の背景、章番号バッジ |
| セカンダリ | ライトグリーン | `86C99B` | チャート副系列、薄いハイライト背景 |
| アクセント | ティール | `1BA1A6` | 注記・示唆コールアウト、リンク的要素 |
| ネガティブ | レッド | `C0392B` | D〜F評価、マイナス値、リスク表示 |
| 中立判定 | アンバー | `D68910` | B〜C評価、要注意項目 |
| 本文 | ダークグレー | `333333` | 本文テキスト |
| 補助 | ミッドグレー | `767676` | キッカー、出所、注記、ページ番号 |
| 罫線 | ライトグレー | `D9D9D9` | 表罫線、区切り線 |
| 背景 | ホワイト | `FFFFFF` | コンテンツスライド背景 |

- ユーザーがコーポレートカラー等を指定した場合はプライマリ2色のみ差し替え、構造は維持する。
- 評価はS〜Fの7段階バッジ(角丸四角+太字1文字)で統一する:
  **S=`0E4D33`(濃緑) / A=`197A56`(緑) / B=`86C99B`地に濃緑文字 / C=`D68910`(アンバー)
  / D=`E67E22`(オレンジ) / E=`C0392B`(赤) / F=`7B241C`(暗赤)**。
  適用外の条件には **対象外(N/A)=`767676`(グレー)** バッジを使い、
  評価集計から除外されていることを注記する。評価色の意味は全スライドで固定し、変えない。

## 2. タイポグラフィ

| 要素 | フォント | サイズ | 色 |
|---|---|---|---|
| メッセージ型タイトル | Meiryo UI / Arial Bold | 18–20pt、最大2行 | `197A56` |
| キッカー(タイトル直下の説明行) | 同上 Regular | 11pt | `767676` |
| 本文・表セル | 同上 | 10.5–12pt | `333333` |
| 大型数値コールアウト | 同上 Bold | 40–60pt | `197A56` または判定色 |
| 出所・注記 | 同上 | 8–9pt | `767676` |
| フッター(©・ページ番号) | 同上 | 8pt | `767676` |

日本語はMeiryo UI(なければYu Gothic UI)、欧文・数字はArialを基本とする。
LibreOfficeレンダリングQAでは日本語フォントが置換されうるため、テキストボックスは
想定幅+10%の余裕を持たせる。

## 3. マスターレイアウト共通規定

- スライドサイズ: 16:9(13.33 x 7.5 in)
- 余白: 上下左右 0.5 in 以上
- タイトルブロック: 左上、幅は全幅の90%
- フッター: 左下=出所(「出所: 」で始める)、右下=ページ番号、右端縦=© 表記(任意)
- **禁止事項**: タイトル下のアクセント線、スライド端の装飾カラーバー、円グラフの乱用、
  テキストのみで図表ゼロのコンテンツスライド

## 4. スライドタイプライブラリ

### T1: 表紙
濃緑(`0E4D33`)の大型パネルを左〜中央に配置し、右側は関連イメージまたは
無地グラデーション。パネル内に: タイトル(2行まで、白28–32pt)、サブタイトル
(資料の位置づけ、白14pt)、日付(左下)。右上に資料番号を置ける余白を確保。

### T2: アジェンダ(トラッカー型)
濃緑背景。左に円形ビジュアルまたは無地の「本日の内容」ラベル、右に章リスト
(番号バッジ+章タイトル)。**章の開始ごとに同じスライドを再掲し、現在章のみ
白文字+濃バッジ、他章は半透明(白50%)にする**。これがBCG様式の要。

### T3: エグゼクティブサマリ
白背景。左レール(幅25%)に章名ボックスを縦に並べ、右75%に各章の結論を
2〜4行ずつ記述。全体で結論→根拠の順。ここに書く数値は本編と完全一致させる。

### T4: フレームワーク表(A/B/C分類)
行=パターン(A/B/Cバッジ+分類名)、列=「対象の例」「主な取組み/特徴」。
各行の先頭文はプライマリ色で結論、続けて黒字で詳細bullet。行間に点線罫。
下部に横断的な気づきをアクセント色のコールアウトで置ける。

### T5: 比較表(多列プロファイル)
列=評価軸(例: 実施主体/パートナー/ターゲット/概要)、行=比較対象。
セル内は短文。最重要列(概要)は幅を広く取り、キーワードをプライマリ色で着色。
列下部にまとめコールアウト(ブラケット+一文)を付けられる。

### T6: 詳細プロファイル(前提|概要の2カラム)
左25%=「前提」(目的/対象者などのラベル+短文)、右75%=「取り組み概要」を
プロセス矢羽(ステップ1→2)やカードで図解。1社・1銘柄の深掘りに使う。

### T7: チャート+テイクアウェイ
上部にメッセージ型タイトル、中央にチャート(幅60〜75%)、右または下に
テイクアウェイボックス(薄緑背景+一文)。軸ラベル・単位・注番号を必ず付す。
正負が混在する棒チャートはゼロ線を明示し、負値は`C0392B`。

### T8: 評価マトリクス(S〜F判定表)
行=評価条件、列=評価(S〜Fバッジ)+根拠(一文)+出所。バッジは評価色規定に従う。
13行を超える場合は2枚に分割するかフォント10.5ptまで許容。最下行または右下に
総合評価の大型バッジ(S〜F)。①では総括スライドとして条件別深掘り(T15)の前後に置く。

### T9: 大型数値コールアウト
2〜4個のKPIを横並びカードで表示: 大型数値(40–60pt)+ラベル(10pt)+
前提注記。②のKPIダッシュボードや①の投資ハイライトに使う。

### T10: ロードマップ
横軸=時間(年/フェーズ)。フェーズ矢羽(chevron)を上段、マイルストーン◆と
KPI目標値を下段に配置。フェーズごとに1行のフォーカス記述。

### T11: ウォーターフォール
開始残高→増減要因(入金/運用益/借入/税・コスト)→最終残高。
増加=プライマリ緑、減少=赤、小計=グレー。②の資産推移説明の主力。

### T12: サマリと示唆
2カラム。左=「分析結果のサマリ」(事実、黒字中心)、右=「示唆/ネクスト
アクション」(プライマリ色の見出し+bullet)。左右の項目は行位置を対応させる。

### T13: 2軸マトリクス
リスク×リターン、確実性×インパクト等。象限ラベル+プロット(銘柄/施策)。
推奨象限を薄緑で塗る。

### T14: クロージング
表紙と同系の濃緑パネルのみ。ロゴまたは資料名+連絡先/免責。

### T15: 構造図(条件深掘りの主力レイアウト、①で多用)
分析済みの「仕組み・構造」を1枚で図示する。レイアウト:
- 左上: メッセージ型タイトル(評価を主張として含む。例:「陳腐化リスクの高いGPUは
  顧客が前払い/持込み。自社投資は建物・冷却・電力に集中し、capexの質は極めて高い」)
- タイトル右端: S〜F評価バッジ(大)+条件番号
- 中央(幅65〜75%): **構造図**。描き方の規則:
  - アクター=角丸ボックス(自社=プライマリ緑塗り+白字、顧客/外部=白地+グレー枠)
  - カネの流れ=実線矢印+金額/条件ラベル、モノ・サービスの流れ=白抜き矢印、
    リスクの所在・移転=赤の破線矢印または赤タグ
  - 陳腐化しやすい資産(GPU等)には赤タグ「陳腐化リスク: 顧客負担」等を付し、
    陳腐化しにくい資産(建物/冷却/電力等)には緑タグを付す、のように
    **リスクが誰に載っているかを色で一目化**する
  - 比較が有効な場合は上下2段(当該銘柄の構造 vs 不合格アーキタイプの構造)で対比
- 右または下(残り25〜35%): 「根拠」ボックス(定量evidence 2〜4点+出所)と
  「評価理由」一文(薄緑背景)
- 構造が単純すぎて図にならない条件(例: 上場市場)は、T7(チャート+テイクアウェイ)
  やT9(大型数値)に差し替えてよいが、1枚1条件の原則は維持する

### T16: 総合評価・分析ロジック(①の必須スライド)
総合評価が「どう導かれたか」を1枚で示すロジックフロー。左→右の3段構成:
- 左(入力): 13条件の評価分布をミニヒートマップまたはバッジの縦列で表示
  (S×n / A×n / ... の集計付き)
- 中(処理): 適用した評価ルールをゲート型のボックスで図示
  「致命条件の拒否権(E以下→総合上限)」「条件6-7の対評価」「C×4以上→B上限」。
  発動したルールはプライマリ色で塗り、非発動はグレーアウト+「非発動」ラベル
- 右(出力): 総合評価の大型バッジ(S〜F)+一文サマリ
段間は太い矢印で接続。第三者が同じ入力から同じ結論を再現できる粒度にする。

### T17: 構造的要因サマリー(①の必須スライド)
総合評価を動かした構造的要因を上下2ブロックで対比:
- 上段「押し上げ要因」(緑系): 要因カード2〜4枚。各カード=構造の一言
  (例:「陳腐化リスクを顧客に移転する前払い構造」)+該当条件番号バッジ+評価
- 下段「押し下げ要因」(赤/アンバー系): 同形式
- 右端に総合評価バッジを縦帯で再掲し、各カードから細矢印で接続
  (どの要因が総合をどちらに引いたかを可視化)
カード内は「構造(だから)→条件評価(となり)→総合への効き(を動かした)」の
因果が読める文にする。エグゼクティブサマリ(T3)とは別物: T3は資料全体の要約、
T17は評価の構造的因果に特化。

### T18: 目標株価算出フロー(①の必須スライド)
「目標株価 = 基準EPS × 適正PER(将来5年EPS成長率 × 利益の質によるPEG評価)」の
計算を左→右のフローで1枚図示する:
- 左: 将来5年EPS推移のミニチャート(3パス、過去成長率不使用の注記)+5年CAGR
- 中左: 構造評価バッジ(S〜F)→許容PEG(対応表由来)の変換ボックス
- 中央: 適正PER = CAGR × 許容PEG の乗算を演算子付きで明示
- 中右: 基準EPS(どのEPSかを明記)× 適正PER = 目標株価
- 右: 大型数値で目標株価(レンジ)と現在株価、乖離%を判定色で表示
下部に最終判断マトリクス(構造評価×乖離)のミニ版と、当該銘柄の位置マーカー。
すべての入力値に出所注記。計算が1枚で追跡・再現できることがこのスライドの品質基準。

## 5. 図表作成の細則

- チャートの系列は最大4本。それ以上は「その他」に集約。
- 予測値は薄色または枠線のみ(実績と視覚的に区別)。予測である旨を注記。
- 表の行数は8行以内を目安。超える場合はAppendixへ逃がす。
- コールアウト(吹き出し・ブラケット)は1スライド2個まで。
- すべての図表に: 単位、期間、出所、(必要なら)注番号。
