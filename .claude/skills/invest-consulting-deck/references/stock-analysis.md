# ①銘柄分析デッキ仕様

前工程(銘柄分析メソッド)で完了した分析を、投資判断資料としてスライド化する。
**分析はしない。受領した報告書の内容を図解するのが仕事**。

デッキの結論は「最終判断(買い/買い検討/監視/見送り)」であり、その根拠は
「目標株価 = 基準EPS × 適正PER(将来5年EPS成長率 × 利益の質によるPEG評価)」の
バリュエーションと構造評価(S〜F)の2軸。**13条件はこの分析を深めるためのメソッド**
という位置づけをデッキ構成にも反映する(条件別スライドは根拠章、クライマックスは
バリュエーションと最終判断の章)。

## 1. 評価スケール: S〜F(7段階)

| 評価 | 意味 | 色 |
|---|---|---|
| S | 圧倒的充足。原型(ORCL型)と同等以上 | 濃緑 `0E4D33` |
| A | 充足。長期保有の根拠として十分 | 緑 `197A56` |
| B | 概ね充足。軽微な留保あり | 薄緑 `86C99B` |
| C | 部分的充足。監視KPIとトリガー必須 | アンバー `D68910` |
| D | 不十分。構造的な弱さあり | オレンジ `E67E22` |
| E | 不充足。不合格原型(MU/VRT/AVGO型)に近い | 赤 `C0392B` |
| F | 明確に失格。単独で投資見送り事由になる | 暗赤 `7B241C` |

- 総合評価もS〜Fで表現する(受領した分析の総合判定に従う。分析側に総合評価がない
  場合はユーザーに確認し、勝手に平均等で算出しない)。
- C以下の条件には「監視KPIとトリガー値」を必ず併記する。
- 評価根拠が受領内容にない条件は「評価保留(根拠未受領)」と明示し、推測で埋めない。

## 2. 審査フレームワーク: 長期保有13条件(固定)

各条件は**必ず1枚ずつスライド化**する。図解すべき「構造」の例も併記する。

| # | 条件 | スライドで図示する構造の例 |
|---|---|---|
| 1 | 10年間の価格決定力・競争優位・成長性を圧倒的水準で維持 | 値上げ→解約率→粗利率の連関、スイッチングコストの構造 |
| 2 | コア事業が潤沢なキャッシュフローを持つ | コア事業→CF創出→AI投資への還流のカネの流れ |
| 3 | コア技術・データがAI事業に転用され成果が出始めている | 既存資産(技術/データ)→転用経路→AI収益の変換フロー |
| 4 | 日本株か米国株 | 上場市場の確認(T9簡素版でよい) |
| 5 | CEOが信頼に足り事業拡大の経歴を持つ | 経歴タイムライン×実行実績(公約→達成)の対応 |
| 6 | 5年後EPS成長率でPEG<1(EPS CAGR 30%以上) | EPS CAGR→PER→PEGの計算構造と閾値 |
| 7 | PEGが低い理由がリスクの過大評価であること(MU型シクリカル陳腐化capexが理由ではない) | **capex構造図: 陳腐化しやすいGPUは顧客が前払い/持込み、自社は建物・冷却・電力等の陳腐化しにくい資産に投資→市場はcapex総額だけを見て過剰に懸念、の構造を図示** |
| 8 | コモディティではない(AVGO型でない) | 差別化レイヤーの積み上げ vs コモディティ層の対比 |
| 9 | 顧客のAI実装の「停めない運用」に不可欠 **(適用条件: AIにかかわる部品・サービスを扱う企業のみ。非該当企業では評価「対象外(N/A)」)** | 該当企業: 顧客のAI稼働チェーンの中での位置(止まると何が壊れるか)。対象外の場合: グレーのN/Aバッジ+適用外の理由を簡潔に示す1枚(T9簡素版)とし、評価一覧・分析ロジックでも対象外としてカウント除外を明示 |
| 10 | 無形資産投資も陳腐化リスクを厳格評価 | 無形資産の世代交代マップ(耐用の長い資産/短い資産の色分け) |
| 11 | 既存CF・設備・技術・VCが停めない運用に不可欠かつ模倣困難・代替不可能 | 参入障壁の多層構造(電力/立地/規制/リードタイム等の積層図) |
| 12 | 従量課金型の収益性格(ORCL IaaS型)であり売り切り・供給過多型(VRT型)でない | 収益モデル対比図: 従量課金の反復フロー vs 売り切りの一回性フロー |
| 13 | (総合)アーキタイプ照合: ORCL型かMU/VRT/AVGO型か | 4象限またはスペクトル上への当該銘柄の位置づけ |

各条件スライドはT15(構造図)を基本とし、構造が単純な条件(4など)のみT7/T9で代替。
連続する条件スライドは、タイトル位置・バッジ位置・フッターを完全に揃えて
「シリーズ感」を出す(BCG資料の連続スライドの様式)。

## 3. 標準ストーリーライン(構成案のたたき台)

```
#1  表紙(T1): 「[銘柄名]([ティッカー]) 長期保有適格性審査」+日付
#2  エグゼクティブサマリ(T3): 最終判断(買い/買い検討/監視/見送り)、構造評価(S〜F)、
    目標株価と乖離%、主要リスク
#3  目次(T2): 1.評価総括 / 2.13条件別の構造分析 / 3.バリュエーションと最終判断 /
    4.リスクと投資アクション ※トラッカー型: 章開始ごとに再掲し現在章をハイライト
--- 第1章 評価総括 ---
#4  中扉(T2再掲)
#5  評価一覧(T8): 13条件×S〜Fバッジ×根拠一文×出所 + 構造評価大型バッジ
#6  構造評価: 分析ロジック(T16): 評価分布→適用ルール→構造評価の導出フロー
#7  構造的要因サマリー(T17): 押し上げ/押し下げ要因を条件番号・構造と紐付けて対比
#8  アーキタイプ照合(T13): ORCL型⇔MU/VRT/AVGO型スペクトル上の位置づけ
--- 第2章 13条件別の構造分析 ---
#9  中扉
#10〜#22 条件1〜13を各1枚(T15構造図、上表の「図示する構造」に従う)
--- 第3章 バリュエーションと最終判断 ---
#23 中扉
#24 利益の質→数字への波及(T5/T15): 構造変化(ビジネスモデル/プロダクト・サービス/
    供給構成)→ROI・ROE・需要の長さ・底堅さへの波及マップ(方向・大きさ・時期)
#25 市場の見方とカタリスト(T10+T5): 現在株価が織り込む前提の言語化と、
    カタリスト時系列(EPS向き/PEG評価向きの分類、時期)
#26 将来5年EPS推移(T7): ドライバー積み上げの3パス(過去成長率不使用を注記)、
    5年CAGR、ガイダンス/コンセンサスとの乖離理由
#27 目標株価の算出(T18): EPS×PER(5年成長率×質PEG)の計算フロー、乖離%大型数値
#28 最終判断(T13): 構造評価×価格乖離の2軸マトリクスと当該銘柄の位置、
    判断を変えるトリガー
--- 第4章 リスクと投資アクション ---
#29 中扉
#30 リスクマトリクス(T13): C以下の条件を発生確率×インパクトで配置、監視トリガー
#31 サマリと示唆(T12): 左=評価総括 / 右=投資アクション(買付条件、監視KPI、売却トリガー)
#32 Appendix: 計算前提(基準EPS・5年EPSパス・許容PEG・目標株価)、出所一覧
#33 クロージング(T14)
```

複数銘柄の比較依頼の場合: #5を「銘柄×13条件のS〜Fヒートマップ」に変更し、
条件別深掘り章は主要銘柄のみ13枚フルで、比較銘柄は差分のある条件のみに絞る
(構成案でユーザーに選択肢を提示)。

## 4. 品質チェック(①固有)

- [ ] 13条件すべてに1枚ずつスライドがあるか
- [ ] 各条件スライドに: S〜Fバッジ / 構造図 / 定量根拠 / 出所 が揃っているか
- [ ] 構造図で「リスクが誰に載っているか」が色で判別できるか(T15の規則)
- [ ] 目次(トラッカー型)があり、章開始ごとに再掲・ハイライト位置が正しいか
- [ ] 総合評価: 分析ロジックページ(T16)があり、評価分布→適用ルール→総合評価の
      導出が再現可能な粒度で図示されているか(発動/非発動ルールの区別を含む)
- [ ] 構造的要因サマリーページ(T17)があり、各要因が条件番号・構造・総合への
      効き方と紐付いているか
- [ ] C以下の条件に監視KPIとトリガー値が併記されているか
- [ ] 総合評価がエグゼクティブサマリ・評価一覧・分析ロジック・要因サマリー・
      最終章ですべて一致しているか
- [ ] バリュエーション章(波及マップ/カタリスト/5年EPS推移/目標株価算出T18/
      最終判断マトリクス)が揃っているか
- [ ] 5年EPS推移に「過去成長率不使用(ドライバー積み上げ)」の注記があるか
- [ ] 目標株価の計算がスライド上で追跡・再現できるか(基準EPS・CAGR・許容PEGの出所付き)
- [ ] 最終判断がエグゼクティブサマリと#28で一致しているか
- [ ] 計算前提(基準EPS・5年EPSパス・許容PEG・目標株価)がAppendixに明記されているか
- [ ] 「本資料は情報整理を目的とし、投資助言ではない」旨の注記があるか
