# 銘柄分析メソッド(meigara-bunseki-method)

銘柄審査の実行手順書。事業の根幹を把握する方法論(10層・芯の特定・市場との差分・確認層・
リスクの効果測定・機構台帳)は `references/business-core-method.md` にあり、すべてのPhaseが
それを土台にする。

## 核心原則(参照ファイルが読めない場合も、これだけは必ず守る)

1. **目的は割安な優良企業の見極め。** 結論は市場との差分として書き、優位の種類(情報・分析・
   時間軸・行動)を明記する。差分がなければ「エッジなし」。
2. **評価の基準は事業本体。** 会計とCFは事業仮説を確かめる確認層。
3. **意図の解読→双方向→効果測定。** 数字を判定する前に経営陣の意図を書き、上振れ・下振れを
   同じ粒度で数値化し、希薄化・借入・集中は1株当たり価値への純効果と反実仮想で判定する。
4. **芯に集中する。** 価値感度分析で1株当たり価値を最も動かす1〜3変数(芯)を特定し、
   調査資源の過半をそこに投じる。網羅は手段であり目的ではない。
5. **限界・定常状態・時間で考える。** 次の1単位の経済性、成長投資を止めた場合の稼ぐ力、
   根幹KPIの加速度(MoM・QoQ年率・TTM YoYの2階差分)。
6. **制約を特定する。** いま成長を律速している段階と、その解放時期は変曲点の最有力候補。
7. **固有性テスト。** 社名を他社に置き換えても成り立つ文は分析ではない。
8. **本源的価値は株価を見ずに先に出す。** 前提(資本コスト・成長率・PER の参照クラス・倒産確率・
   シナリオ確率)を株価を見る前に記録し、利益・キャッシュフロー・リスクから価値を逆算する。
   株価との比較は最後の工程。「株価と整合した」は結論の根拠にならない(intrinsic-valuation-credit.md §1)。
9. **PER の相場観を参照クラスで持つ。** 妥当 PER は、市場平均(2026年: 日本 TOPIX 17倍台・日経 18倍、米国 S&P500 約19倍など
   最新値)、同じ成長率・ROIC の企業群、PER 理論式((1−g÷ROIC)÷(r−g))の中で位置づける。
   日本市場平均並みの PER を、高品質・高成長企業の下限に使わない。
10. **資本集約度とリスクは1か所で1回だけ数える。** capex は FCF・SOTP で、倒産リスクは倒産確率で、
   集中はシナリオ確率で数え、PEG や倍率で重ねて割り引かない。借入で成長する企業は、FCF の黒字化時期・
   レバレッジ・倒産確率の経路(F21)を必ず推計する。
11. **製品と損益の流れから入る。** 製品・サービスを 5W1H+価格で棚卸しし(L0)、損益をセグメント→
   原価→粗利→営業費内訳→営業利益→営業外→税→純利益の流れ(F19、前年比つき)で読み、
   競合との品質×価格の差をバリューチェーンで説明する(F20)。戦略施策は「小さい」で止めず
   1株当たり価値に試算する(F22)(product-and-pnl-flow.md)。
12. **成長企業は利益率を3つに分けて評価する。** ① 現在(立ち上げ費用・償却の先行・稼働前の賃料で下がっている)、
   ② 定常(1単位の容量の一生で見た利益率。再契約の単価・経済的耐用年数・残存価値を実績から置く)、
   ③ 均衡(競争後)。①に倍率を当てて「低い」と結論しない。全社営業利益率が今より悪化するか、なぜか、
   いつ反転するかを、構成比の効果と事業内の効果に分けて答える(growth-and-capex-valuation.md §1〜§3・§7)。
13. **利益率と優位の持続期間は産業構造から導く。** ファイブフォースを数値で埋め(電力の待ち年数・建設期間・
   供給量・買い手の集中・代替・値下げ圧力)、設備先行型の成功例(AWS)と失敗例(2000年の光ファイバー)と
   照合して、定常利益率と CAP を出す。優位は単価か費用の差として数値化する(同 §4)。
14. **金利の局面を年度で見て割引率を置く。** 政策金利・国債利回り・見通し・歴史的水準から期間構造で
   割引率を置き、金利シナリオの感応度を示す。成長企業の物差し(ルール・オブ・40 を FCF・EBITDA・
   オーナー利益の3通り)でも点検する(同 §5・§6)。
15. **【第4.5版】成長企業は、成長段階の尺度(G1〜G8)で構造を評価する。** 現在の ROTCE・利益率・資本比率を
   そのまま条件の評価にしない。段階(獲得期・転換期・刈り取り期・防衛期)を診断し、獲得 1 単位の採算
   (CAC・LTV・回収期間)、販促費が攻めか必要に迫られた支出か(6 つの検査)、主口座化による切替コスト、
   クロスセルが生む将来の収益、株主資本への依存度(自己資本の自給率)、B2B 基盤の段階、新技術による
   コスト構造の変化、業態の組み合わせ(例: 銀行免許 × フィンテック)の希少さと資本コスト(負債と株主資本に分けた
   必要利回り)を数値で判定し、13 条件に反映する。**EPS は販促費の出し入れで調整できるため、
   EPS の成長を分解し、販促費率の低下に頼る部分を明記する**(growth-stage-evaluation.md)。
16. **【第4.5版】シナリオ確率は証拠から出す。** 25/50/25 などの固定値を置かない。強気シナリオ(うまくいった場合)を
   ベースと同じ粒度で描き、節点ツリー・参照クラスの基準率・先行指標で確率を出し、市場の暗黙の確率と並べる
   (growth-stage-evaluation.md §9)。
17. **【第5版】成長企業は、フェーズを最初に決め、現在と将来(実現性を加味)の二層で構造を評価する。** 初歩の規律
   (KPI は前期比・前年比・率の推移で読む / EPS の四半期を税・株数・一時要因に分ける / フライホイールとバリューチェーンを
   競合と比べて数字で確かめる / 資本モデルは業界と比べてから評価する / マクロ要因は両面で合計し市場の織り込みと比べる /
   図は事業の形に合わせる)を毎回行い、その上に「市場が値段に入れていない因果」の示唆を 1 つ以上出す
   (growth-stage-evaluation.md 第5版)。
18. **【第5.1版】構造評価の変化は、必ず許容 PEG と α に反映する。** 等級の文字だけで PEG を決めず、等級の中の位置を
   条件の点数(S 5〜E 0 の平均)で決める。条件が 1 つ上がれば PEG は上がり α は下がる。将来の構造は節点ツリーの
   組み合わせごとの PEG で価値に入れる(valuation-model §3-3)。「等級が同じだから据え置き」は禁止。
19. **【第5.2版】妥当 PER は許容 PEG × g だけで決める。** 同業の PER・DCF・TBV×ROTCE は交差確認で、平均に入れない。
   g は当該年度から 3〜5 年の EPS CAGR(経営陣の計画が実績で裏付けられ、エンジンと一致するならその伸び)。
   信用・資本・希薄化は EPS 経路・確率・株数で数え、倍率で割り引かない。信用と資本の制約は同業と比べて数量化し、
   株価が示す前提を逆算して比べる(growth-stage-evaluation §6-2)。「PEG 1.0 × g」の値を必ず併記して検算する。

## 目的と評価の基準

- **目的は、割安な優良企業を見極めること。** 分析の価値は、市場の仮説の質を上回ることに
  ある。市場と同じ材料・同じ見方で出した結論には、投資判断上の価値がない。
- **評価の基準は事業本体に置く**(Phase 1.5、business-core-method.md)。顧客がなぜ払い、事業がどう広がり、
  何年続くか。**会計数値とCFは、事業について立てた仮説が数字に表れているかを確認する層**
  であり、評価の出発点にしない(business-core-method.md §5)。
- **報告書の軸は経営陣の成長シナリオである。** ただしシナリオは、事業エンジンの変数
  (原子単位の数・単価・拡張率・寿命・拘束資本)、自己強化ループのリンク、制約の解放に
  翻訳して評価する。経営陣の言葉を、そのまま採点の対象にしない。
- **結論は常に「市場との差分」として書く**(business-core-method.md §4)。差分が見つからなければ
  「エッジなし」と明言する。それも正当な結論である。

分析とは、①事業本体を把握し(Phase 1.5)、②現状の収益構造を解剖し、③経営陣のシナリオを
特定し、④シナリオを事業エンジンの変数に翻訳したピースに分解して採点し、⑤シナリオが
収益構造をどう変えるかを時系列で追い、⑥その進捗と価格(年度別PEG/PER/適正株価)を、
市場の仮説と突き合わせること。

最終判断は「目標株価 = 基準EPS × 適正PER(将来EPS成長率 × 利益の質によるPEG評価)」で行う。
- **基準EPSは事業実態EPS**とする。一時要因を正規化したうえで、EPSが事業実態を映さない
  業種(設備型インフラ・金融・不動産再生・SBCの大きいソフト・急成長SaaS)では、
  business-core-method.md §5-3の補正を**上下両方向**にかける。
- 将来EPS成長率は**過去の成長率を一切外挿せず**、コンセンサス積み上げとドライバー
  積み上げで作る。ただし**直近の加速度(MoM・QoQ年率・TTM YoYの2階差分)は、
  コンセンサスの修正余地として使う**(business-core-method.md §3 L10)。
- **長期保有13条件は、この分析を深く行うためのメソッドでしかない**(条件充足が目的ではない)。

**フラットな視点を徹底する**: 強気にも弱気にも寄せない。具体的には次の3つを守る
(business-core-method.md §1)。
- **意図の解読を先に行う**: 数字を良い・悪いと判定する前に、経営陣がなぜそうしたかを
  事業の言葉で書く。
- **双方向で見る**: すべての構造要素を、上振れ機構と下振れ機構の両方で評価する。
- **効果で測る**: 希薄化・借入・リース・顧客集中・SBCは、存在ではなく1株当たり価値への
  純効果で判定する。

コンセンサス経路・会社シナリオ経路・事業エンジン経路を併置し、どれを採るかを明示的に
判断する。判断の軸(クラックス)は因果命題として立て、仮説思考で層ごとに検証する
(例: 「テクノロジープラットフォームは内製化しやすいか」→大型顧客なら内製化が経済的に
成立するが、決済インフラ・債権回収の自前構築は中小顧客にはコスト高で割に合わない、
という層別の検証)。

ゴールは「事業本体で理解し、構造で整理し、シナリオで検証し、市場との差分を価格に落とし、
パワポに直結する形で出力する」こと。すべての判定は「この結論を1枚のBCGスライド
(構造図)で図示できるか?」を自問しながら行う。図示できない判定は理解が浅い証拠であり、
追加調査に戻る。

## 全体ワークフロー

```
Phase 0: ゲート審査(即時失格チェック) → 失格なら短報告で終了
   ↓
Phase 1: 基礎調査(research-protocol.md+市場の仮説の出典+根幹KPIの時系列+一次情報
   │  +損益の全項目+製品別の価格・品質+信用データ+PER参照クラス)
   ↓
Phase 1.3: 製品・サービスの5W1H台帳(L0)と損益フロー図(F19)【2026-10-12 新設】
   │  (product-and-pnl-flow.md §1・§2)
   ↓
Phase 1.5: 事業本体の把握【全Phaseの土台】(business-core-method.md §3〜§4)
   │  原子単位とエンジン式(報告売上±5%で照合)→価値の起点→ユニットエコノミクスと
   │  増収の源泉分解→自己強化ループと制約→需要の連鎖→資本の出し手と資産の生産性→
   │  時間構造と定常状態利益→持続性と競争優位期間→成長余地→変化の検出(加速度)→
   │  市場の仮説の特定と差分の初期仮説。機構台帳(business-core-method.md §7)を起票
   │  →【1周目の終わりに】価値感度分析で芯(上位1〜3変数)を特定(§3A)
   │  →【2周目】調査資源の過半を芯に投じ、市場が暗に置く値・自分の見積り・優位の種類を確定
   ↓
Phase 2: 利益の質の構造分析(機構台帳→数字への波及マップ)
   ↓
Phase 2.5: 現状の収益構造の解剖と鳥の目マップ(F1/F2/F9/F10+品質監査ループ)
   ↓
Phase 2.7: 経営陣シナリオの特定と分解(ピースを事業エンジンの変数に翻訳。
   │  主要ピースは1株当たり価値に試算: F22)+競合との品質×価格×バリューチェーン(F20)
   ↓
Phase 3: 13条件による深掘り判定ループ(事業本体ブリーフと整合させる)
   ↓
Phase 4: 構造化(アクター/フロー/リスク所在/時間)
   ↓
Phase 5: バリュエーション(前提の事前登録→事業実態EPS→3経路+弱気パス→PER参照クラスと
   │  理論式→PEG→年度別評価→SOTP→FCF・レバレッジ・倒産確率の経路(F21)→本源的価値。
   │  株価は最後に比較。CFは確認層、リスクは効果測定、二重計上の禁止)
   ↓
Phase 5.5: シナリオの採点と実現性(成立条件・根幹KPIの加速度・確度の更新値)
   ↓
Phase 6: 総合評価・最終判断(構造評価 × 価格乖離 × 市場との差分)
   │  + エントリー価格帯(3ゾーン)・時系列投資戦略(4フェーズ)
   ↓
Phase 7: 報告書の出力(evidence台帳・機構台帳を内包。図表F1〜F22。品質ゲート付き)
```

## Phase 2.5: 現状の収益構造の解剖と鳥の目マップ

【2026-10-12 第2版で追加】設備先行型・高成長の事業は、`references/growth-and-capex-valuation.md` §1〜§4 に従い、
利益率を ① 現在 / ② 定常(コホート経済性)/ ③ 均衡に分け、ファイブフォースの数値表から定常利益率と CAP を導く。

`references/structure-map-method.md` に従い、「現状の事業構造理解→将来の事業構造→
現在地」の三段で銘柄をバリューチェーン全体像に位置づける。**「分析の中心は規模で
決める」**: 注目テーマ性の高いセグメントではなく、規模(売上・利益貢献)が最大の
事業から分析する。

- **収益・費用フロー解剖(F10)**: セグメントより細かい**収益ライン×費用ライン
  粒度**でカネの流れを解剖する。収益ミックスの時系列変化・営業レバレッジの分解
  (増収の何%が増益に落ちるか)を含む。**各収益ラインには顧客価値定義
  (誰に/何のために/どんな製品・サービスを/代替手段は何か)を必須で付す**
  (代替不可能性・必要性・景気感応度分析の出発点)。**低迷・急伸しているラインは
  数量×単価×ミックス+離脱・客層シフト・内製化/代替・需要量に要素分解する**
  (「市場が恐れている」で分析を止めない)
  - 【追加】**各収益ラインの増収を、新規獲得/既存顧客の拡張/離脱に分解する**
    (business-core-method.md §3 L2)。既存顧客の拡張による増収は追加の販促コストがほとんどかからない
    ため、ラインごとの限界利益率の推計に使う
  - 【追加】**フロー収益とストック収益を分け、転換係数を記す**(business-core-method.md §3 L6)
- **現在構造(F1)**: 業界バリューチェーン(L1)→銘柄のポジション(L2)→カネ・モノ・
  情報のフロー(L3、structure-thinking.mdと同一文法で記述。二重定義しない)の
  3レイヤー分解+利益プール分析(段階別マージン率×市場規模で利益の溜まり場所を判定し、
  銘柄が高プール段階にいるか低プール段階に閉じ込められているかを判定する)。
  【追加】フローの図には、business-core-method.md §3 L3の自己強化ループと制約(律速段階)を重ねる
- **将来構造(F2)**: 変化ドライバー(技術/規制/需要/供給)→利益プールの移動を予測
  (Phase 2の波及マップと整合必須)。F1と同一レイアウトの再掲オーバーレイとする
- **現在地(F9)**: 現在構造→将来構造への移行ステージ(3〜4段階、各ステージの判定基準は
  定量)を定義し、現在地を実測値とともに一文で宣言する。**ステージの軸は期間ではなく
  経営アクション・構造イベント**(買収統合/広宣費投下/新サービス/垂直統合/
  クロスセル立ち上がり/制約の解放等)で取り、**各ステージの所要時間を見積もる**
  (期間はアウトプット)。ステージごとに収益構造特性とPEG含意を付す。
  【追加】エンジンごとのS字カーブ上の位置(business-core-method.md §3 L6)と整合させる。
  次ステージへの移行条件は判別KPI(Phase 5.5)と共有できる場合は共有する
  (新規KPIを乱造しない)

**品質監査ループ(BCG級ゲート)**: F1/F2/F9/F10が完成したら3層ルーブリック(L1完全性/
L2密度・具体性/L3示唆性)でS/A/B/Cの4段階自己採点する。**B未満(C)は不合格**とし、
不足項目を調査項目に差し戻して再構築する(最大3周)。3周で未達の項目は「既知の制約」
として報告書に明記する。判定には冒頭の「この結論を1枚のBCGスライドで図示できるか」
テストを最終確認として接続する。

**差し戻し条件**: チェックリストが埋まらない、F2の構造変化がPhase 2の波及マップと
矛盾する、現在地宣言に実測値根拠がない、または品質監査ループでB未満のまま3周を
終える場合、いずれもPhase 1に戻り追加調査する(3周で未達の項目は既知の制約として
明記し先に進んでよい)。

## Phase 2.7: 経営陣シナリオの特定と分解

## Phase 3: 13条件による深掘り判定ループ

【第5版】成長企業(growth-stage-evaluation.md §0 の適用条件に当たる企業)は、Phase 3 の前に同ファイル §1〜§9
(フェーズの診断・二層の構造・KPI の読み方・EPS 分解・フライホイール・資本モデルの業界比較・マクロの両面・図の形・初歩の点検)を行い、
G1〜G8 の採点表を作り、各条件の判定で §11 の対応表を使う。「成長段階の弱さ」と「構造の弱さ」を
同じ C にしない(段階の弱さは監視 KPI に置く)。

条件1〜12を順に判定する。各条件はPhase 1.5の事業本体ブリーフとPhase 2の構造分析を
検証・深化するためのメソッドとして使う(条件判定が事業本体ブリーフ・波及マップと
矛盾したら、どちらかを再検証)。各条件で以下のループを回す:

```
1. condition-guide.md の判断軸に照らして仮判定(S〜F)
2. 追加調査トリガーに該当するか確認
   → 該当: 深掘り調査して再判定(1条件につき最大2周)
   → 非該当: 判定確定
3. 根拠一文+定量evidence(2〜4点)+出所を台帳に記録
4. C以下の判定には監視KPIとトリガー値を必ず定義
```

**判定の規律**:
- evidenceのない判定はしない。2周調査しても根拠が揃わなければ「評価保留(理由明記)」
- 願望で評価を上げない。**同様に、証拠なしに評価を下げない**。
  【変更】迷ったら評価を動かさず、判定の決め手になる証拠を特定して追加調査する。
  2周で決まらなければ評価保留とし、確認KPIと閾値を置く(business-core-method.md §2 A8)
- 判定間の整合を保つ(例: 条件2がSなのに条件11で「CFが弱い」と書く矛盾を許さない)
- 【追加】**CF・財務に関わる条件は確認層として判定する**: CFの弱さを見たら、まず
  事業上の理由(成長capex、Jカーブ、前払いの時期、外部化の設計)を特定し、その理由が
  1株当たり価値を増やすかどうかで判定する(business-core-method.md §5・§6)
- **「規模が小さいから」を理由に評価を対象外にしない**

## Phase 5: バリュエーション

【第4.5版】成長企業は、販促費の裁量部分を推計し、成長投資控除前 EPS を定常状態の価値と条件2 の判定に使う
