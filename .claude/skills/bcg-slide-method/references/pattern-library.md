## 2. 選び方の決定木

```
Q1 このスライドは何を証明するか
├ 構造・取引・資金の流れ(誰が誰に何を渡し、リスクは誰が持つか)
│    → 関係図 flowMap + mechPanel
│        期間の長さが論点か → 図の下に timeBand
│        評価が C 以下か   → 下端に kpiBand
├ 数値の推移・比較・構成(3 個以上)
│    → chartPanel(右に takeaway と小さな表)
│        推移 = 折れ線または縦棒 / 順位 = 横棒 / 構成 = 積み上げ(円は乱用しない)
├ 対象ごとの属性の比較、評価の一覧
│    → table + takeaway(8 行以内を目安。超えたら分割または付録)
├ 2 軸での位置づけ、判定規則の早見表        → matrix
├ 入力 → 処理 → 出力の計算、手順、ゲート    → flow(+ 下に table)
├ 先に見せたい主要数値が 2〜4 個            → kpiTiles + 下段に要約の行または table
├ 2 つの観点の対比(需要 | 供給、事実 | 示唆)→ 左右 2 分割(density-composition.md §3 C-1)
└ 章の切れ目 / 資料の入口 / 免責             → agenda / cover / closing
```

選んだら 3 つを確かめる。
1. その型は**タイトルを証明している**か(無関係な要素が入っていないか)。
2. 数値 3 個以上が**図になっている**か(文字の数字の並びになっていないか)。
3. 密度が足りるか(density-composition.md §1)。足りなければ複合構成にする。

## 3. 型ごとの規則

- 表: 先頭列は左寄せ、他は中央(`align` で変更可)。見出し行は濃緑に白字。行数は 8 以内。
- チャート: 系列は最大 4 本。単位・期間・出所を付ける。予測は薄色か枠線のみ。正負混在はゼロ線を引き、負を赤にする。
- 関係図: 箱は合計 10〜14(自社 3〜5、外部 3〜5)。レーンで領域を分け、左から右へお金・モノの順に並べる。矢印に数量、番号 ①〜 は右の仕組みと対応させる。箱の種類と線の種類は design-system.md §4・§5。
- コールアウト(takeaway・ブラケット)は 1 スライドに 2 個まで。
- 図表ゼロ(テキストだけ)のスライドは作らない。タイル 3 枚だけのスライドも作らない(総括や評価一覧に統合)。

## 4. 設計書への書き方

「本文の型」欄に `部品名 + 複合構成 + 理由` を 1 行で書く。

例: `flowMap + mechPanel + timeBand(C-4)。理由: 優位の期間が論点で、顧客・事業・壁・競合の関係を期間と合わせて示すため`

決定木が示す型と、報告書など入力側が候補に挙げた型が食い違うときは、決定木を優先し、相違の理由を設計書に書く。
