## 7. 示唆の層(§14)

- 市場は「Keytruda SCで年4,000億級のロイヤリティ」と見て2027E 41倍を払っている。だが事業の因果では、(1)料率は2%で最終値は売上$14B規模でも定常EPS約3,600(現値PER 66倍)、(2)それに至るまでの2026〜2028年のEPSは**有限の約$10億プール+新規契約の前払金**で、プールが尽きる2029年に「経常」へ切り替わる際に谷ができうる。(3)欧州9か国の販売制限でプール到達が後ろへずれる。
- 確認KPI(反証可能): ①2026年Q3決算(2026-11-12)の売上1,140億・EPS 968との差、②2026-11-19のドイツ控訴審、③MerckのQ3決算でQlex四半期売上が$0.9B超か、④Merckからの第2回販売マイルストーンの時期、⑤2%の一次確認(Merck 10-K/Q)。いずれも現値で3経路PEGが0.75に近づく材料ではなく、**エッジなし**。

import math
L = {5:"S",4:"A",3:"B",2:"C",1:"D",0:"E"}
def integrate(cur, fut, p, lead_ok):
    """p>=0.6 & 先行指標2Q以上道筋上 → 中間(端数は現在側)。0.4<=p<0.6 → 現在+上方の留保。p<0.4 → 現在。"""
    if cur is None: return None, False
    if p >= 0.6 and lead_ok:
        mid = (cur+fut)/2
        v = math.floor(mid) if fut >= cur else math.ceil(mid)   # 端数は現在側
        return v, False
    if 0.4 <= p < 0.6 and fut > cur: return cur, True
    return cur, False
def run(name, rows):

    for no, cur, fut, p, lead in rows:

        if v is not None:
