### 2.3 L2 エンジン式とユニットエコノミクス

- エンジン式: 売上 = 出荷枚数(12インチ換算) × 1枚当たり売上(ASP)。ASP = ノード・パッケージのミックスと値上げ。
- 出荷枚数(20-F、6-K): 2023年 12.00M、2024年 12.91M、2025年 15.02M、2026年は1〜3Q 12.99M + 4Q 推定 4.60M = 約 17.59M。年間の生産能力は 17M 枚超(2025年、20-F)。
- ASP(NT$/枚): 2023年 180千 → 2024年 224千 → 2025年 254千 → 3Q26 334千(前年同期比 +37.8%、米ドルでは $10.44千 / $8.10千 = +28.8%)。
- 1枚当たり(3Q26): 売上 NT$334千(約$10.4千)、粗利 NT$222千、営業利益 NT$196千。
- 増収の源泉(2026年、米ドル、推定): 出荷枚数 +17.1%、ASP +22.7% で売上 +44%。対数で分けると出荷 44% : 価格・ミックス 56%。2026年4Q のガイダンス中央($53.3B)÷出荷推定 4.60M = $11.59千/枚で、2026年平均より 16%高い。
- 資本の効率(NOPAT/純PP&E、税率17%): 2023年 25%、2024年 34%、2025年 43%、3Q26 の年率 64%。2023〜25年の ΔNOPAT/ΔPP&E は 134% だが、価格主導のマージン拡大を含むため安定した数字ではない(参考)。

### 2.4 L3 自己強化ループと制約

- ループ: 先端ノードの量産実績 → 顧客の設計採用(2〜3年前から) → 出荷増・単価増 → 営業CF → 設備投資と研究開発(2025年 研究開発は売上の 6.5%、NT$約2,460億、前年比 +20.7%) → 次ノード。顧客の増加が歩留まり学習曲線を速め、粗利率が上がる。
- 制約: ①EUV など装置の供給(会社は「装置は逼迫」と述べた、3Q26)、②電力・用地(AI データセンター側の電力は会社が米国で現地確認に人を送る)、③N2 の立ち上がり希薄化(2026年 2〜3pt)、④海外工場の希薄化(2026年約2pt → 数年内に 3〜4pt)、⑤先進パッケージの能力(CoWoS は 2026年末 月12万枚 → 2027年末 20万枚と外資は見る、二次)。
- 制約の解放時期: 台南の3nm新工場 2027年上期、追加の3nm工場 2028年上期、Arizona 2工場目 2027年3Q、熊本2工場目 2028年、A14 は 2028年量産(会社、3Q26)。

### 2.5 L4 需要の連鎖

AIデータセンター事業者の設備投資(2026年の大手4社計 約$725〜750B、2027年は Citi 予想で Alphabet/Amazon/Meta の3社だけで $801B、Moody's は 2027年に $1兆近く、いずれも二次)→ AI加速器・CPU・ネットワーク(NVIDIA、Broadcom、AMD、自社設計)→ TSMC のウエハーとパッケージ。代金を払うのは半導体設計会社で、その原資は事業者の設備投資。連鎖の弱い環は、事業者の資金調達(Citi は Alphabet/Amazon/Meta の3社が 2027〜28年にフリーCFがマイナスになると警告、二次)と電力。
消費者向け・価格に敏感な需要は弱いと会社自身が述べている(3Q26)。

### 2.7 L6 時間構造と定常状態利益

- 契約の期間: ウエハー発注は顧客の予測に基づき、take-or-pay 契約の証拠は無い。顧客との関与は2〜3年前から。仮受金 NT$1,899億が能力予約を示す。
- 定常状態利益: 2026年の売上水準(推定 $176B)で粗利率を会社の「サイクルを通じた下限 56%」、営業費用率 7.5%、税率 17.5% と置くと、EPS は NT$90.4(推定)。9%で資本化して NT$1,005 = 現在の株価(NT$2,420)の 42%。**成長の値段は株価の 58%**(§3-5 の分解)。
- 景気循環のデータ: 売上の最大の落ち込みは 2023年の -4.5%(NT$)、営業利益の山からの下落 -17.8%、EPS は 2022年 → 2023年で -14%。2022〜2025年の営業利益率の最低は 2023年の 42.6%。確認できた最低の粗利率は 2018年の 48.3%(20-F FY2018)で、2023年は 54.4%。在庫日数 82日(3Q26)、売掛金 28日。

## 6. 13条件(1条件ずつ)。点: S5 A4 B3 C2 D1 E0。条件4は対象外(TSM は NYSE の ADR で適格)

### 条件1 価格決定力・優位・成長(10年) → **S5**
- 価格決定力の実績: 売上/出荷枚数 2023年 NT$180千 → 2025年 254千 → 3Q26 334千(前年同期比 +37.8%、米ドルで +28.8%)。粗利率 54.4%(2023年) → 59.9%(2025年) → 66.4%(3Q26)。値上げ: 3nm の一部で 2026年下期に最大+15%(TrendForce、検索要約)。2027年は基本 5〜10%の引き上げを交渉との報道(Nikkei 2026-07-21、TSMC は確認せず)。
- Power: 規模、独占的資源(歩留まり学習)、切替コスト、ネットワーク(§2.8)の4つが強化中。
- 優位期間: 10年超(条件11)。市場シェア 72.5%(TrendForce 2Q26)、2位 Samsung 5.9%。
- 成長: 会社の 2024〜29年 売上 CAGR は 25%に近づく(2026-01)。ただし 2029年以降の成長は証拠が薄く、ここは成長の「水準」でなく「持続」を見て S。
- 反対側の見方(A): 価格上昇の一部は N3 から N2 へのミックスによる。純粋な値上げ幅は不明。それでも粗利率 +6.9pt(前年比)は価格・稼働率・コスト改善の合成で、競合がいない状態でしか起きない。S を維持。

### 条件2 コア事業のキャッシュフロー → **S5**
- 営業CF/設備投資 = 76%(2023年、最悪)、52%、56%、54%(2026年1〜3Q)。フリーCFは2023年も NT$2,922億でプラス。株式の発行なし、長期負債は 3Q26 に 8,184億へ減少(2024年末 9,584億)、純現金 約 3.2兆。
- 基準例(定常状態の FCF が成長投資の大半をまかなう)を満たす。第一段階 batch_23 は 2023年の FCF の薄さと2026年の設備投資 $60B を理由に A としたが、2023年も営業CFが設備投資の 1.3倍あり、2026年1〜3Q も 1.9倍で、証拠は S を支える。
- 将来(2029年): 基本の経路で設備投資 $85〜92B(売上の 33〜36%)でも、営業CF(純利益 約4.3兆+減価償却 約1.1兆、推定)は設備投資(約2.9兆)の約 1.8倍。

### 条件3 コア技術の転用と成果 → **S/A 4.5**
- AI加速器は 2025年の売上の高い10%台(会社)で、全社の増収の最大の寄与(会社)。HPC は 2025年の増収の 78%、3Q26 は売上の 68%。
- 留保(A 側): 転用の追加投資が小さいとは言えない(設備投資が売上の 35%)。転用というより需要側の移動であり、収益の多重性は小さい。S(成長の主因)と A(多重性)の中間 4.5。

### 条件5 CEOの信頼性と事業拡大の経歴 → **S5**
- §2.10 の経歴台帳と検査。成長事業(先端ノードの量産、HPC・AIの拡大)を自ら築いた経歴(技術開発 → 工場運営 → 事業開発 → CEO)。ガイダンスは売上 13/13、粗利率 13/13 で下限以上、EPS は 2018〜2025年に年率 24.7%で希薄化なし、配当は増額。
- 迷いの有無: 第一段階は経歴台帳なしで A(4.0〜4.5)。台帳と定量の検査で「公約の大半を達成」と「1株価値を増やした記録」を確認できたため S。ただし設備投資の効率(投資の伸びが売上の伸びを上回る年が続く)は検証待ちで、これが条件5 の下方の留保。
- 留保(監視): 年齢と任期(2027年)。後継の層(共同COO 2名)は厚い。海外工場の希薄化は顧客と政府の要請に応じた決定で、自ら開示している。

### 条件6 5年後EPS成長率で PEG<1(CAGR 30%以上) → **C2**
- 起点は今期(2026年)。2年(3年目が無い)。3経路: ①コンセンサス中央 26.8%(PEG 0.92 ADR / 0.82 台湾)、②会社 11.5%(PEG 2.15)、③エンジン基本 18.8%(3年、PEG 1.31)。
- 閾値(CAGR 30%以上かつ PEG<1)を満たす経路: ①の PEG は <1 だが CAGR が 30%に届かない(5社平均の高い側で 29.4%)。②③は CAGR で大きく未達。満たす経路は0。規則「どの経路も満たさない → C以下(満たさない幅で決める)」。最も近い①で -3pt(高い側 -0.6pt)の近接なので、C の中で上側(C2、D には落とさない)。
- 市場との乖離(A の要件)も満たさない: 1年ベースの PEG は TSM 0.73 / 市場(S&P 500、Zacks)1.16 = 0.63 倍(0.6 以下に届かない)、成長の倍率 33.6%/19.45% = 1.7倍(2倍に届かない)、同業の PEG 中央値以下は満たす。
- 第一段階 B3(CAGR 49.8%、PEG 0.44)は、2025年起点の2年に今期の+66%を含んでいた。

### 条件7 PEGが低い理由がリスクの過大評価であること → **C/B 2.5**(§7)
- 110番の比 r = 市場の織り込み ÷ 期待影響。ADR で r=1.20(境界、C の上端 B の下端)、台湾の株価で r=1.40(B)。決め手は g(2028年のコンセンサス)。g が 22.4%なら r=0.84、40.4%なら 1.82。2周調べても決まらなかったため、両側(C と B)の中央 2.5。

### 条件8 コモディティではない → **S/A 4.5**
- 先進ノード(売上の 79%)に代替が無く、価格は顧客の価値で決まり上昇中。束(ウエハー+パッケージ+設計環境 OIP+歩留まり)で競合に勝つ。成熟ノード(売上の 21%)は SMIC・UMC と競合する A/B の領域。加重で S と A の間(0.79×5 + 0.21×3.5 = 4.7 を 0.5 刻みで 4.5)。
- 第二の見方: 完全な代替不能(ASML の EUV)ではなく、Samsung/Intel が追う構造は変わり得る。

### 条件9 停めない運用に不可欠(AI関連のみ適用) → **S5**
- AI加速器の先端ノードと CoWoS の主たる製造元。会社: 「すべての AI プレーヤーが TSMC と組んでいる」「需要は供給能力を大きく上回る」(3Q26)。5倍レチクルの先端パッケージを量産しているのは TSMC のみ(会社発言)。代替の製造元に移るには設計の作り直しが2〜3年。

### 条件10 無形資産投資の陳腐化 → **A4**
- 研究開発は全額費用(2025年 売上の 6.5%)。のれん等は NT$250億で自己資本の 0.5%。貸借対照表上の陳腐化の対象が小さい。工程の知識は世代をまたいで蓄積(N7 が 8年後も売上の 10%)。ノードごとにIP・設計環境の再整備が要るため S ではなく A。

### 条件11 模倣困難・代替不可能 → **S5**
- 再現コストテスト: Intel は先端ロジックの外部顧客を大口で未確保(自社年次報告)。Samsung は 2Q26 のシェア 5.9%。SMIC は 5.4%。TSMC の設備投資は 1社で年 $60B超。十分な資金でも10年以上(Intel は10年以上かけ、なお外部顧客が無い)。

### 条件12 従量・継続課金の収益性格 → **B3**
- ウエハー単位の従量(出荷枚数 × 単価)で顧客の成長に乗るが、契約で縛られた継続課金ではない。前受金+仮受金は売上の 6.3%、take-or-pay の証拠なし。価格は景気後退期(2023年)にも崩れず、供給過多で崩れる型(VRT)ではない。B(反復購入はあるが契約で縛られない)。上方の留保: 長期契約と前受金が増える場合(確率 35%)。

### 条件13 アーキタイプ照合 → **A/B 3.5**
- MU/VRT/AVGO 型との比較: MU 型は景気循環で価格が崩れ陳腐化する設備に資本を投じる。TSMC は設備を自社で負う(設備投資が売上の 33〜35%、顧客資金は 2割弱)が、価格は 2023年も崩れず(粗利率 54.4%、営業利益率 42.6%)、設備の経済的寿命は会計の5年より長い兆候があり(N7 の継続稼働)、稼働率は逼迫。ORCL 型との差: 従量の契約性が薄く、陳腐化の負担が自社にある。
- 1点の大きな留保(自社が負う資本集約度)がある A と、それが小さくない B の中間 3.5。

構造平均(n=12): (5+5+4.5+5+2+2.5+4.5+5+4+5+3+3.5)/12 = **4.083**。

    res7[gname] = row

    if exp_impact < 0.15: return 3
    if r >= 1.5: return 4
    if r >= 1.2: return 3

    return 1
P['grade7'] = {g: {k: grade_from_r(v['r_mid'], P['risk_adj'][1]) for k, v in row.items()} for g, row in res7.items()}

scale = 1.0
for _ in range(200):

    risks[1] = (risks[1][0], tuple(min(x*scale, .8) for x in saved[1][1]), risks[1][2])
    risks[2] = (risks[2][0], tuple(min(x*scale, .8) for x in saved[2][1]), risks[2][2])

    if e < imp0: scale += 0.01

P['reverse_scale'] = scale

def avg(s7, s5=5, s6=2, s3=4.5):

scen_w = {'基本':.5, '強気':.25, '弱気(2023型の調整)':.25}

# SEC EDGAR の 6-K (決算ニュースリリース EX-99.1) から、実績とガイダンスを抜き出す。
# 入力: pr/<日付>_aXqYYe_withguidancexfinal.htm (curl -A "research <mail>" で取得済み)
import re, html, glob, json
def txt(f):
    t = open(f, errors='ignore').read()
    t = re.sub(r'<(script|style).*?</\1>', '', t, flags=re.S)
    t = re.sub(r'</(p|div|h\d|li|tr)>', '\n', t); t = re.sub(r'</t[dh]>', ' | ', t)
    t = re.sub(r'<[^>]+>', '', t); t = html.unescape(t)
    return re.sub(r'\s*\n\s*', ' ', re.sub(r'[ \t\xa0　]+', ' ', t))
rows = []
for f in sorted(glob.glob('pr/*withguidance*')):
    dt = f.split('/')[1][:10]; t = txt(f)
    q = re.search(r'for the (\w+) quarter ended (\w+ \d+, \d{4})', t)
    m_rev = re.search(r'In US dollars, \w+ quarter revenue was \$([\d.]+) billion', t)
    gm = re.search(r'Gross margin for the quarter was ([\d.]+)%, operating margin was ([\d.]+)%', t)
    eps = re.search(r'diluted earnings per share of NT\$([\d.]+)', t)
    g_rev = re.search(r'Revenue is expected to be between US\$([\d.]+) billion and US\$([\d.]+) billion', t)
    g_gm = re.search(r'[Gg]ross profit margin is expected to be between ([\d.]+)% and ([\d.]+)%', t)
    g_om = re.search(r'[Oo]perating profit margin is expected to be between ([\d.]+)% and ([\d.]+)%', t)
    rows.append((dt, q.group(1) + ' ' + q.group(2)[-4:] if q else None, m_rev.group(1) if m_rev else None,
                 gm.groups() if gm else None, eps.group(1) if eps else None,
                 g_rev.groups() if g_rev else None, g_gm.groups() if g_gm else None, g_om.groups() if g_om else None))
