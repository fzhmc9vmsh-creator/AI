### 2.3 L2 エンジン式とユニットエコノミクス(G1)

- 原子単位: **月次の稼働顧客**。エンジン式: managerial 売上 = 平均稼働顧客 × ARPAC(月次の稼働顧客当たり売上)× 3。
- 照合(2Q26): 稼働顧客 平均 114.4M(顧客 135.2M→138.9M × 稼働率 83.4〜83.5%)× ARPAC $17.1 × 3 = $5,867M、報告 $5,876M(**-0.1%**)。1Q26 -0.4%、4Q25 -0.4%(Q4'25 に managerial 導入。それ以前は IFRS 売上基準の ARPAC のため -2.5〜-3.6% 小さく出る。定義変更に注意)。±5% の合格基準を満たす。
- 稼働顧客当たり(年、2Q26): 粗利 $85、営業費 $28、税引前 $57(managerial)。マーケティング費 $104M ÷ 純増 3.7M = 純増 1人当たり $28(総増を非開示のため目安)。税引前での回収は約 6か月。会社が開示する顧客1人当たりの提供費 $1.0/月(20-F: ブラジルでは顧客当たりの提供費と G&A が既存銀行より約 85% 低いと会社が推定)。
- コホート経済性(1Q26 説明資料): ブラジルのカード 平均 3か月、正味マージン 19.9%、ROAA 8.9%。ブラジルの無担保 平均 7か月、正味マージン 28.0%、ROAA 15.8%。メキシコのカード 平均 2か月、正味マージン 28.0%、ROAA 14.1%。**3つのコホートとも資本コストを上回る**(G1 良)。
- G2 獲得投資の裁量性: マーケティング費は売上の 1.8%(前年 1.4%)。SoFi(約 32%)と違い、EPS を販促費の出し入れで動かす型ではない(成長投資控除前 EPS の補正は不要。補正は +0)。

### 2.4 増収の源泉(L2)
2Q26 managerial 売上 FXN +39% = 顧客 +13%(稼働顧客 +14% 前後)× ARPAC +22%(FXN)。報告ベース(米ドル)では ARPAC +37%(BRL 高が +11.8% の寄与、2Q25 平均 5.658 → 2Q26 平均 5.059)。**増収の約 36% は顧客の増加、約 64% は顧客当たり収益(既存顧客の拡張・商品の深化・金利と限度額)**(対数で ln1.13 : ln1.22)。既存顧客の拡張は追加の獲得費がほぼ無く、限界利益が高い。

### 2.5 L3 自己強化ループと制約
- ループ: 無料の口座・カード(顧客 1.39億人)→ 低い提供費(効率比率 19.5%、既存銀行より大幅に低い)→ 低い預金コスト(CDI の 88%)と高い稼働(月次稼働率 83.5%、ブラジル 86%超)→ 取引データ(NuFormer、基盤モデルがブラジルのカード・無担保、メキシコのカードで稼働)→ 与信の精度(会社: 主口座化した顧客の延滞は平均の約半分、所得帯ごとの 90日超延滞は 2025-07 以降改善、一方で同業の所得帯は悪化)→ 限度額の拡大・商品の追加 → ARPAC の上昇 → 顧客の増加(推奨・ブランド)。
  - 定量の証拠が弱いリンク: 「データ → 貸倒の優位」。同業比の純償却率の比較が取れていない(§12.1)。会社の主張(所得帯ごと)は仮説として扱う。
- 制約(律速): ①**信用の質とブラジル子会社の資本**(CET1 13.0% → 11.9% を半年で低下。最低 10.5% までの超過資本 $1.85B)。需要は律速でない。②顧客数の飽和(ブラジル成人 1.6億人強に対し 1.18億人)。純増は 2Q26 に 3.7M(前年同期 4.1M、-10%)。③メキシコは銀行化(2026-08-06)で預金・給与・貸出の制約が外れた直後。
- 解放時期: メキシコの給与振込・預金保険(2026年下期〜2027年)。ブラジルの CET1 は、利益の積み上げ(半年で +$0.44B)と RWA の増加(+$4.57B)の釣り合いで決まる。

### 2.6 L4 需要の連鎖と層
最終需要は家計の消費と所得(ブラジル家計の自由与信延滞率は BCB 系列 SGS 21112 で 2024-12 の 5.4% → 2025-12 の 7.06% → 2026-08 の 8.01% と上昇。過去最高、上昇の約半分は会計基準の変更と報道)。需要の層は、習慣的(月次稼働 83.5%)が中心で、契約済み(受注残)は無い。裁量的(カードの購入額 +16% FXN)が混じる。代金を払うのは顧客で、原資は賃金と家計信用(Desenrola 型の債務整理がある)。連鎖の弱い環は、ブラジルの雇用・賃金と金利。

### 2.8 L6 時間構造と定常状態利益、成長の値段
- 与信は数か月〜数年で回収されるフローで、顧客の関係(口座・主口座)がストックに近い。IFRS 9 の初日引当で、**与信の増加が先に費用になり、収益は後から来る**。このため 2026 年 1H の税引前利益率 20.9%(2025 年 24.5%)は成長の速さを反映した「Jカーブ」の側面があり、成長が鈍れば上がる(推定)。
- 定常状態利益(成長投資を止めた場合、推定): 与信の純増を止めると費用先行が解け、IFRS 税引前利益率は 2025 年の水準(24.5%)に戻ると置き、税率 25.8%、売上 2026 年 $22.6B なら EPS $0.84(22.58B × 24.5% × (1−25.8%) ÷ 4.906B)。税 12.5% のままなら約 $0.99。ここでは 2026 年 EPS 0.85 を定常の目安にし、**株主資本コスト 14% で資本化すると $6.07 = 株価の 41%**(税を 25.8% に直した EPS $0.72 なら $5.14 = 35%)。**成長の値段は株価の 59〜65%**(valuation-model §3-5)。
- 景気循環のデータ: 90日超 NPL の山は 2024 年 3Q の 7.0%(2Q26 6.9%)、15–90日 NPL の山は 2024年 1Q の 5.1%(2Q26 4.8%)。与信コスト/平均貸出は 2025年 3Q の 14.4% から 2026年 1Q の 20.5%(意図したリスク拡大)へ。営業利益の山からの下落は IFRS 税引前利益で -3.6pt の利益率低下(2025年 3Q 26.8% → 2026年 1Q 19.2%)があるが、絶対額は増加を続けた(通期の最大の落ち込みは無い)。

def ddm(g1, r=0.14, roe0=0.31, roe_T=0.20, g_T=0.05, yrs_fade=7, eps0=E26, n_fast=3):
    """EPS grows g1 for n_fast years, then g fades linearly to g_T over yrs_fade years; payout=1-g/ROE (ROE fades to roe_T). Value at t=0 per share."""
    eps = eps0; pv = 0.0; t = 0
    g_list = [g1]*n_fast + [g1 + (g_T-g1)*(i/(yrs_fade)) for i in range(1, yrs_fade+1)]
    for i, g in enumerate(g_list):
        t += 1
        eps_prev = eps; eps = eps*(1+g)
        roe = roe0 + (roe_T-roe0)*min(1.0, i/(len(g_list)-1))
        payout = max(0.0, 1 - g/roe)
        pv += eps*payout/(1+r)**t
    # terminal: Gordon on year-N EPS with g_T, payout 1-g_T/ROE_T
    N = len(g_list)
    tv = eps*(1+g_T)*(1-g_T/roe_T)/(r-g_T)
    pv += tv/(1+r)**N
    return pv
