**決め手**
1. 第一段階の PEG 0.57 は「前期実績 0.87 → 来期 1.77」の2年 CAGR 42.7% に、今期(FY2026)の跳ね(+56%)が含まれていた。今期の予想 EPS で測る PER(25.8倍)と同じ年度から測ると、コンセンサスの CAGR は 29.9〜30.3%、PEG は 0.85〜0.86 になる(SBC控除後なら 1.0〜1.14)。
2. 構造は、コア(CoStar 系・Apartments.com・LoopNet)は強いが、Homes.com への投資(2025年の純投資 8.5億ドル、累計およそ 30億ドル)と大型買収の資本配分(2025年 Matterport・Domain 計 38億ドル、売上の 8〜12倍、取得事業の税引前利回りは粗い推定で 2.6%)が条件5・10 を押し下げ、条件7 は「PEG が低い理由がリスクの過大評価」と言えるほど PEG が低くない。全条件を最も良く読んでも 4.14 で、4.0 を超えるには11条件のほぼすべてが上振れする必要がある。
3. Homes.com の販促は「攻め(裁量的で、実際に削減されている)」だが、単位経済(G1)は未達(経済的 LTV/CAC 0.15〜0.54、基準は 1.5 以上)で、損益分岐の道筋も、会社の計画(2029年末)に届く確率は節点ツリーで 6%(会社計画を取り込んだ強気シナリオ全体で 15%)、2031年末までで 42%。「成長段階の弱さ」として免責できる水準にない。

**再審査の条件(総合を動かす証拠)**: 株価が 30.5ドル以下(調整後の定義でコンセンサス CAGR のまま PEG 0.75)、またはコンセンサスの 2029年調整後 EPS が 3.30ドル以上(現在 2.98 の +11%)に上がる。構造は、Homes.com の純投資の四半期実績が会社計画の線(2026年Q4 の居住用調整後EBITDA 約1億ドル=ガイダンスからの逆算)に乗り、純新規受注(NNB)が前年並みに戻った場合に、条件5 と条件1 を1段上げる余地が出る。それでも平均は 3.8 前後で、4.0 には届かない。**2026-10-27 の決算は、構造の判定を変えるものではないが、これらの KPI の確認点になる。**

### L1 価値の起点・L2 増収の源泉
- **顧客が払う理由**: 商業不動産のブローカーは CoStar を使わないと取引の根拠(賃料・空室・売買事例)を欠く(基準データが業界の共通言語)。賃貸の管理会社は入居者の見込みを買う(PERQ の分析として、Apartments.com の見込み客は次点の競合の 2.5 倍の割合で成約。**会社が引用する第三者分析で、独立検証は未了**)。Homes.com のエージェントは自分の物件と顔を掲載する場を買う(会社は 10〜11 倍の ROI と説明、検証不能)。
- **増収の源泉(2026上期、売上 +20%、18.2億ドル)**: CFO は「増収の約半分が有機」と述べた(有機 約 +10%)。残りは Domain(2025年8月〜)。**下期の有機成長は 8.5〜9%**(上期より 1〜1.5pt 低い)と会社が言う。純新規受注(NNB)は 2025年 3.08億ドル(過去最高)、2026Q1 6,700万(+20%)、Q2 6,900万(**-26%**、前年同期 約 9,300万)。
- **限界利益率**: Q2 の増収 +144 に対し営業利益 +103(72%)。販売費は前年同期と同じ 395(増収に対し 0%)、一般管理費は -7%。2025年Q2 の営業損失 -27 が営業外の利息 +33・その他 +16 で黒字に見えていたが、2026Q2 の税引前利益 74 は全額が本業(営業外は -2)。
- ユニットエコノミクス: CoStar は更新率 93% の購読(収入の平均寿命 約 14年)。Apartments.com は月次更新率 99%(平均寿命 約 8年、年換算)。獲得費(CAC)は両事業とも未開示のため LTV/CAC は出せない(未取得)。Homes.com は 4章で計算する。

### L3 ループと制約
- ループ: ① CoStar の調査データ → 加入者 → 掲載の需要(LoopNet)→ 掲載が CoStar のデータを厚くする(CoStar 加入者 +19%、LoopNet の有料掲載 +9%。定量の証拠あり)。② Apartments.com は 物件 → 見込み客 → 更新(物件 +12%、更新 99%)。③ **Homes.com → 消費者の集客 → エージェントの会員 → 掲載物件 → 集客** は、集客側の証拠が弱い(Comscore で Homes.com の訪問は主要ポータルの約 5% と Realtor.com が主張。会社は Google Analytics で「Homes.com ネットワーク 1.08億/月」と言うが、これは Apartments.com と Land を含む数字)。**証拠のないリンクは仮説として扱う。**
- 現在の制約(律速): ① Apartments.com は需要側(空室が高く、管理会社が価格に敏感、競合が値引き)。② Homes.com は 営業の生産性(インサイド営業 660人 → 約400人に削減、1人当たり生産性 +19〜20%、フィールド営業 50人へ)と集客。③ 資本は律速ではない(自己資金で賄い、現金 12.7億ドル→Zonda後は純負債 約4.4億ドル)。解放の時期: フィールド営業の全国展開に「数年」(CEO)。

### L4 需要の連鎖と層
最終需要の資金: 商業不動産の取引量(2025年 +23%、データセンター需要を含む。出所: Motley Fool 2026-02)、賃貸の空室と譲歩(現在は高め)、住宅の取引(30年住宅ローン金利 7.49%、HousingWire 2026-08)。層: 契約済み・習慣的(購読 93%、1年契約 72%)が大半で、裁量的な取引型は Domain・Ten-X・Matterport 機材。景気感応度: 上は取引量の回復(CoStar・LoopNet・Homes.com)、下は商業不動産の縮小(購読者の減)と賃貸の供給過剰(Apartments.com の単価)。

### L5 資本と資産
- **出し手マップ**: 株主(2017年に 260ドルで公募、手取り 8.34億ドル。その後の資本調達の累計は未確認)、社債 10億ドル(2.8%、2030年7月満期)、顧客の前受 2.33億ドル、2025年に現金 約47億ドルのうち 28億ドルを買収に使用。2026年は自社株買い 7億ドル計画、Zonda 8億ドル。
- **経済的耐用年数と会計の差**: 買収の無形資産(のれん 49.8億+無形 16.7億 = 66.5億ドル、自己資本の 84%。Zonda 後は約 74億)は 2026〜2030 に 252・219・193・179・147百万ドル償却。顧客の平均寿命(全社更新率 89% なら約9年)と償却期間(技術・データ 8年等)はおおむね整合し、**会計と経済の差は大きくない**(上にも下にも)。自前で築いたデータ(38年、研究員 1,500人超)は費用処理で帳簿に無く、会計は過小。
- **ROIC**: 直近12か月の投下資本 76.6億ドル(自己資本 79.3+負債 10.0-現金 12.7)に対し、(調整後EBITDA 607 - SBC 192 - 減価償却 56)×(1-26%)= 268 → **3.5%**。Homes.com の純投資(直近12か月 約7.6億ドル、推定)を除くと **10.8%**。コアの有機部分は高く、買収で膨らんだ資本が平均を下げている。
- 買収の取得対価と売上倍率: Matterport 19.3億ドル(11.7倍)、Domain 19.1億ドル(8.4倍)、Visual Lease 2.8億(7.9倍)、OnTheMarket 1.2億(3.0倍)、Zonda 8.0億(4.7倍、調整後EBITDA 20倍)。**Matterport と Domain の調整後EBITDA(推定: Domain 38%、Matterport 8%)は年約 1.0億ドルで、対価 38.4億ドルの 2.6%**(税引前、現金の運用利回り 4%超より低い)。この見積もりは推定で、確認できる開示は無い。反例として Apartments.com(2014年に取得、のれん 4.2億、2014年4〜12月の売上 76.8百万 → 2025年は約 11.7億ドルと推定)は高い収益を生んだ。

### L6 時間構造と定常状態利益
- **定常状態**(Homes.com の純投資が 85% 消えると置く。推定): 調整後EBITDA 1,268(= 800 + 550×0.85)、SBC 156・減価償却 77 を引いた税引後利益 766、1株 1.89ドル(SBC控除後)。株価 35.02 は定常状態利益の **18.5倍**。EV 146億ドル(時価総額 142億+純負債 4.4億、Zonda 後の推定)は定常状態EBITDA の 11.5倍、2026年の調整後EBITDA(814、Zonda 4か月込み)の 18.0倍。
- **成長の値段**: 定常状態(成長ゼロ、資本コスト 9%)の価値 85億ドル(EV の 58%)。差の 61億ドルが成長の値段。永続成長 3% を認めると定常価値は 128億ドル(EV の 87%)。すなわち市場は、**コアが3%成長するなら、残りの成長と Homes.com のオプションをほぼ無料で売っている**。ただし Homes.com の純投資が恒久的に続けば、この計算の前提(85% が消える)が崩れる。
- 価値の時間分布(基本シナリオ): 2030年末までの FCF の現在価値は EV の 14%、2031年以降(終価を含む)が 86%。遠い価値の比率が高く、その確度は Homes.com の損益分岐とコアの成長に依存する。

**1つに決める: 事業実態 EPS = 調整後 EPS から SBC の税引後を引いた値(FY2026 は 1.07ドル)。** 理由(スキル valuation-model §3-1「SBCの大きいソフト」、business-core §5-2・§5-3):
1. SBC は調整後税引前利益の **21%**(FY2025 は 39%)で「SBCの大きいソフト」に該当し、採用に使う本物の費用である。1株 0.285ドル。
2. 希薄化は株数に出ている(2024年 407 → 2025年 420.7[Matterport で 11.7百万株を発行]→ 2026Q2 404.4[自社株買い 7+13.75百万株で吸収])。SBC を費用に入れたので、希薄化を重ねて引かない(二重計上の禁止)。
3. **買収無形資産の償却は足し戻す**(会社と同じ)。対価はすでに支払われ、その採算は ROIC と条件5・10 で別に判定する。償却を引くと(GAAP)0.57 で、EPS の年次比較は償却の減少(2026 252 → 2030 147)で歪む。経済的な減耗と会計の差は小さい(L5)。
4. Homes.com の投資は足し戻さない(スキルの規則)。

**どちらの定義でも結論が変わらないか**: 8章の表。条件7 の等級は A(調整後)↔ C(SBC控除後)で動くが、構造平均は 3.68 と 3.50 で、**どちらも A+ に届かない。成長 A+ は両定義で 0 本。総合は不通過で同じ。** GAAP では PEG が上がる(エンジン基本で 3年 1.16)ため、さらに厳しくなる。

## 8. 規則の検査と判定

### 規則の検査
- E 以下の拒否権: 該当なし(最低点は条件7 の 2.0 で、条件7 の範囲の下端 D=1 でも E ではない)。
- C 以下(2.0 以下)の個数: **1**(条件7、SBC控除後)。4個以上で総合を B までとする規則は不発動。
- 条件6・7 の対評価: 条件7 が B 未満(C)なので、条件6 を S にしない。条件6 は B(3.0)のため抵触しない。
- 各 C の仕分け(growth-stage §11): 条件7 の C は「構造の弱さ」ではなく「PEG が低くない」ことによる。G1 未達・G2 攻めの Homes.com は、条件2・12・13 ではなく条件5・7・10 に反映済み。

### 構造 A+ の判定: 不通過
- 事業実態の定義: 平均 3.50、上方 3.59(区分「遠い」: 3.6 未満)。
- 調整後の定義: 平均 3.68、上方 3.77(区分「近い」: 3.6〜4.0)。
- A+(4.0 以上)は、どちらの定義でも、上方の留保込みでも届かない。

### 成長 A+ の判定: 不通過
3経路のうち PEG ≤ 0.75 を満たすのは 0 本(基本)。②は CAGR を満たすが PEG が 0.76〜0.87。①は CAGR が 30% 前後で PEG 0.85〜1.14。③基本は PEG 0.96〜1.02。
