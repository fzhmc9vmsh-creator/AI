## 6. 示唆の層(§14)

- 市場は「PUF・先端ノードで権利金が2026年下期から加速」と見て、2026E 79倍・2028E 35倍を払っている(2028年は1名の予想)。だが事業の因果では、2026年の伸びの主役は授権金(Q2は39.2%)で、権利金は上期+約10%(推)、Q2は前期比-6.4%。権利金が売上の約6割を占める以上、**2027年コンセンサス47.72元(売上+38%必要)の達成可否は権利金の加速にかかる**。
- 確認KPI(反証可能): ①2026年Q3決算(11月上旬、日付は未確認)で権利金が7.5億台湾ドル以上、②PUF比率が15%以上、③2027年コンセンサスが47.7元を維持、④TSMC 12吋滲透率の開示。①〜③が揃えば将来評価の確率は上がるが、現値でPEG 1.0(主定義)を割るには2028年EPSが約112元(現コンセンサスの1.4倍)必要で、この点は「エッジなし」。

def integrate(cur, fut, p, lead_ok):
    """p>=0.6 & 先行指標2Q以上道筋上 → 中間(端数は現在側)。0.4<=p<0.6 → 現在+上方の留保。p<0.4 → 現在。"""
    if cur is None: return None, False
    if p >= 0.6 and lead_ok:
        mid = (cur+fut)/2
        v = math.floor(mid) if fut >= cur else math.ceil(mid)   # 端数は現在側
        return v, False
    if 0.4 <= p < 0.6 and fut > cur: return cur, True
    return cur, False
def run(name, rows):
