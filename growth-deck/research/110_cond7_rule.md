# 条件7 の採点規則(改訂、ユーザー指示 2026-10-19)

## 経緯
A〜D班の早期判定(101〜104)と、それ以前の二次審査(81)では、条件7 に C 以下を付けた根拠が次のような形だった。
- 「実在するリスクだが、織り込みの定量は未了。迷ったため C」(TSMC)
- 「市場が誤りとは言えない」(NVIDIA、Broadcom)
- 「顧客集中の経済的影響を測れていない」(Credo)

つまり、弱気側の意見を数量化せずに、そのまま減点していた。Opus の指示書(100)にあった「迷ったら下の点を付ける」も、この偏りを強めた。

ユーザーの指示: **実在するリスクでも、影響度と確率を分析し、大きくなければクリアとする。**

## 採点の手順
1. **リスクの列挙**: 市場が安さの理由にしているリスクを、出典付きで挙げる(アナリストの弱気論、空売り報告、報道、株価の反応)。
   - **必ず「成長の未達」を1行目に入れる。** 低 PEG の多くは、市場がコンセンサスの EPS 経路そのものを疑っていることが理由である。
     コンセンサスが実現しない確率と、その場合の EPS 経路(事業エンジン経路の基本・弱気、過去の予想修正の実績、景気循環の山谷)を
     p と I に置く。これを抜くと、妥当 PER が高く出て r が機械的に大きくなる(第一段階 13・15班で、20社中15〜18社が A になった)。
2. **数量化**: リスクごとに次を出す。
   - p: 3〜5年のうちに起きる確率
   - I: 起きた場合の本源的価値への影響(%)。EPS の経路 × 倍率で計算する。
   - 重なるリスク(例: 設備投資の山と顧客集中)は、二重に数えないよう調整する。
   - 数値が一つに決まらない場合は、範囲で置いて中央値で判定する。「定量できない」を理由に減点しない。
3. **期待影響**: Σ(p × I)
4. **市場の織り込み**: 1 − 現在の PER ÷ リスクがない場合の妥当 PER。妥当 PER は、構造評価から決まる許容 PEG × g で求める。
5. **判定**(織り込みと期待影響の比 r = 織り込み ÷ 期待影響 を主軸にする)
   | 条件 | 評価 |
   |---|---|
   | 構造的に市場が正しい(自社が負う陳腐化設備投資、供給過多) | E(既存の規則どおり) |
   | r ≥1.5、かつ見落としを確認できる KPI と時期がある | S |
   | r ≥1.5 | A |
   | 1.2 ≤ r <1.5 | B |
   | 0.8 ≤ r <1.2(市場の織り込みが見合っている) | C |
   | r <0.8(市場の織り込みが足りない) | D |
   | 期待影響が 15%未満で、致命リスク(単独で p ≥25% かつ I ≥50%)がない | 上の結果が C・D でも **B(クリア)** に引き上げる |
6. **記録**: リスクごとに p、I、出所、計算式を表にして残す。

## 第5.2版の規則との関係
condition-guide 条件7 の第5版・第5.2版の追記(「市場が織り込むリスクの量を測る」「『実在のリスクとして残る』だけでは判定にしない」)を、数値の閾値付きで運用するもの。条件6・7 の対評価(条件7 が B 未満なら条件6 を S にしない)はそのまま残す。

## 改訂履歴
- 2026-10-19 初版: 期待影響の絶対値だけで C・D を決め、市場の織り込みとの比較を 15〜25% の帯でしか見ていなかった。
  このため、織り込みが期待影響の 1.6倍あるブロードリーフが D になった。条件7の本旨(安さはリスクの過大評価か)とも、
  スキル第5版の「織り込みが経済的影響を明確に上回れば B 以上」とも矛盾していたため、Opus が比 r を主軸に改めた(同日)。
- 2026-10-21: 第一段階で条件7 が A に偏った(低 PER の会社で r が機械的に大きくなる)。原因は、市場が疑っている「コンセンサスの成長そのもの」を
  リスク表に入れていなかったこと。1行目に「成長の未達」を必ず置く規則を追加した(Opus)。
