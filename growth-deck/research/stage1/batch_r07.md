## 結論

- **「深掘り」は 0 社。** 20社すべてが構造平均 3.45 未満(最高は BIRK 2.95、次いで 6715.HK・2192.HK 2.77)。

- **この班の入口(ふるい直し)に通貨の混在の誤りがあった。** 粗いふるいは info 欄の epsForward ÷ epsCurrentYear を使うが、epsForward は株価通貨(HKD・USD)に換算済み、epsCurrentYear は決算通貨(CNY・EUR・CHF)のままである。このため決算通貨が株価通貨と違う会社の伸びが水増しされた。通貨をそろえた earnings_estimate(0y→+1y)で測り直すと、6715.HK は +43.2% → +21.9%、6881.HK は +25.8% → +7.1%、1361.HK は +28.6% → +9.5%、BIRK は +39.6% → +24.2%、ONON は +44.4% → +19.0%、2192.HK は +30.6% → +11.2% で、**6社とも25%未満**になった。これらは構造を問うまでもなく成長が不通過で、ふるい直しの他の班(HK・欧州・スイスの銘柄)にも同じ混入があるはず。Opus に確認を勧める。

## 方法の注記(全社共通)

- **点**: S5 A4 B3 C2 D1 E0。条件4は対象外、条件9は AI 関連のみで本班は全社 N/A。avg は 11条件(1・2・3・5・6・7・8・10・11・12・13)の平均。半点は中央の点(例: B/C=2.5)。
- **成長の測り方**: CAGR は今期(FY0、PER の分母と同じ年度)起点。earnings_estimate は今期(0y)と来期(+1y)しか無く、3年目が無いので、**FY0→FY1 の1年の伸びを consensus_cagr_pct、cagr_years=1** とした。PEG = 今期 PER(2026-10-23〜24 の終値 ÷ FY0 EPS)÷ その伸び(%)。株価は決算通貨に換算した(HKD→CNY は 7.848/6.680 の比、BIRK は USD/EUR 1.1234、ONON は USD/CHF 1.2131。いずれも yfinance 自身の換算比から逆算)。前期実績からの2年 CAGR は参考として各節に書いた。
- **FY0 の年度**: 12月期の会社は FY0=2026年12月期。BIRK=2026年9月期(未発表)、TRX=2026年8月期、PHR=2027年1月期。
- **成長の判定**: A+ = CAGR ≥31% かつ PEG ≤0.75。境界 = CAGR 25〜31% かつ PEG ≤1.0、または CAGR ≥31% で PEG 0.75〜1.0。不通過 = それ以外。本班の PEG 中央値は 0.45(20社)。
- **深掘りの基準(Opus)**: 構造平均 ≥3.45 かつ 今期起点のコンセンサス CAGR ≥25%(一過性を補正した後も)。
- **条件6**: CAGR ≥30% かつ PEG<1 で B(コンセンサス1経路のため A は付けない)。満たさなければ CAGR ≥22% で C、未満で D。一過性の費用で FY0 が谷になった DKNG・FLUT は補正後の伸びで採点し、機械値での点を avg_upper に出した。予想者の少なさ(VFF・CTEV・TRX は1名)は確信度の注記にとどめ、点は数字どおり。
- **条件7**: 110番の規則。許容PEG(条件6・7を除く9条件の平均 <3.0 は 0.8、3.0〜3.5 は 1.0、3.5超は 1.2)× g(コンセンサス CAGR と持続成長の小さい方)= 妥当PE。織り込み = 1 − PE0/妥当PE。期待影響 = Σp×I − 重なり調整。**リスク表の1行目は全社『成長の未達』**(I = 1 − 1/(1+コンセンサスの伸び))。r ≥1.5 → A、1.2〜1.5 → B、0.8〜1.2 → C、<0.8 → D。PE0 が妥当PE以上なら D。期待影響 15%未満かつ致命リスク(単独で p≥25% かつ I≥50%)なしなら B に引き上げ。p・I は採点者の推定(出所を各表に書いた)。S は確認 KPI が必要なため付けていない。
- **持続成長** = ROE(直近12か月 ROE と FY0 予想 EPS ÷ 1株純資産の平均)×(1 − 配当性向)。ROE が買収由来ののれんで薄まる会社(BIRK・FLUT)や、予想 EPS が調整後で簿価と基準が違う会社では、この規則が g を低く出す(結果は D になりやすい)。そのため旧規則の r を併記した。
- **将来の構造**: 3〜5年後を描いて現在との差を数字で示せたのは DKNG の条件3(予測市場の収益化)と BRSL の条件3(iLottery)だけで、実現確率 45%(40〜60% → 上方の留保のみ。現在の点は動かさない)。他は将来=現在、avg_upper = avg(DKNG・FLUT は条件6の機械値を加算)。
- **条件5**: 経歴台帳は第一段階では作らない。経歴を確認できない会社は B。
- **データの注意**: FY0・FY1 のコンセンサスは調整後(株式報酬・取得償却を除外する会社が多い)。FLUT の earnings_estimate の +1y(1.73ドル)は GAAP と調整後が混在して使えず、epsForward(6.962ドル)を FY1 の調整後とみなした。6715.HK の粗利率は yfinance の年次(1%)と TTM(71%)が食い違い、営業利益率を使った。
