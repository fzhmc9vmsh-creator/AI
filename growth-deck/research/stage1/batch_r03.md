# 第一段階の中立評価(ふるい直し): batch_r03(飲料・バイオ医薬・CDMO 20社)

作成: 2026-10-24 / 手順書: research/200_neutral_protocol.md、条件7: 110_cond7_rule.md、物差し: condition-guide・growth-stage-evaluation(§0〜§2、§10・§11)・valuation-model §3-3。
追加指示(Opus): 今期(FY0)起点の CAGR で成長を判定する(300_stage2_brief.md の6)。前期実績からの CAGR は参考として別に書く。深掘りへ進める基準は「構造平均 ≥3.45 かつ 今期起点のコンセンサス CAGR ≥25%」。

## 読み方と前提(先に)
- 点は S5 A4 B3 C2 D1 E0(半段あり)。avg は条件1・2・3・5・6・7・8・10・11・12・13 の11個の平均(条件4は手順書により対象外、条件9は AI 非関連で全社 N/A)。avg_upper は「上方の留保」(実現確率40〜60%の将来の改善)を認めた場合の平均。
- 統合の規則(§2): 実現確率60%以上かつ先行指標が道筋の上なら現在と将来の中間。40〜60%は現在の点のまま上方の留保。40%未満は現在の点。本班では中間に動かした条件はなく、上方の留保だけを付けた(表の「将来」「確率」列)。
- 構造の判定: A+(avg ≥4.0、かつ C以下が4個未満)/ 近い(3.6〜4.0、または avg_upper ≥4.0)/ 遠い。E の拒否権に該当する条件は無い。C以下(≤2)が4個以上の会社は「総合は B まで」(SUJA、ZJLD、Luzhu、Fennec)。
- 成長の判定(今期起点のコンセンサス経路のみ):
  - CAGR の起点は PER の分母と同じ今期(FY0)。PER0 = 現在株価 ÷ FY0 予想 EPS(HK 株は株価を HKD→CNY に換算してから割る。screener の PER は換算していなかった)。
  - 年数は FY0→FY0+3(終点に予想者が2名以上いる場合)、無ければ FY0→FY0+2、さらに無ければ FY0→FY0+1(1年)。各社の年数は cagr_years に記す。1年だけの値は「来期の跳ね」であり、継続的な成長の証拠としては弱い。
  - A+ = CAGR ≥31% かつ PEG ≤0.75 かつ PEG ≤同業の中央値。境界 = CAGR ≥25% かつ PEG ≤1.0(A+ 未満)。それ以外は不通過。PEG = PER0 ÷ CAGR。
  - 同業の PEG 中央値(screen/out/all_scored.csv、2026-10-19、予想 PER ÷ CAGR の旧基準): Biotechnology 0.92(21社)、Beverages-Non-Alcoholic 1.48(5社)。蒸留酒・ワイナリーは2社のため非アルコール飲料の値で代用。本班では PEG ≤0.75 の方が厳しく、中央値が効く会社は無い。
  - 予想者の少なさ(n=1〜2)は確信度の注記にとどめ、点は数字どおりに付けた(条件6も同じ)。
  - 谷の基準年: 前の山から測り直さない。山から山の比較(前期実績 → 来期、または2025実績 → 2028)は「参考」として別に書いた。
- コンセンサスの出所は2つ。(A) Yahoo(yfinance の earnings_estimate、2026-10-24。FY0 と FY1 のみ)。(B) Nasdaq/Zacks(api.nasdaq.com の earnings-forecast、2026-10-24。米国上場の11社のみ、FY0〜FY3)。両者は EPS の定義が違う会社がある(例: TVTX の FY0 は A が調整後 +1.67、B が -0.92)。複数年の CAGR は B の同一系列で測り、FY0 が負または定義が割れる会社(OMER、TVTX)は A の1年で測った。HK・上海の9社は A のみ。
- スクリーナーの値(screen/data/screener_quotes.csv)は古い。例: ARGX は今期 18.68 → 来期 35.59 だったが、現在は FY0 28.3(A)/29.1(B)で、来期成長は +17.8%(A)/ +27.8%(B)。9980、2269、1530 なども予想が変わっており、ふるい直しの基準(今期→来期 ≥25%)を現在の値では満たさない会社がある。本稿は現在の値で判定した。
- 条件7(110番の規則): 比 r = 市場の織り込み ÷ 期待影響。織り込み = 1 − PER0 ÷ 妥当PER。妥当PER = 許容PEG × g(g はコンセンサス CAGR を50%で頭打ち。頭打ちしない場合の r を併記)。許容PEG は valuation-model §3-3 の表(S 1.6〜2.0、A 1.3〜1.6、B 1.0〜1.3、C 0.8〜1.0)で、条件6・7を除く平均が帯の中のどこにあるかで決めた(帯 C [1.5,2.5)、B [2.5,3.5)、A [3.5,4.5)、S [4.5,5])。リスク表の1行目は全社「成長の未達」。リスク間の重なりは相関を見て、p・I を重ならない形で置いた。期待影響が15%未満で致命リスク(単独で p ≥25% かつ I ≥50%)が無ければ B 以上に引き上げた。
- 検索: Web 検索は約33回(上限40)。確認した決め手は各社の節に出所を書いた。確認できなかった事項は「(未確認)」「(一般知識)」と書き、点は中央の B(3)を使った。
- 本班の対象は「粗利率35%以上」でふるった318社のうちの20社で、条件4(日本株か米国株)は手順書どおり対象外にした(HK・上海の9社と、オランダ法人で米国上場の ARGX を含む)。
