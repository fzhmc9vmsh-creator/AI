# 第二段階(深掘り)指示書(Opus / 2026-10-21)

## 対象
第一段階(research/stage1/)で「深掘り」とした会社。構造が A+ か「近い」で、成長が A+ か境界の会社。
確定済みの対象: Nu Holdings(NU)、Alnylam(ALNY)、Eli Lilly(LLY)、TSMC(2330.TW / TSM)。残りの班で出た会社は追加する。

## 目的
楽観も悲観もせずに事業構造を徹底的に掘り、構造A+(13条件の平均 4.0以上と、規則の検査)と成長A+(3経路)を確定させる。
中立の規律は 200_neutral_protocol.md、条件7は 110_cond7_rule.md に従う。第一段階の採点は出発点であって、結論ではない。

## やること(1社1ファイル: research/3xx_deep_<ticker>.md)
1. **事業本体**(business-core-method.md の L1〜L9)
   - 原子単位とエンジン式、ユニットエコノミクス、増収の源泉
   - 自己強化ループと制約、需要の連鎖、資本の出し手、経済的耐用年数、定常状態利益、競争優位期間(CAP)
2. **価値感度分析**: 価値を最も動かす変数(芯)を特定する。
3. **成長フェーズと二層の構造**(growth-stage-evaluation §1・§2・§10〜§12)
   - 現在と 3〜5年後の構造、実現確率の節点ツリー
4. **13条件**: 1条件ずつ、現在/将来/実現確率/統合で採点する。根拠は一次資料(10-K・20-F・決算説明・会社発表)で確かめる。
   - 条件5 は経歴台帳(condition-guide 条件5 の手順)を作ってから採点する。
   - 条件6 はスキルの規則どおり(閾値で B、市場との乖離を 2経路で満たせば A、3経路と条件7 ≥B で S)。
   - 条件7 は 110番の規則で、リスク表(p、I、出所)と比 r を出す。
5. **事業実態 EPS の定義**を確定してから 3経路を出す。
   - GAAP・調整後・株式報酬の扱いを並べ、スキル(product-and-pnl-flow、valuation-model)の事業実態 EPS の定義で1つに決める。
   - どちらの定義でも結論が変わらないかを示す。
6. **成長A+ の3経路**
   - **CAGR の起点は PER の分母と同じ年度にそろえる。** PER を今期(FY0)予想 EPS で測るなら、CAGR も FY0 → FY0+3(無ければ +2)で測る。
     第一段階は「前期実績 → 来期」の2年 CAGR を今期 PER と組み合わせており、今期の跳ねを成長と PER の両方に数える分だけ PEG が低く出ていた。
     参考として、12か月先(NTM)EPS を起点にした値も併記する。
   - ① コンセンサス(2出所以上、今期起点の3年。無ければ2年と明記)
   - ② 会社シナリオ(中期目標・ガイダンスを事業エンジンの変数に翻訳)
   - ③ 事業エンジン(基本シナリオ。強気・弱気は感度として別記)
   - 各経路で CAGR ≥31%、PEG ≤0.75、同業 PEG 中央値以下を判定する(同業は5社以上で表に出す)。
7. **規則の検査と判定**
   - 構造A+(通過/不通過、平均、規則の発動)
   - 成長A+(3経路それぞれ)
   - 総合(通過/不通過/保留と、保留の決め手)
8. 計算は Python で行い、コードをファイル末尾に貼る。数値には出所と日付を付ける。推定は推定と明記する。

## Opus の確認
提出後、Opus が採点を1条件ずつ確かめ、偏り(弱気・強気どちらも)があれば差し戻す。通過社が出れば、順位付けとフル分析(1位を厚く)に進む。
