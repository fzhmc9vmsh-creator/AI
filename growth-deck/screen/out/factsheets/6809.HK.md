## 事業の説明(yfinance)

Montage Technology Co., Ltd., an integrated circuit (IC) design company, provides IC-based solutions for cloud computing and AI infrastructure in the People's Republic of China. The company provides components for memory modules, such as multiplexed rank registering clock driver, multiplexed rank data buffer, registering clock driver, data buffer, clock driver, SPD EEPROM with hub, temperature sensor, and power management IC, as well as server and client memory module products. It also offers DDR5 PMIC, SPD Hub, and TS; PCIe retimers; CXL Memory eXpander Controller, a Type 3 Compute Express Link DRAM memory controller; clock chips; and Jintide server platform. Montage Technology Co., Ltd. was founded in 2004 and is based in Shanghai, the People's Republic of China.
