# せどり利益計算機

仕入れ値・販売予定価格・商品のサイズカテゴリーを入力するだけで、**販売プラットフォームごとの利益/損失を一括比較**できるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます(インストール・サーバー不要)。

1. **仕入れ値** を入力
2. **販売予定価格** を入力
3. **サイズカテゴリー** を選択(サイズから送料を自動推定)
4. 必要なら **その他経費**(梱包材・交通費など)を入力

→ メルカリ / 楽天ラクマ / ヤフオク! / Yahoo!フリマ / Amazon の利益・利益率・損益分岐価格が即座に表示され、最も有利なプラットフォームがハイライトされます。

## サイズカテゴリー

| カテゴリー | 目安 |
|---|---|
| 小型 | 厚さ3cm以内・A4まで(本・小物・カード類) |
| コンパクト | 厚さ7cm程度の小箱(化粧品・小型ガジェット) |
| 60サイズ | 3辺合計60cm以内(小型家電・おもちゃ) |
| 80サイズ | 3辺合計80cm以内(靴・小型調理家電) |
| 100サイズ | 3辺合計100cm以内(炊飯器など) |
| 120サイズ | 3辺合計120cm以内(掃除機・プリンター) |
| 160サイズ | 3辺合計160cm以内(大型家電) |

## 🔍 AI相場検索(Claude API連携)

商品名・容量・型番を入力して「相場を調べる」を押すと、Claude(`claude-opus-4-8`)がWeb検索ツールでメルカリのSOLD価格やヤフオク落札相場を調査し、以下を自動で行います。

- **相場の推定**: 下限 / 中央値 / 上限を表示し、中央値を販売予定価格に自動反映(チップのクリックで切り替え可能)
- **サイズカテゴリーの推定**: 商品の一般的な梱包サイズから7カテゴリーのいずれかを自動選択
- **相場サマリーと信頼度**の表示

### 利用に必要なもの

[Claude Platform](https://platform.claude.com/) で発行した **Anthropic APIキー**(従量課金)。アプリ内の「🔑 Claude APIキーの設定」に入力すると、ブラウザの localStorage に保存されます。

> 🔒 キーはこの端末のブラウザにのみ保存され、Anthropic APIへ直接送信されます(中間サーバーなし)。共有PCでは使用後に「キーを削除」を押してください。ブラウザから直接利用するAPIキーであるため、専用のワークスペースで使用上限(Spend Limit)を設定したキーの利用を推奨します。

## 手数料・送料のカスタマイズ

「⚙️ 手数料・送料の設定」を開くと、プラットフォームごとに以下を自由に変更できます。

- 販売手数料率(%)
- 固定手数料(円)
- サイズカテゴリー別の送料(円)
- 比較に含めるかどうかのON/OFF

設定はブラウザの localStorage に自動保存されます。「初期値に戻す」ボタンでリセットできます。

## 計算式

```
販売手数料 = 販売価格 × 手数料率 + 固定手数料
利益       = 販売価格 − 仕入れ値 − 販売手数料 − 送料 − その他経費
利益率     = 利益 ÷ 販売価格
損益分岐価格 = (仕入れ値 + 固定手数料 + 送料 + その他経費) ÷ (1 − 手数料率)
```

> ⚠️ 初期値の手数料・送料はあくまで目安です。各プラットフォームの最新の料金体系を必ずご確認ください。
