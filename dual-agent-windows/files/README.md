# AI共同作業

Claude(責任者)とGoogle AI(調査担当)の協調環境です。

## パソコンで使う
デスクトップの「AI共同作業」をダブルクリックし、依頼を入力します。成果物は `final` フォルダに入ります。

## iPhoneで使う
iPhoneのClaudeアプリの「Code」から、パソコン上のセッションを開いて依頼を書きます。
作業はパソコン上で動くので、パソコンの電源とClaudeデスクトップアプリを起動したままにしてください。
Google側(Antigravity/Gemini)はパソコン内で呼ばれるため、iPhoneには何も入れません。

## 安全のための決まり
APIキー・追加課金は使いません。削除・送信・購入・投稿・公開は自動では行いません。
