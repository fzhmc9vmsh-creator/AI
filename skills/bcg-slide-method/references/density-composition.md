# 情報密度と複合構成(BCG級の「濃さ」の作り方)

**このファイルは品質の生命線。** BCG実物と素人スライドの最大の差は、色や整列ではなく
**情報密度と構成**にある。仕様(色hex・座標・pt)を完璧に守っても、要素が少なく
文字が薄いスライドは「きれいな幼稚園のお絵かき」にしかならない。
BCGスライドは1枚で議論が完結する**高密度の証拠パッケージ**である。

## 1. 密度の定量基準(実在BCG12枚の実測に基づく)

本編の分析スライド(表紙・章扉・依頼事項を除く)は、以下のレンジを目標にする:

| 指標 | 目標レンジ | 薄すぎ警報 | 過密警報 |
|---|---|---|---|
| 本文総文字量(メッセージ+ボディ+脚注) | 350〜900字 | 300字未満 | 1,100字超 |
| 情報単位数(ボックス/表の行/バッジ/バー/チップ) | 15〜60 | 10未満 | 80超 |
| 数値の個数(データポイント+ラベル) | 定量スライドで10〜40 | 5未満 | — |
| 階層の深さ(見出し→項目→詳細→注記) | 3〜4層 | 2層以下 | — |

- **薄すぎ警報が最頻の失敗**。1メッセージ+箇条書き4個+図形3個のスライドはBCG級では
  「未完成」。メッセージを支える証拠(数値・内訳・理由・注釈)を3〜4層まで掘って載せる
- **1情報単位の定義**: 独立して読める1つの数字・ラベル・短句(箇条書き1項目=1、
  表のセル1つ=1、「結論(理由)」形式のセル=1、バーの1セグメント=1、バッジ=1)
- 対象外(薄くてよい): 表紙・章扉・エグゼクティブサマリー・依頼事項・
  P-13使用スライド(単一キーナンバー訴求は意図的な低密度)

## 1.5 視覚エンコーディング義務(最重要の失敗防止)

実際の失敗例の解剖から: 配色・フォント・文字量が仕様通りでも、**数値をテキストボックスに
「書いた」だけでチャートを1つも「描いていない」**資料はBCG級に見えない。

1. **メッセージが直接指す数値比較・構成・推移(数値3個以上)は、必ず比例描画する**
   (バーの長さ・面積が値に比例する図形を描く)。数字入りの箱を並べるのは表であって
   チャートではない。※ヘッダーファクト表(R5/C-5の基本属性行)や属性表(P-17)の
   数値は「参照情報」であり比例描画の対象外
2. 本編の定量スライドには**最低1つの比例描画チャート**(棒/積み上げ/ウォーターフォール/
   折れ線/マップ上の配置)を置く。全編がテキスト+矢印だけの資料は監査で差し戻し
3. **1テキスト単位は原則30字以内**。60字を超える文章ボックス(メッセージライン・
   示唆カラム・コールアウト帯を除く)は、箇条書き分解・表化・図解化のいずれかで解体する
4. 表(グリッド)も視覚要素である。行グループ帯・背景色・ブラケットを備えた本格的な表を
   恐れず使う(R7)。「箇条書きを2列に並べたもの」は表ではない

## 2. 密度の上げ方(正しい順序)

密度は「文字を増やす」のではなく「**証拠の階層を増やす**」ことで上げる。
§1の目標レンジ下限に達した時点で追加を止めてよい(過密警報に近づけるのが目的ではない)。順に:

1. **セルや項目に理由を付ける**: 「必要」→「必要(取引データの秘密保持と改ざん防止のため)」
   ※R2/P-2型(アイコンのみのセル)は対象外 — その型の密度は示唆カラム・ファクト行等の
   他要素で稼ぐ
2. **数値ラベルを全打ちする**: バー・セグメントすべてに%や実額を直接記す(凡例任せにしない)
3. **ファクト行を足す**: 比較対象の基本属性(名称・日付・金額・コード等)を表頭に3〜5行並べる
4. **番号ストーリー注釈を足す**: 図中の要所に①②…を置き、側の解説列で各2〜3行説明する
5. **示唆カラムを足す**(§3)
6. **脚注・出所を本物にする**: 定義脚注+出所(複数可、URL・時点付き)で最下部を埋める

やってはいけない密度の上げ方: 同じ内容の言い換えで文字数を稼ぐ/フォントを小さくして
余った所に別メッセージの内容を足す/装飾図形を足す。

**文字の書法**(密度と可読性の両立): ボディ内は体言・短句(1項目12〜30字)。
「です・ます」をボディに書かない。セルは「結論(理由)」形式。これにより
同じ面積に2倍の情報が入る。

## 3. 複合構成5型(C-1〜C-5)

BCG実物は単一の図ではなく、**複数パネルの組み合わせ**で1枚を構成する。
Phase 2で表現パターン(P-x)を選んだ後、必ず「どの複合構成を併用するか」を決める。
併用は1スライド原則2つまで(例: C-5+C-1。過密警報を超えない範囲で)。

### C-1 事実+示唆の分離(右側示唆カラム)
- ボディを左右に分割: 左(幅24.47cm)=事実・分析(図表)、右(幅6.5cm)=示唆・解釈
  (24.47+0.5+6.5=31.47cm=コンテンツ幅)
- 示唆カラムは「•」箇条書き2〜4個、各30〜60字。「〜と推察される」「〜が示唆される」
  「〜が重要」等、事実と区別できる言い回しにする
- 左右の間に小さな緑の連結マーク(▶や円矢印)を置いてもよい
- 使いどき: データ比較・実態調査系のスライドすべてで第一候補

### C-2 コールアウト帯(結論の帯・吹き出し)
- 高密度の表やマップの右端(幅4.5〜6cm)に、縦長の緑帯(GREEN_LIGHT塗り+GREEN枠)を置き、
  「この表から言えること」を50〜80字で書く
- 図中版: 特定領域に矢印付き吹き出し(白地+GREEN枠)で20〜40字の解釈を添える
- 使いどき: 表が主役でメッセージの補強が1点に絞れるとき

### C-3 3パネル構成(現象→メカニズム→論点)
- ボディを3縦パネルに分割: 有効幅30.47cm(=31.47−ガター0.5×2)を左:中:右=
  47:28:25で配分 → 標準は 14.32cm+8.53cm+7.62cm(比率は内容に応じ調整可、
  合計が30.47cmになるよう必ず検算)
- 左: 全体像の図(2軸マップ・フロー等)/中: 鍵となる概念の分解(「①大規模な技術実証
  ②構造的リスクの緩和」のような番号ブロック)/右: 検討の視点(A/B/Cラベルの問いボックス)
- パネル間は番号・文字ラベル(①②、A/B/C)で相互参照する
- 使いどき: 論点整理・フレームワーク提示・検討会の冒頭スライド

### C-4 フランキング構成(左右リスト+中央マップ)
- 中央に位置づけマップ(2軸)、左右に対応する具体リスト(基金名・施策名等のボックス列)を
  置き、破線矢印でマップ位置と接続する
- リストのボックスは高さ0.8cm程度で7〜10個並べてよい(旗・小アイコン可)
- 使いどき: 「全体地図と個別プレイヤーの対応」を1枚で見せるとき

### C-5 ヘッダーファクト表+チャート小マルチ
- 上段: 比較対象をn列に並べ、基本属性(名称・コード・日付・金額等)を3〜5行の表で提示
- 下段: 同じn列の直下に、対象ごとの同型チャート(100%積み上げ棒等)を2段まで並べる
  (行ラベル「地域別内訳」「タイプ別内訳」を左端に)
- 列の縦ラインを表とチャートで完全に揃える(=読者は縦に1対象を読める)
- 使いどき: 3〜5対象の多面比較(定性属性+定量構成の両方があるとき)

## 4. 番号ストーリー注釈(全パターン共通の武器)

R1だけの技法ではない。**あらゆる図に適用してよい**:
- 図中の意思決定ポイント・注目点に番号バッジ(①〜⑧)を置く
- 図の下段または側面に「① 見出し(緑太字)+詳細2〜3行(黒)」の解説列を並べる
- 図とテキストの往復で、1枚に「3秒の全体理解」と「30秒の詳細検証」を同居させる
- 矢印だけで語れない因果・順序は、番号を振ってテキストで語る

## 5. データ→切り口の設計(どのデータをどの枠組みで処理するか)

「データがあるのにスライドが薄い」原因は、切り口(分析の軸)の設計不足。
Phase 1でメッセージを立てる前に、対象データを以下の標準軸に当てて**複数の切り口で
集計してから**、メッセージに効く切り口を選ぶ:

### 財務・投資分析データの標準切り口
| 切り口 | 見るもの | 典型パターン |
|---|---|---|
| 成長性 | 売上・利益・セグメント別CAGR、四半期トレンド | P-5/P-7 |
| 収益性の構造 | 粗利率→営業利益率のブリッジ、費目分解 | P-6/P-9 |
| 資本効率 | ROE/ROICの分解(デュポン)、投下資本の内訳 | P-9 |
| キャッシュと還元 | FCF、配当・自社株買い、投資配分 | P-6/P-5 |
| 構成比の変化 | セグメント/地域/顧客ミックスの時点間比較 | 100%積み上げ(C-5) |
| 相対比較 | 同業他社比(成長×利益率、バリュエーション) | P-8/P-2 |
| リスク | 感応度、シナリオ、リスク一覧 | R7型の表/P-3 |

### 切り口設計の規律
- 1スライドの切り口は1つ(成長の話と還元の話を1枚に混ぜない)
- **「絶対値+構成比+時点間変化」の3点セット**が揃うと密度と説得力が同時に上がる
  (例: 調達額の絶対値ファクト行+投資家構成比の積み上げ+前回発行との差)
- データにない切り口をでっち上げない。切り口候補を集計した結果メッセージ性が
  弱ければ、その切り口は捨てる(捨てた記録は設計書に残す)。メッセージ性の目安:
  差が2倍以上ある/傾向が反転している/読者の意思決定・懸念に直結する、のいずれか
- 比較対象は必ず入れる(単独の数字は評価不能。前年・計画・同業・他国のどれかと並べる)

## 6. 密度の自己検算(Phase 2設計書とPhase 4監査で使用)

設計書の各スライドについて以下を記入・検算する:

```
- 想定文字量: ___字(§1レンジ内か)
- 情報単位数: ___個(15〜60か)
- 複合構成: C-_(なし の場合、なしでメッセージが証明しきれる理由)
- 数値の個数: ___個
- 階層: メッセージ→[パネル見出し]→[項目]→[詳細/理由]→[脚注] の___層
```

**薄すぎ警報に該当したら、そのスライドは実装に進まず** §2の順序で証拠を掘り増すか、
隣接スライドと統合する。データが本当に無い場合のみ「情報の少なさを正直に見せる」
選択をし、設計書に明記する。
