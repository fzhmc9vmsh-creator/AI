# 長期保有13条件の判断ガイド(condition-guide.md)【復元版】

> 復元の出所: 13条件の文言と評価スケールは invest-consulting-deck/references/stock-analysis.md
> (同一フレームワークの資料化仕様)から原文どおり復元した。判断軸・評価目安・落とし穴は、
> 銘柄分析メソッドのSKILL.md本文と第II部(business-core-method.md)の原則に合わせて
> 再構成したものであり、原本の文言そのものではない。

## 0. 位置づけと共通規律

- 13条件は**分析を深く行うためのメソッド**であり、条件充足が目的ではない。
- 各条件の判定は、Phase 1.5の事業本体ブリーフ・機構台帳と整合させる。矛盾したら
  どちらかを再検証する。
- **双方向・効果測定・意図の解読**(business-core-method.md §1)を全条件に適用する。
  リスクの存在だけで評価を下げない。証拠なしに上げもしない。
- 迷ったら評価を動かさず、決め手の証拠を特定して追加調査する(最大2周)。決まらなければ
  「評価保留」とし、確認KPIと閾値を置く。
- C以下には監視KPIとトリガー値を必ず定義する。
- 「規模が小さいから」を理由に評価を対象外にしない。

## 1. 評価スケール: S〜F(7段階)

| 評価 | 意味 |
|---|---|
| S | 圧倒的充足。原型(ORCL型)と同等以上 |
| A | 充足。長期保有の根拠として十分 |
| B | 概ね充足。軽微な留保あり |
| C | 部分的充足。監視KPIとトリガー必須 |
| D | 不十分。構造的な弱さあり |
| E | 不充足。不合格原型(MU/VRT/AVGO型)に近い |
| F | 明確に失格。単独で投資見送り事由になる |

- 条件3: コア資産(技術・データ・顧客基盤・ノウハウ)が、新しい収益線に転用され成果が
  出始めているか(収益の多重性・オプション価値)
- 条件11: 既存の資産・関係が、顧客の業務に不可欠かつ模倣困難・代替不可能か
- 条件12: 収益が反復・積み上がり型(ストック・従量・継続課金)か、一回性・供給過多型か

## 3. 条件別の判断軸・評価目安・落とし穴

### 条件1 価格決定力・競争優位・成長性(10年)
- **判断軸:** 顧客価値と価格の差(未行使の価格決定力)、更新時単価÷初回単価、7 Powersの
  数と強さ、競争優位期間(CAP)、成長余地の天井と天井を上げる仕掛け。
- **評価目安:** S=値上げ・更新単価上昇の実績があり、Powerが2つ以上で強化中、CAP10年超の
  根拠がある。B=Powerはあるが強化の証拠が弱い。D以下=値下げ圧力、代替の台頭。
- **落とし穴:** 過去の高利益率をそのまま「価格決定力」とみなす。粗利率の低下を、需要の
  強さの裏返し(有料利用の急増など)か価格の弱さかを分けずに減点する。
- **追加調査トリガー:** 値上げの発表、競合の価格改定、解約率の変化、更新単価の開示変更。

### 条件2 コア事業の潤沢なキャッシュフロー
- **判断軸(確認層として):** コア事業単体の定常状態利益と営業CF。全社FCFが成長capexで
  マイナスでも、コア事業が潤沢に稼ぎ、成長capexが契約済み需要・前払い・高い増分ROICで
  裏付けられているなら減点しない(business-core-method.md §5・§6)。
- **評価目安:** S=コア事業の定常状態CFが成長投資の大半をまかなえる、または成長投資が
  顧客・パートナーの資本で裏付けられている。D以下=コア事業そのものの稼ぐ力が落ちている。
- **落とし穴:** 全社FCFの符号だけで判定する。前払い(顧客からの資金)を「質が悪い営業CF」
  とだけ読み、需要の強さの証拠を見落とす(逆に前払いの将来の履行コストも見る)。

### 条件3 コア技術・データの転用と成果
- **判断軸:** 既存資産→転用経路→新収益の変換フロー。転用先の収益が数字に出始めているか
  (根幹KPIの加速度)。追加投資の小ささ(収益の多重性)。
- **評価目安:** S=転用先の収益が全社成長の主要因になり始めている。C=転用の計画はあるが
  数字に出ていない(オプション価値として機構台帳に記録)。
- **落とし穴:** 「まだ小さいから」と評価対象外にする。逆に、発表だけで成果とみなす。

### 条件4 日本株か米国株
- ゲート条件。ADR・二重上場は本籍と主上場で判断が割れるためユーザーに確認する。

### 条件5 CEOの信頼性と事業拡大の経歴
- **判断軸:** 仕組みを作った実績(誰が・いつ設計したか)、ガイダンス達成率、言行一致、
  資本配分の効果採点、失敗の開示と修正の速さ、インセンティブの単位(business-core L9)。
- **評価目安:** S=過去の公約の大半を達成し、資本配分が1株価値を増やしてきた記録がある。
  D以下=公約の未達が続き、説明が変わる。
- **落とし穴:** 語りの上手さ、知名度、メディア露出で評価する。

### 条件6 5年後EPS成長率でPEG<1(EPS CAGR 30%以上)
- **判断軸:** 事業実態EPSの5年CAGRと、現在株価でのPEG(現在PER÷CAGR%)。コンセンサス・
  会社シナリオ・事業エンジンの3経路それぞれで計算する。
- **評価目安:** S=3経路すべてでCAGR30%以上かつPEG<1。B=事業エンジン経路でのみ満たす
  (市場との差分の候補)。D以下=どの経路でも満たさない。
- **落とし穴:** 調整後EPSや一時要因込みのEPSで計算する。EPSが事業実態を映さない業種で
  補正をかけない。条件7と切り離して評価する(必ず対で評価)。

### 条件7 PEGが低い理由がリスクの過大評価であること
- **判断軸:** 「なぜ安いのか」を市場の仮説として出典で特定し、business-core §4の
  見落とし原因(分類の誤り・会計の歪み・時間軸・平均値の罠・複雑性・小型株の無視・需給・
  片側の物語)のどれで説明できるかを判定する。陳腐化リスクを誰が負っているか
  (顧客の前払い・持込みで顧客負担か、自社負担か)を構造図で示す。
- **評価目安:** S=安い理由が見落としで説明でき、確認KPIと時期がある。E以下=安い理由が
  構造的(シクリカルな陳腐化capexを自社が負う、供給過多)で、市場が正しい。
- **落とし穴:** capex総額だけで「MU型」と判定する(何に投資しているか、陳腐化しやすい資産
  を誰が負担しているかを見ない)。逆に、安さを根拠なく「市場の誤り」と決めつける。

### 条件8 コモディティではない
- **判断軸:** 差別化レイヤーの積み上げとコモディティ層の対比。価格の決まり方(コスト積上げか
  価値基準か)。顧客が乗り換えたときの損失。
- **落とし穴:** 製品の技術的優位だけで判定し、顧客から見た代替可能性を見ない。

### 条件9 停めない運用に不可欠(AI関連企業のみ)
- **判断軸:** 顧客のAI稼働チェーンの中での位置。止まると何が壊れるか、顧客は何日で代替
  できるか。
- 非該当企業は対象外(N/A)とし、評価分布・全ルールのカウントから除外する。

### 条件10 無形資産投資の陳腐化リスク
- **判断軸:** 無形資産(ソフト・データ・顧客関係・ブランド)の世代交代マップ。耐用の長い
  資産と短い資産の比率。会計上の耐用年数と経済的耐用年数の差(両方向)。
- **落とし穴:** 陳腐化リスクだけを見て、長く稼ぐ資産(帳簿外の顧客基盤など)を見落とす。

### 条件11 模倣困難・代替不可能
- **判断軸:** 参入障壁の多層構造(電力/立地/規制/リードタイム/顧客データ/関係)。
  再現コストテスト(十分な資金を持つ競合が何年・いくらで再現できるか)。競合CEOの
  攻撃シナリオ(business-core L7)。
- **落とし穴:** 障壁を列挙するだけで、どれが律速的に効いているかを特定しない。

### 条件12 従量課金型の収益性格
- **判断軸:** 課金単位が顧客の成長に自動で乗るか。反復フローか一回性フローか。
  フロー→ストック転換の有無(不動産再生のマスターリース・運営受託なども含む)。
- **評価目安:** S=従量・継続課金が主で、顧客の利用拡大がそのまま売上になる。D以下=
  売り切りで、供給過多時に価格が崩れる。
- **落とし穴:** 「売り切り」に見える事業の中にあるストック化の仕組みを見落とす。

### 条件13 アーキタイプ照合
- ORCL型(従量課金・陳腐化リスクの顧客移転・代替不可能な運用基盤)⇔MU型(シクリカルな
  陳腐化capex)/VRT型(売り切り・供給過多)/AVGO型(コモディティ化)のスペクトル上に
  位置づける。business-core §8のビジネスモデル型(A〜G)もエンジンごとに併記する。

## 4. 条件判定と事業本体の整合チェック

- 条件2・7・10は、business-core §5(確認層)・§6(効果測定)の規則で判定しているか。
- 条件1・8・11は、L7の競争優位期間と矛盾していないか。
- 条件6の3経路の差が、business-core §4の市場との差分宣言と一致しているか。
