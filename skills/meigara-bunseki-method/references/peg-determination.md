# 妥当PEGの確定手続き(Phase 5)

本ファイルは**妥当PEGを1点で確定する手続き**と、**現在株価への忖度を構造的に
禁止する順序ゲート**を定める。PEGの中身(3経路のうち第3経路=相対優位スコアカード)は
`edge-generation.md` §3、EPSの作り方は `consensus-eps-protocol.md` を参照。

**この2つが本ファイルの存在理由である**:
1. **PEGはレンジではなく1点で出す**。そのために事業を分析している
2. **現在株価から逆算したPEGに、分析後のPEGを合わせにいってはならない**

---

## §1 実行順序(逆算防止ゲート)

Phase 5は順序が固定されている。**順序を守ること自体が方法論**であり、
入れ替えると分析が無意味になる。

```
① 正規化EPSとEPSパスを確定する
   (consensus-eps-protocol.md に従う。定義・年度・通貨・株数を揃える)
        ↓
② 妥当PEGを1点で確定し、根拠とともに封印する
   (3経路の収束 → 単一値 → Appendix Bに記録)
   ★★ この時点まで、現在株価から逆算したインプライドPEG・
      インプライド成長率を計算しない。見ない。 ★★
        ↓
③ 封印後にはじめて現在株価を見る
   インプライドPEG = 現在株価 ÷ 基準EPS ÷ 将来EPS成長率
   を算出し、封印したPEGとの乖離を測る
        ↓
④ 乖離が大きい場合にやってよいのは「見落とした事実の探索」だけ
   (§3の手続きに従う)
```

### 1-1 なぜ②の前に株価を見てはいけないのか

現在株価を先に見ると、**アンカリングが必ず起きる**。人間もモデルも、
「分析では1.2でも文句ないが、今の株価だと0.8だから乖離が大きすぎる。
1.0くらいにしておこう」という調整を無意識に行う。これをやった瞬間、
出力は「株価をやや上回る/下回る程度の目標株価」に収束し、
**分析の結論は株価の関数になる**。事業を解剖した意味が消える。

**乖離が大きいことは、分析の失敗ではなく分析の結果である**。
乖離が大きい状態は、次のいずれかを意味する:

| 状態 | 意味 | 取るべき行動 |
|---|---|---|
| 妥当PEG > インプライドPEG(株価が安い) | 市場が構造を過小評価しているか、こちらが見落としている | §3の探索 → 見落としがなければ「投資機会」として提示 |
| 妥当PEG < インプライドPEG(株価が高い) | 市場が織り込みすぎているか、こちらが構造を過小評価している | §3の探索 → 見落としがなければ「見送り/監視」として提示 |

どちらも**結論として提示してよい**。乖離の大きさを理由にPEGを動かしてはならない。

### 1-2 封印の実務

②で確定したPEGは、以下をセットでAppendix Bに書き込んだ時点で「封印」とする:

- 妥当PEG(1点)
- 3経路それぞれの値と、収束の判断
- 相対優位スコアカードの7軸の採点と事実根拠
- 基準に置いた「平均的企業群」の定義
- 確定日

封印後にPEGを書き換える場合は、**§3の改定手続きを経て、初期値を消さずに残す**。

## §2 1点で確定する手続き

### 2-1 なぜレンジを禁じるか

- レンジは**判断の放棄**である。「PEG 1.1〜1.4」は、目標株価が27%変わることを
  意味し、投資判断(買い/見送り)を反転させうる幅を分析側が決めずに
  読み手に押し付けている
- 分析の目的は「この事業は平均的企業群と比べてどれだけ優れているか」を
  **決めること**である。優劣を判定するために事業を解剖したのだから、
  結論は1点で出せなければならない
- レンジは事後的な正当化を可能にする。どちらに転んでも「レンジ内」になる

### 2-2 3経路から1点を作る

`edge-generation.md` §3の3経路(同一基準ピア実勢 / グロース慣行上の位置 /
相対優位スコアカード)を、それぞれ**1点の値**として出す。そのうえで:

| 3経路の散らばり | 採用 |
|---|---|
| ほぼ一致(幅が0.1以内) | 中央の値を採用 |
| 中程度に散らばる(幅0.1〜0.3) | **相対優位スコアカード(第3経路)を主とする**。事業の中身を最も反映しているため。ただし他2経路との差の理由を書く |
| 大きく散らばる(幅0.3超) | **最も保守的(低い)経路の値を採用**し、なぜその経路を採ったか、なぜ他経路を退けたかを書く。同時に、散らばりの原因(ピア選定の誤り/成長期間の不一致/EPS定義の不一致)を疑い、経路の作り直しを一度は試みる |

**いずれの場合も出力は1点**。「1.1〜1.4」ではなく「1.1。理由は…」と書く。

### 2-3 有効数字

PEGは**小数第1位まで**(例: 1.2)を既定とする。相対優位スコアカードの合計が
明確に中間にある場合に限り第2位(例: 1.15)を使ってよい。
それ以上の桁は擬似的な精密さであり、使わない。

### 2-4 年度別PEG

- **既定は全年度に基準PEG(1点)を適用する**
- 年度によって値を変えてよいのは、**成長ステージの移行という構造イベント**で
  説明できる場合に限る(Phase 2.5のF9のステージ変化、設備の稼働率到達、
  契約構造の転換、ミックス効果の発現など)
- 変える場合も**各年度1点**で置き、**年度ごとに変更理由(どの構造イベントか)**を書く
- **年度別PEGをレンジ(x〜y)で置くことは禁止**
- 「なんとなく先の年度は不確実だからPEGを下げる」は理由ではない。
  不確実性はEPSパス(弱気パス)とエントリー価格帯で表現する。
  **不確実性をPEGに二重計上しない**

## §3 乖離が大きいときの正しい手続き

③で乖離が大きいと判明したとき、やってよいことは**1つだけ**である:
**自分が見落とした事実がないかを探すこと**。

### 3-1 探索チェックリスト

乖離が大きい方向に応じて、以下を確認する:

**妥当PEG > インプライドPEG(株価が安すぎるように見える)場合**——
市場が知っていて自分が知らないことを探す:
- [ ] 訴訟・規制・調査・会計方針の変更など、開示済みだが自分が拾えていない事象
- [ ] 大株主の売却圧力、ロックアップ解除、増資観測、指数除外
- [ ] EPS定義の食い違い(市場は調整後、自分はGAAPで見ている等)
- [ ] コンセンサスEPSが直近で大きく下方修正されている(リビジョンの見落とし)
- [ ] 会計年度・通貨・株数(分割/希薄化)の不整合
- [ ] 対象銘柄が構造的にディスカウントされるカテゴリ(コングロマリット、
      支配株主の存在、二重上場、ガバナンス)に属している
- [ ] 弱気派のsteelmanが不十分で、真の懸念を捉えられていない(§edge-generation §1へ)

**妥当PEG < インプライドPEG(株価が高すぎるように見える)場合**——
市場が織り込んでいる将来を自分が捉えられていないか探す:
- [ ] 経営陣シナリオのピースで、自分が「まだ小さい」として過小評価したものがないか
- [ ] 市場が使っている成長期間が自分より長い(5年でなく10年で見ている)
- [ ] 市場が使っているEPSが自分の正規化EPSより高い定義になっている
- [ ] 買収・提携・新規事業など、直近の発表を織り込み損ねていないか
- [ ] 強気派のsteelmanが不十分で、真の期待を捉えられていない

### 3-2 改定してよい条件

- **新しい事実が見つかった場合のみ**、PEGまたはEPSパスを改定してよい
- 改定は「事実 → 相対優位スコアカードの該当軸の採点変更 → PEGの変更」という
  **経路をたどること**。PEGを直接書き換えてはならない
- 改定時は以下をすべてAppendix Bに残す:
  **初期PEG / 改定後PEG / 改定を正当化した新事実 / その出所と取得日 /
  変更した軸と採点の前後**

### 3-3 改定してはならない場合(禁止事項)

以下は**明示的に禁止**する:

- ❌ 新事実がないのに、乖離が大きいという理由だけでPEGを動かす
- ❌ 「分析では1.2だが、現在株価では0.8だから乖離が大きすぎる」→「1.0にする」
- ❌ 目標株価が現在株価から遠すぎるという理由で、基準EPSや成長率を差し替える
- ❌ 乖離を「妥当に見える幅」に収めるために弱気パスを本線に格上げする
- ❌ PEGをレンジに戻して、乖離の大きさを幅の中に隠す

**探索の結果、見落としがなければ、乖離はそのまま報告する**。
それが投資機会(または明確な見送り事由)であり、本分析の成果物である。

### 3-4 探索しても説明できない乖離の扱い

見落としが見つからず、乖離が極端(目安: ±60%超)なまま残る場合:

- PEGは動かさない
- **「乖離が極端であり、市場と本分析のどちらかが誤っている」と明記**し、
  どちらが誤っている可能性が高いかを、市場の織り込み前提を逆算した形で論じる
- **確信度を1段階下げる**(Phase 6)
- 乖離の正誤を判別するKPIを指定し、判別KPI(Phase 5.5)に送る
- エントリー価格帯は分割エントリー圏を広く取る(scenario-strategy.md §6)

**「わからない」を「真ん中を採る」で埋めない**。極端な乖離を平均化して
穏当に見せることは、分析ではなく粉飾である。

## §4 チェックリスト(Phase 5の出力前)

- [ ] 妥当PEGが**1点**で書かれている(レンジになっていない)
- [ ] 3経路それぞれの値が1点で出ており、収束の判断理由が書かれている
- [ ] 年度別PEGが既定どおり基準PEG1点で、変えている年度には構造イベントの
      理由が付いている(レンジになっていない)
- [ ] **PEGの確定がインプライドPEGの算出より先に行われた**ことが、
      Appendix Bの記載順序と確定日で追跡できる
- [ ] PEGを改定した場合、初期値・改定値・新事実・出所・変更した軸が残っている
- [ ] 新事実なしの改定が1件もない
- [ ] 乖離が大きいまま残っている場合、それが結論として提示され、
      確信度と判別KPIが付いている
