# コンセンサスEPSの取得規律(Phase 1・5)

将来EPSパスはバリュエーションの土台であり、**ここが汚れているとPEGも目標株価も
全部壊れる**。アナリスト予想は「使ってよい唯一のアナリスト情報」(目標株価と
レーティングは使わない)であるからこそ、取り方を厳密に定める。

**本ファイルの前提**: 旧版は「TradingViewで全予想年度を取得する」とだけ書いていた。
これは不十分である。理由は§1に示す。

---

## §1 なぜTradingViewを単一ソースにしてはいけないのか

TradingViewは便利な取得先だが、**それ自体が予想を作っているのではなく、
集約ベンダー(LSEG/Refinitiv系等)のデータを表示している二次情報**である。
以下の歪みが構造的に入りうる:

| リスク | 具体的に何が起きるか |
|---|---|
| **EPS定義の不明瞭さ** | 表示されているのがGAAP EPSか調整後(non-GAAP)EPSか、希薄化後か基本かが画面上で判別できないことがある。自分の正規化EPSと定義が違えば成長率が数pt単位でずれる |
| **会計年度基準のずれ** | 決算期が12月でない企業で、暦年ベースに組み替えられている場合がある(FY表記の意味が会社開示と違う) |
| **通貨のずれ** | 米国上場の外国企業・ADRで、報告通貨と表示通貨が異なることがある |
| **株数調整のタイムラグ** | 株式分割・大型自社株買い・増資の反映が遅れると、過去との接続が壊れる |
| **カバレッジ数の非表示/薄さ** | 期遠年度はアナリスト2〜3名しか予想を出していないことが多く、「コンセンサス」の名に値しない平均が表示される |
| **更新遅延** | 決算発表直後は改定が反映されるまで数日かかることがある |
| **平均か中央値か** | どちらを表示しているかで、外れ値1名の影響が大きく変わる |

したがって規律は「TradingViewを使うな」ではなく、
**「TradingViewを起点にしてよいが、単一ソースにせず、定義を必ず確認する」**。

---

## §2 取得手順

### 2-1 ソースの積み方(最低2ソースで突合)

1. **一次(定義の基準)**: 会社IR・決算短信・10-K/10-Q・決算説明資料から、
   **実績EPSの定義**(基本/希薄化後、GAAP/調整後、調整項目の内訳)を確定する。
   **コンセンサスの定義はこの一次情報に合わせて解釈する**
2. **コンセンサス主ソース**: TradingView等の集約表示から、全予想年度を取得
3. **コンセンサス突合ソース**: 別系統でもう1つ取得する
   (会社IRが載せているコンセンサス、証券会社のスクリーナー、
   金融データサイト、日本株なら会社四季報・IFIS等)
4. **突合**: 2と3が**5%以上乖離したら理由を特定する**まで先へ進まない。
   典型原因は EPS定義の違い / 会計年度の解釈 / 通貨 / 更新時点

### 2-2 予想年度ごとに必ず記録する項目

| 項目 | なぜ必要か |
|---|---|
| 予想年度(会社の会計年度で明記) | 暦年との混同を防ぐ |
| コンセンサスEPS(平均/中央値を区別) | 外れ値の影響を判定するため |
| 高値予想・安値予想 | 見方の分散=論点の所在を示す |
| **カバレッジ人数** | 薄いコンセンサスを軸にしないため |
| **EPS定義**(GAAP/調整後、基本/希薄化後) | 自分の正規化EPSと揃えるため |
| 通貨 | 為替による見かけの成長を排除するため |
| **3か月前比のリビジョン方向と幅** | 予想が上向いているか下向いているかは、水準以上に情報量がある |
| 取得日・取得元URL | 再現性 |

### 2-3 カバレッジが薄い年度の扱い

- **カバレッジ3名未満の年度は「参考値」扱い**とし、EPSパスの軸にしない
- その年度は、Phase 2.6のドライバー(数量×単価×ミックス、稼働率、
  契約構造)からの積み上げを主とし、コンセンサスは照合用に併記する
- カバレッジ人数は年度ごとに必ず書く(「FY28はカバレッジ2名」と明記すれば、
  読み手はその年度の数字を割り引いて読める)

## §3 コンセンサスの解釈規律

### 3-1 定義を自分の正規化EPSに揃える(最重要)

**コンセンサスが調整後EPS、自分の分析が正規化EPS(一時要因除外)の場合、
両者は別物である。** 揃えずに成長率を計算するのが、PEGを壊す最大の落とし穴。

手順:
1. コンセンサスのEPS定義を特定する(調整後なら、何を調整しているか)
2. 自分の正規化EPSとの差分項目を列挙する
   (株式報酬費用、買収関連償却、一時的な税効果、為替差損益 等)
3. **どちらかに揃える**。揃えられない場合は、その旨を明記し、
   成長率の計算に使う系列は**始点と終点で同じ定義**であることだけは死守する
4. 揃えた結果をAppendix Bに記録する

### 3-2 期遠年度の楽観バイアス

アナリスト予想には、**期遠年度ほど楽観的になりやすい**という構造的な傾向がある
(カバレッジが薄く、下方修正は決算を跨いで段階的に起きるため)。したがって:

- **期遠年度のコンセンサスをそのままベースパスに採用しない**
- Phase 2.6のドライバー(稼働率の到達時期、ミックス効果の発現年度、
  契約の更新サイクル)と突合し、**採用する/割り引く/自分のパスに差し替える**を
  年度ごとに判断して、その判断理由を書く
- リビジョンが**下向きに続いている**銘柄では、直近コンセンサスもまだ高い
  可能性を疑う(下方修正はまとめてではなく小刻みに来る)

### 3-3 コンセンサスと自分のパスが乖離するとき

- **乖離の理由を収益ライン単位で説明できないうちは、自分のパスを採らない**
  (説明できない乖離は、たいてい自分の誤りである)
- 説明できる場合は、その説明が **Phase 5.7の独自示唆(L2)の候補**になる。
  差分台帳(F17)に送る
- 乖離の方向(自分が強気か弱気か)を明示し、片側にしか乖離がない場合は
  ポジション先行を疑う

### 3-4 使ってよい範囲(再掲)

| 使ってよい | 使ってはいけない |
|---|---|
| コンセンサスEPS(平均/中央値)、高安レンジ、カバレッジ人数、リビジョン方向 | **目標株価** |
| レポート・決算callの論点と質問(市場の関心の観測データ) | レーティング(買い/中立/売り) |
| アナリストが提示する業界データ・一次的な事実 | 結論・投資判断 |

## §4 チェックリスト(Phase 5に入る前)

- [ ] 実績EPSの定義を一次情報(会社開示)で確定した
- [ ] コンセンサスを**2ソース以上**で取得し、5%以上の乖離があれば理由を特定した
- [ ] 予想年度ごとに、EPS・平均/中央値の別・高安・**カバレッジ人数**・
      **EPS定義**・通貨・**3か月前比リビジョン**・取得日・URLを記録した
- [ ] カバレッジ3名未満の年度を「参考値」と明示し、軸にしていない
- [ ] コンセンサスのEPS定義を自分の正規化EPSに揃えた(揃えられない場合は明記し、
      成長率計算の始点・終点の定義は一致させた)
- [ ] 会計年度基準・通貨・株数調整(分割/増資/自社株買い)の整合を確認した
- [ ] 期遠年度をそのまま採らず、ドライバーとの突合で年度ごとに採否を判断した
- [ ] 直近決算がコンセンサスに反映済みかを確認した(発表直後は要注意)
- [ ] 目標株価・レーティングを台帳に混入させていない
