## §1 利益の質の構造分析(数字への波及マップ)

- **入力は機構台帳**(business-core-method.md §7)。構造変化の源泉を4種で特定する:
  ビジネスモデル/プロダクト・サービスミックス/供給構成/契約形態。
- 各機構が、どのKPIを通じて、次のどれにどの方向・大きさ・時期で効くかを描く:
  - ROI・ROIC(エンジン別・増分)、ROE(デュポン分解: 利益率×総資産回転率×レバレッジ)
  - 需要の長さ(契約期間・継続率・受注残の転換スケジュール)
  - 底堅さ(ストック比率・定常状態利益・景気感応度)
- 上振れ・下振れの両方向で描く。資産の外部化によるROE上昇と残った義務は同じ図に並べる。

## §2 カタリストとリスクの整理

- 3分類: **EPS向き**(利益水準を動かす)/**PEG再評価トリガー**(市場が許容する倍率を
  動かす: 分類の見直し、持続年数の見直し)/その他。
- **必須4属性**: 影響度の目安(ΔEPS・ΔPEG)、実現可能性、時期、合格ライン。
- 各カタリスト・リスクは機構台帳の番号と1対1で対応させる(二重管理しない)。

## §3 EPSと目標株価

### §3-0 EPS品質フォレンジック(必須前工程、6点)

1. **EPS成長の対数分解**:
   ln(EPS₁/EPS₀) = ln(売上₁/売上₀) + ln(純利益率₁/純利益率₀) − ln(株数₁/株数₀)
   さらに純利益率を、営業利益率・営業外・税率((1−税率₁)/(1−税率₀))に分ける。
   どの項がEPS成長を作っているかを示す。
2. **裁量費用の意図分析**: 広告宣伝費・S&M・R&Dの増減を、新規獲得用/既存拡張用/
   新製品用に分け、削って利益を出していないか、投資して利益を抑えていないかを判定する
   (後者は定常状態利益の推計に使う)。
3. **実効税率の実態**: 税優遇・繰越欠損金・一時的な税効果を除いた平常の税率。
4. **EPS定義の明示**: 基本/希薄化後、GAAP/調整後。比較は同じ定義で揃える。
5. **会社開示値優先**: 会社が開示する指標は自己流で再算出しない。
6. **一時要因の正規化**: 税優遇・一過性損益・非営業の評価益(保有株式の評価益、ワラント益、
   資産売却益など)を除いた**正規化EPS**を作る。

### §3-1 事業実態EPS(基準EPS)

正規化EPSに、EPSが事業実態を映さない業種の補正を**上下両方向**でかけたもの
(business-core-method.md §5-3)。補正の内訳はAppendix Bに記録する。

| 型 | 補正 |
|---|---|
| 設備型インフラ | 会計上の償却を経済的耐用年数ベースに置き換える(上下どちらにも動く)。定常状態利益を併記 |
| 金融 | 手数料事業(資本を使わない)と貸出事業(資本を使う)を分ける。公正価値評価益は売却実績で検証 |
| 不動産再生 | ストック利益は持続利益、フロー利益は平均回転で正規化。含み益を併記 |
| SBCの大きいソフト | SBC控除後で計算し、希薄化の効果を別途判定 |
| 急成長SaaS | 定常状態利益率を併記(成長投資の費用計上による過小評価を補う) |

### §3-2 将来EPS経路(過去成長率の外挿は禁止)

| 経路 | 作り方 | 役割 |
|---|---|---|
| コンセンサス経路(ベース) | TradingViewの全予想年度コンセンサス | 市場の期待値の代理 |
| 会社シナリオ経路(強気) | Phase 2.7のシナリオ台帳を数値に翻訳 | 経営陣の計画が実現した場合 |
| 事業エンジン経路(独自) | 原子単位の数×単価×拡張率×限界利益率、ストック収益の積み上げ、制約の解放時期、機構台帳の大きさから積み上げる | **コンセンサスとの差が、市場との差分の数値表現** |
| 弱気パス(独立) | 下振れ機構が顕在化した場合を、強気と同じ粒度で積み上げる | 下値の確認 |

- 直近の加速度(QoQ年率・TTM YoYの2階差分)から、コンセンサスの上方・下方修正余地を記録する。
- コンセンサスの最終予想年度より先は、事業エンジン経路の考え方(浸透率・天井・CAP)で延長し、
  延長部分であることを明記する。

### §3-3 許容PEGの導出(3経路の収束。表の機械適用は禁止)

> 【2026-10-12 改訂】本節は intrinsic-valuation-credit.md(PER の参照クラス・理論式・二重計上の禁止・倒産確率)
> と併用し、矛盾する場合はそちらを優先する。PEG は「成長率に対する倍率」の要約にすぎず、資本集約度や
> 倒産リスクを PEG の割引で表現してはいけない(それらは FCF・SOTP・倒産確率で1回だけ数える)。
> PEG の採用値は、参照クラス表と PER 理論式((1−g÷ROIC)÷(r−g))で必ず検算する。

**経路a 同一基準ピアの実勢**: 同じEPS定義・同じ期間のCAGRで計算したピアのPEG分布。
ピアは事業モデルの型(business-core §8)が同じ企業から選ぶ。

**経路b グロース慣行と市場の相場(参照クラス)上の位置**: PEG=1を成長と倍率が見合う水準とする慣行(ピーター・リンチ)
を出発点に、次の解釈アンカーで位置づける。**あわせて、PER の参照クラス表(日米の市場平均・同じ成長率と
ROIC の企業群。intrinsic-valuation-credit.md §2)の中で位置づける。** 例: 日本市場平均は成長率が低くても
14〜16倍、米国市場平均は 20倍前後(必ず最新値で更新)。これより高い成長率と ROIC を持つ企業の妥当 PER が
これを下回るなら、その理由を事業の構造かリスクの数値(倒産確率など)で説明する。
- 1未満: 市場評価が著しく低い
- 1〜1.5: 一般・レガシー並み
- 1.5超: 高評価(持続年数・質への信認がある場合に限り正当化される)

**経路c 質とシナリオの因果**【再設計】: 構造評価から出発し、事業本体の質で調整する。

| 構造評価 | 出発点のPEGレンジ |
|---|---|
| S | 1.6〜2.0 |
| A | 1.3〜1.6 |
| B | 1.0〜1.3 |
| C | 0.8〜1.0 |
| D以下 | 許容PEGを設定しない(買い判断の対象外) |

調整要因(それぞれ根拠と大きさを書く。**資本集約度・倒産リスク・顧客集中・希薄化は、FCF・SOTP・倒産確率・
シナリオ確率・株数で数えるため、ここでは調整しない。二重計上の禁止**):
- 競争優位期間(CAP): PEGは成長の持続年数を表現できない。同じ成長率でもCAPが長いほど上方
- 自己強化ループの強さと、制約の解放が近いか
- ストック収益比率、定常状態利益率(報告利益率との差が大きいほど、報告EPS基準のPEGは上方)
- 非対称性(下値限定・上値開放の凸性があれば上方)
- 下振れ機構の大きさと確率(効果として織り込む)

3経路が収束しない場合は、どの経路の前提が事業本体と整合するかを判断して採用値を決め、
理由を記録する(機械的な平均はしない)。

### §3-4 年度別評価テーブル(F13)

| 年度 | 事業実態EPS | 成長率g | PEG(x〜y) | 妥当PER=PEG×g(%) | 適正株価=妥当PER×EPS |
|---|---|---|---|---|---|

- 成長率gは当該年度から先の3〜5年CAGRを使う(単年の成長率は振れが大きい)。
- 【再設計】gが50%を超える年度は、PEGの線形性が崩れるため、gを50%で頭打ちにした値と
  頭打ちなしの値を併記し、採用理由を書く。
- **年度別PEGは1固定等の全年度同一値を原則禁止**。シナリオの実現可能性と時期から、
  x〜yの狭いレンジで年度別に置く(成熟に向かうにつれ、成長率とともにPEGも変化する)。
- 【2026-10-12 追加】**成熟年度(5年 g が 15% を下回る年度)は PEG × g を使わず、PER 理論式
  ((1−g÷ROIC)÷(r−g))と参照クラスで妥当 PER を置く。** 機械的な PER の下限(例: 14倍)を置かない。
  事業別に ROIC が大きく違う場合は、事業別の PER(または EV/NOPAT)を合算する。
- 3経路(+弱気)それぞれでテーブルを作る。

### §3-5 交差確認と「成長の値段」

**業種別の交差確認**: PEG経路の目標株価を、次で確認する。ずれが大きい場合は、どちらの前提が
事業本体と整合するかを判断して記録する。
- 金融: 1株当たり有形自己資本 × (ROTCE−g)÷(資本コスト−g)
- 不動産再生: ストック利益の資本化価値 + 正規化フロー利益の価値 + 含み益
- 設備型インフラ・複合企業: 事業別評価の合計(SOTP)と定常状態利益

**成長の値段(現在株価の分解)**:
- 定常状態価値 = 定常状態利益 ÷ 資本コスト(成長がゼロでも残る価値)
- 成長の値段 = 時価総額 − 定常状態価値
- 成長の値段が小さい(またはマイナス)のに、事業エンジン経路が成長を示しているなら、
  市場は成長をほぼ無料で売っている。強い差分の候補になる。逆に、成長の値段が大きいのに
  成長の持続年数の根拠が弱ければ、過大評価の候補になる。

**リバースDCF**: 現在の株価が織り込む成長率と持続年数を逆算し、参照クラス(同規模・同成長率の
企業が何年その成長を維持したか)と、事業本体のCAP推計の両方と比べる。株価を当てにいく
道具ではなく、市場の前提を読む道具として使う。

**価値の時間分布**: 1株当たり価値のうち、3年以内に生じる部分と、それ以降に生じる部分の比率。
市場の時間軸が短い局面では、遠い価値ほど割り引かれやすい(時間差裁定の余地)。

## §4 最終判断

### §4-1 2軸マトリクス【再設計】

価格乖離 =(目標株価−現在株価)÷現在株価。3経路それぞれで算出し併記する。

| 構造評価 \ 乖離(採用経路) | +30%以上 | +10〜30% | −10〜+10% | −10%未満 |
|---|---|---|---|---|
| S・A | 買い | 買い | 買い検討 | 監視 |
| B | 買い | 買い検討 | 監視 | 見送り |
| C | 買い検討 | 監視 | 監視 | 見送り |
| D以下 | 見送り | 見送り | 見送り | 見送り |

- **市場との差分がない(エッジなし)場合は、乖離がプラスでも「買い」にしない**。
  「買い検討」を上限とし、差分が生まれる条件を書く。
- 非対称性(弱気パスの下値:強気パスの上値、確率加重の期待値)を併記する。
- 判断を変えるトリガー(判別KPIの閾値)を添える。

### §4-2 テールリスクの分離

会計不正疑惑等の低確率・高インパクト事象は、可能性分析のうえで本体評価から除外し、
リスクマトリクス(F14)で発生確率×影響度+顕在化トリガー付きで管理する。分離と無視は別物
である。テールでない通常のリスクは、効果として本体評価に組み込む(business-core §6)。
テール扱いを、評価を甘くする逃げ道にしない。

### §4-3 計算の規律

- 計算はコードで行い、前提(基準EPS・定義・補正内訳・期間・出所・取得日)を固定する。
- すべての入力値に出所を付け、第三者が再現できるようにする。
