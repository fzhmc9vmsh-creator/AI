# 事業の解剖法(Phase 2.6)

Phase 2.5が「カネの流れの解剖」なら、本ファイルは「**その事業が実際に何をやって
いるのかの解剖**」を担う。ここが埋まらないまま条件判定・バリュエーションに進むと、
結論は必ず過去の数字の外挿に堕ちる。**数字は事業構造の結果であって原因ではない**。

出力は収益ライン別の**事業解剖カード(F15)**と**キャッシュ循環マップ(F16)**、
および**需要特性の中立記述**の3点。

---

## §0 対象ラインの選定

Phase 2.5のF10で切り出した収益ラインのうち、以下を**すべて**対象にする:

1. 売上比率の上位から累計して**70%以上**を占めるライン
2. 売上比率は小さいが、**粗利率が全社平均を上回る**(または会社計画・構造上
   これから上回る)ライン
3. 直近で**急伸または急減しているライン**(比率・粗利率にかかわらず)

「まだ小さいから対象外」は禁止(2と3がこれを潰すための条項)。対象外にした
ラインがある場合は、その理由と売上比率を明記する。

## §1 稼ぎ頭の速度と経営陣の見通し

### 1-1 速度の測り方

売上比率トップのラインについて、以下を**併記**する(片方だけは不可):

| 指標 | 取り方 | 何がわかるか |
|---|---|---|
| 実績CAGR(3年・5年) | 期首→期末の年平均成長率 | 中期の巡航速度 |
| 直近4四半期の前年同期比 | 四半期ごとに4点並べる | 加速/減速の向き |
| 直近四半期の年率換算 | QoQを年率化(季節性がある場合は注記) | 足元の勢い |

2位以下のラインも「売上比率 × 成長率」をセットで並べ、
**全社成長率の何ptをどのラインが作っているかの寄与度分解**を出す:

```
全社成長率 = Σ(ライン i の売上比率(期首) × ライン i の成長率)
```

- 寄与度1位のラインが「実際の稼ぎ頭」である。売上比率1位と寄与度1位が
  ずれている場合、**それ自体が重要な発見**(構造転換が進行中の証拠)
- 減速しているラインは、Phase 2.5の要素分解(数量×単価×ミックス+離脱・
  客層シフト・内製化/代替・需要量)に必ず接続する

### 1-2 経営陣の見通し

ガイダンス・中期経営計画・決算call・Investor Dayの**一次発言**から、
「これから何%で伸びると言っているか」を引用付きで取る:

- ライン別の見通しが開示されていれば ライン別、なければ全社+定性コメント
- 期間(単年ガイダンス / 3年 / 5年 / 中長期目標)を必ず明記する
- 経営陣が数値を出していない場合は「数値目標なし」と書く(推測で埋めない)

### 1-3 差の説明(このPhaseの核心)

**実績成長率と経営陣見通しの差**を明示し、その差が何によって埋まると
経営陣が言っているのかを書く:

- 差を説明する要因(新製品/新地域/価格改定/設備の稼働/買収/構造改革)を列挙
- **差が説明できない場合、それ自体が最重要の発見**である。
  「経営陣は加速すると言っているが、加速の担い手が特定できない」は
  Phase 5.5のクラックス候補・Phase 5.7の独自示唆候補になる
- 逆に実績 > 見通し(会社が保守的)の場合も同様に扱う

## §2 粗利の実像と次の稼ぎ頭

### 2-1 ライン別粗利率

- **開示があれば開示値を使う**(会社開示値優先の原則)
- 開示がなければ推計する。推計方法(セグメント営業利益からの逆算、
  同業他社の同種事業のマージン、原価構造からの積み上げ等)と
  **その推計がどれだけ幅を持つか**を必ず併記し、Appendix Bに記録する
- 粗利率の**方向**(改善/横ばい/悪化)と**原因**を、
  ①単価、②原価(仕入・人件費・減価償却)、③ミックス、④稼働率
  のどれかに帰着させる。「競争激化のため」で止めない

### 2-2 次の稼ぎ頭(ミックス効果の時期)

粗利率が全社平均より高い、または構造的にこれから高くなるラインについて、
**全社粗利率を何pt押し上げるのがいつか**を試算する:

```
将来の全社粗利率 = Σ(ライン i の将来売上比率 × ライン i の粗利率)
```

- 高粗利ラインの成長率と現在の比率から、比率が10%/20%に達する年度を出す
- そのときの全社粗利率を試算し、現在との差(pt)を示す
- **「まだ小さいから評価対象外」は禁止**。小さくても成長率と粗利率が高ければ、
  ミックス効果が効き始める時期を必ず出す。試算不能なら「非開示のため試算不能・
  必要な追加開示は○○」と明記する

### 2-3 希釈側も見る

**成長しているが粗利率が低いライン**は全社粗利率を希釈する。
成長がそのまま良いことだと書かない。増収と増益の乖離が
このメカニズムで説明できる場合は、営業レバレッジの分解(Phase 2.5)と接続する。

## §3 5つの問い(WHO / WHAT / HOW / WHEN / WHERE)

各対象ラインについて埋める。**フレームワークの名前を書くのではなく、中身を書く**。
「ファイブフォース分析の結果、競争は激しい」のような記述は無価値であり、
**実名プレイヤー・実数・実際に起きた取引条件の事実**で書く。

### 3-1 誰に(WHO)— マーケティング・ターゲット分析

- 顧客セグメントの定義(業種/規模/地域/用途)
- 顧客数、**上位顧客の集中度**(上位1社・5社・10社の売上比率)
- 意思決定者は誰か、購買動機は何か(コスト削減/売上増/規制対応/リスク回避)
- 獲得チャネル(直販/代理店/セルフサーブ)と獲得コスト、回収期間
- **スイッチングコスト**の中身(データ移行/業務適合/契約/教育/認証)
- 解約・離脱の実績(解約率、NRR=既存顧客売上継続率、離脱理由)

### 3-2 何を(WHAT)— プロダクト分析

- 提供物の定義と、顧客にとっての**代替手段**(競合他社/内製/何もしない)
- **SWOT**をライン単位で(全社SWOTは粗すぎる)。
  強み・弱みは自社の内部要因、機会・脅威は外部要因に厳密に分ける
- **PPM(製品ポートフォリオ)**上の位置:
  金のなる木(高シェア・低成長)/花形(高シェア・高成長)/
  問題児(低シェア・高成長)/負け犬(低シェア・低成長)。
  **重要なのは現在位置ではなく「今後どこへ動くか」と「金のなる木が
  問題児の投資を賄えているか」**

### 3-3 どんな方法で(HOW)— バリューチェーン / ファイブフォース

**バリューチェーン分析**:
- 工程を分解し(調達→製造/開発→販売→導入→保守)、
  **自社が握る工程と外注する工程**を色分けする
- **付加価値がどの工程に溜まっているか**(工程別の粗利貢献)
- 自社が握る工程は模倣可能か。外注工程に依存リスクはあるか

**ファイブフォース分析**(一般論禁止・実名と事実で):
| 力 | 書くべき事実 |
|---|---|
| 供給者交渉力 | 主要仕入先の実名・集中度・過去の値上げ受諾実績・代替可能性 |
| 買い手交渉力 | 上位顧客の実名/属性・値引き要求の実績・入札か相対か |
| 新規参入 | 直近3年の実際の参入者・参入に必要な資本/時間/認証 |
| 代替品 | 実在する代替技術・代替手段の価格性能比と採用実績 |
| 既存競合 | 主要競合の実名・シェア・直近の価格動向(値上げが通ったか) |

**値上げが実際に通ったかどうか**は価格決定力(条件1)の最重要証拠であり、
必ず事実で確認する。

### 3-4 いつ(WHEN)— 時期の解剖

- **売上認識のタイミング**: RPO(残存履行義務=契約済み未計上の売上)・
  受注残・契約期間・検収基準・従量課金の計上時点。
  **RPOのうち12か月以内に計上される比率**は成長の先行指標として重要
- **設備の稼働**: 稼働開始時期、現在の稼働率、フル稼働時の売上寄与
- **製品ローンチ**: 発表→出荷→量産→収益貢献の各時期
- **拡大戦略の実行時期**: 増設・新地域進出・新チャネル・買収統合の完了時期
- **受注→売上→キャッシュのタイムラグを月数で書く**

### 3-5 どこで(WHERE)— 市場環境

- 地域・市場セグメントの定義
- **その市場のサイズと成長率**(出所・調査機関名・発行年を必ず付す)
- 自社のシェアと順位、シェアの方向(取っているか、削られているか)
- 規制環境(許認可・補助金・関税・データ規制)とその変化
- 市場そのものの構造変化(需要の質が変わっていないか)

## §4 キャッシュの時間構造(F16)

**キャッシュが先に出ていく構造か、先に入ってくる構造か**を、収益ラインごとに判定する。
これは成長の資金繰り制約と、減速時の先行指標の両方を決める。

### 4-1 判定材料

| 構造 | 判定材料 | 成長時に起きること |
|---|---|---|
| **先に入る**(前受型) | 前受金・契約負債・繰延収益の増加、サブスク年払い、保守料前受 | 成長が速いほどキャッシュが積み上がる。運転資本がマイナス |
| **先に出る**(先行投資型) | 在庫・売掛の増加、設備投資の先行、研究開発の資産化/費用化、顧客獲得コストの先行 | 成長が速いほどキャッシュが枯れる。調達が必要 |

- **CCC(現金循環日数)= 売上債権回転日数 + 棚卸資産回転日数 − 仕入債務回転日数**
  を算出し、時系列で並べる(マイナスなら前受型に近い)
- 契約負債・繰延収益の**前年比の伸び**を売上の伸びと比較する
  (契約負債の伸び < 売上の伸び なら、将来の減速の先行サイン)

### 4-2 「どこで産み、どこに投下しているか」

産む場所 → 投下先を**矢印で結んだ図(F16)**にする。投下先については必ず:

- 投下額(capex・R&D・買収・広告宣伝費)とその**内訳**
- 投下 → 稼働 → 収益化の**時間差**(月数・年数)
- **現在の稼働率と稼働開始予定**
- 投下の性格: 維持更新か、増設か、新規事業か
  (維持更新capexが減価償却を上回り続けている場合、その理由を確認する)
- 資金源: 営業CF / 借入 / 増資(希薄化リスクをEPS品質フォレンジックに接続)

### 4-3 出力する含意

- **先出し構造**なら、成長加速は短期のFCF悪化を伴う。
  FCFの悪化を「悪化」と書く前に、それが成長投資由来か収益性劣化由来かを分ける
- **先入り構造**なら、減速は契約負債・RPOの伸び鈍化に先に現れる。
  **何を先行指標として見るか**を判別KPI(Phase 5.5)の候補に送る

## §5 需要特性の中立記述

成長性と需要に波があるか、不景気に強いかを、**良い/悪いの評価を一切付けずに
特性として記述する**。ここで評価を混ぜると、以降の条件判定が汚染される。

### 5-1 記録する4点

1. **循環の周期と振幅**: 過去2回以上の景気後退局面・在庫調整局面での
   売上/受注/粗利率の実績(ピークからボトムまでの下落率と、回復までの月数)
2. **需要の長さ**: 契約期間、リプレース周期、製品の耐用年数、
   一度採用されてから離脱するまでの平均年数
3. **景気感応度**: 何と連動するか(GDP/設備投資/広告市況/住宅着工/
   半導体サイクル/エネルギー価格)。相関の方向と、連動が観測できた実例
4. **解約・離脱・稼働率低下の実績**: 不況時に実際に何が起きたか

### 5-2 条件判定への翻訳

特性を記述したら、**それを条件判定の入力に翻訳する**。翻訳の型:

| 特性 | 中立的な言い方 | 条件への効き方 |
|---|---|---|
| 循環が大きい | 需要は3〜4年周期で±30%振れる | 条件7: 「シクリカルだから減点」ではなく、**現在の株価がサイクルのどこを前提にしているか**で判断。条件2: ボトム期のCFが投資を賄えるか |
| 需要が長い | 契約は5年、リプレースは7年周期 | 条件1・11・12: 収益の反復性と可視性の根拠 |
| 不況に強い | 前回後退局面で売上−3%、粗利率横ばい | 条件2: CFの底堅さ。ただし**成長の天井**とセットで見る |
| 不況に弱い | 前回後退局面で売上−28%、粗利率−6pt | 条件7・11: 弱いこと自体は減点ではない。減点は「弱いのに強い前提で価格が付いている」場合のみ |

**原則**:
- **シクリカルであること自体は減点事由ではない**。減点になるのは
  「シクリカルなのに、シクリカルでない前提で価格が付いている」場合だけ
- **ディフェンシブであること自体も加点ではない**。
  成長の天井と、価格決定力の有無をセットで評価する
- 「良い/悪い」は価格(バリュエーション)との突き合わせで初めて決まる。
  Phase 2.6の段階では特性の記述に徹する

## §6 差し戻し条件(Phase 2.6のゲート)

以下のいずれかに該当したらPhase 1に戻って追加調査する(最大2周。
2周で未達の項目は「既知の制約」に明記して先へ進む):

- [ ] 稼ぎ頭の実績成長率(CAGR+直近年率)と経営陣見通しのどちらかが数字で書けない
- [ ] 全社成長率の寄与度分解ができていない
- [ ] ライン別粗利率が推計すら置けない
- [ ] 高粗利ラインのミックス効果の時期が試算されていない(または試算不能の明記がない)
- [ ] WHO/WHAT/HOW/WHEN/WHEREのいずれかが一般論(実名・実数なし)で埋められている
- [ ] キャッシュが先出しか先入りかが判定できていない、またはCCCが出ていない
- [ ] 産む場所→投下先の対応と、投下→稼働→収益化の時間差が書けていない
- [ ] 需要特性が過去2回以上の景気後退局面の実績で裏付けられていない
- [ ] 需要特性の記述に良し悪しの評価が混入している
- [ ] 需要特性が条件判定の入力に翻訳されていない

## §7 自己認識(このPhaseの位置づけ)

**本Phaseの成果物は「公知の基本」である**。稼ぎ頭の成長率も、粗利率も、
キャッシュの時間構造も、需要の波も、経営陣の見通しも、市場参加者の大半が
知っている。**これだけを並べた報告書に価値はない**。

同時に、**この基本がないままPhase 5.7に進んでも独自示唆は生まれない**。
独自示唆(L2)は、ここで積んだ解像度の高い事実——特に稼働率、売上認識の
タイムラグ、ミックス効果の時期、キャッシュの時間構造——を、市場が使って
いない組み合わせ方で使ったときに生まれる。

**基本は独自示唆の原材料であって、成果物ではない**。
