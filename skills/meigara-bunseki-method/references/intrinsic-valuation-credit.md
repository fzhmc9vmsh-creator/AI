# 本源的価値と信用リスク(intrinsic-valuation-credit.md)【2026-10-12 新設】

> 新設の理由(Oracle 分析での失敗):
> 1. **株価へのアンカリング:** 株価の逆算値を見た後でコアの資本コストを選び、「株価と整合」を
>    結論の根拠にした。本源的価値は株価を見ずに先に出すべきだった。
> 2. **PER の相場観の欠如:** 20%超で EPS が伸び、強い堀(DB)を持つ企業に、日本市場の平均並み
>    (14〜15倍)の PER 下限と、0.8〜0.95 の低い PEG を当てた。日本企業の平均は、成長率が
>    はるかに低くても 14〜15倍である。参照クラスの中で位置づけていなかった。
> 3. **二重計上:** 資本集約度を SOTP の capex 控除と PEG の割引の両方で数えた。
> 4. **信用リスクを倍率で代用:** FCF の黒字化時期、レバレッジの経路、倒産確率を推計せず、
>    低い PEG と弱気シナリオで済ませた。黒字化に伴う倒産確率の低下が、価値と倍率をどう
>    変えるかを書かなかった。
>
> 本ファイルの規律は valuation-model.md より優先する。

## §1 株価から独立した本源的価値(ブラインド評価)

1. **前提の事前登録:** 株価・時価総額・株価から逆算した値を見る前に、次を表に固定して
   Appendix B に記録する: 資本コスト(根拠つき)、事業別の成長率と利益率、PER の参照クラス、
   倒産確率の経路、シナリオの確率。後から変えた場合は、変更前の値・変更理由・変更が株価を
   見た後かどうかを記録する。
2. **本源的価値を先に出す:** 利益・キャッシュフロー・リスクから1株当たり価値を算出する
   (§2〜§4)。
3. **株価との比較は最後の工程:** 乖離 =(本源的価値 − 株価)÷ 株価。「株価と整合したので
   妥当」は結論にならない。株価との差は、市場との差分(business-core §4)の候補として
   扱い、原因を特定する。
4. **リバース DCF は確認の道具:** 市場が暗に置く前提を読むために使い、自分の前提を
   それに寄せない。

## §2 PER の相場観(参照クラス)

**原則:** PER は「成長率・利益の質(ROIC)・持続年数・リスク」の関数である。対象企業の
妥当 PER は、必ず次の参照クラス表の中で位置づける。数値は分析のたびに最新値で更新する
(research-protocol §1-I)。

**参照クラス表の様式(分析時に最新値で埋める):**

| 参照クラス | 12か月先予想PER | 予想EPS成長率 | ROIC・利益の質 | 位置づけ |
|---|---|---|---|---|
| 日本市場平均(東証プライム・TOPIX) | (例: 14〜16倍) | (例: 5〜10%) | 中 | 成長が低い企業の水準。これを高成長・高品質企業の下限に使わない |
| 米国市場平均(S&P 500) | (例: 20〜23倍) | (例: 10〜15%) | 中〜高 | 平均的な米国大型株 |
| 高品質・成熟ソフト(保守・サブスク中心、成長 5〜10%) | (例: 22〜30倍) | | 高 | 成熟後のコア事業の基準 |
| 高成長プラットフォーム(成長 15〜25%) | (例: 25〜35倍) | | 高 | |
| 設備型インフラ(データセンター REIT・通信) | P/AFFO・EV/EBITDA で比較 | | 低〜中 | 資本集約型の事業の基準 |
| 赤字の高成長インフラ(ネオクラウド) | EV/売上・EV/EBITDA | | 未確立 | |

**妥当 PER の理論式(参照クラスと照合する):**
PER(NOPAT 基準)≒(1 − g ÷ ROIC)÷(r − g)。例: r=9%・g=5%・ROIC 30% → 約 21倍、
r=9%・g=3%・ROIC 30% → 約 15倍、r=9%・g=5%・ROIC 12% → 約 15倍。
**同じ成長率でも ROIC が高いほど PER は高い。** 成熟年度の PER は「日本平均」ではなく、
この式と、同じ成長率・ROIC の参照クラスで決める。

**禁止事項:**
- 高品質・高成長企業に、市場平均以下の PER 下限を機械的に当てる。
- PEG を、参照クラスで確かめずに低く置く(PEG が1未満になる理由は、事業の構造か
  リスクの数値で説明する)。
- 成長が鈍る年度に、PEG × g をそのまま当てて PER を一桁にする(成熟年度は理論式と参照クラス)。

## §3 二重計上の禁止(資本集約度とリスクは1か所で1回だけ数える)

| 要素 | 数える場所(1つだけ) | 数えてはいけない場所 |
|---|---|---|
| 資本集約度(capex の大きさ) | FCF・SOTP の投資控除、または ROIC を通じた PER 理論式 | PEG の割引、別途の倍率ディスカウント |
| 倒産・資金繰りリスク | §4 の倒産確率(確率加重または資本コストへのハザード加算) | PEG の割引と弱気シナリオの両方 |
| 顧客集中 | シナリオ確率と機構台帳の効果(確率 × 影響 − 代替需要) | 資本コストへの上乗せと、シナリオの両方 |
| 希薄化 | 株数の経路 | 倍率の割引 |

**チェック:** 目標株価の計算フローの各段に、どのリスクを数えたかの欄を設け、同じリスクが
2回出ていないことを確認する。

## §4 信用リスク: FCF の黒字化 → レバレッジ → 倒産確率 → 価値(F21)

**目的:** 借入で成長する企業について、FCF がいつ黒字化し、それに伴って倒産確率がどう下がり、
資本コストと倍率がどう変わるかを、年度の経路として示す。

**手順:**
1. **FCF の経路:** 年度ごとに、営業 CF(顧客前払いを分けて示す)− capex(総額と純額)=
   FCF。黒字化する年度を特定する。会社・格付会社・アナリストの予想と並べる。
2. **レバレッジの経路:** 純有利子負債(+リース、格付会社の調整後債務の定義に合わせる)÷
   EBITDA。インタレスト・カバレッジ(EBITDA ÷ 支払利息)。格付会社の格下げ・格上げの閾値と
   比べる。
3. **倒産確率の経路(2つの方法で交差確認):**
   - **市場の値:** CDS(または社債スプレッド)から、年間ハザード率 λ ≒ スプレッド ÷
     (1 − 回収率)。回収率は慣行の 40%。例: 200bp → 約3.3%/年、100bp → 約1.7%/年。
     (市場のスプレッドにはリスクプレミアムが含まれ、実際の倒産確率より高めに出る)
   - **格付けの過去実績:** 格付会社の格付別の累積デフォルト率(BBB・BBB-・BB+ の1年・5年・
     10年)。レバレッジの経路から格付けの経路を置き、累積倒産確率を出す。
4. **価値への反映(どちらか1つ。§3 の二重計上禁止):**
   - **確率加重:** 株主価値 =(1 − 累積倒産確率)× 存続時の価値 + 累積倒産確率 ×
     倒産時の株主回収(通常ほぼ0)
   - **資本コストへのハザード加算:** 株主資本コスト = 通常の資本コスト + λ ×(1 − 株主の回収率)。
     λ は年度ごとに経路で変える(黒字化後に下がる)。
5. **再評価のタイミング:** FCF の黒字化とレバレッジの閾値割れ(格上げ見通し)で倒産確率が
   下がる年度は、倍率の再評価(PEG 再評価トリガー)の最有力候補になる。その年度と、
   倒産確率の低下が1株当たり価値に与える効果を、カタリスト一覧(F5)に載せる。

**F21 の必要情報要素:** 年度別の営業 CF(前払い内訳)・capex・FCF、純有利子負債・リース、
EBITDA、レバレッジ倍率と格付けの閾値、CDS(実績と経路)、年間・累積の倒産確率(2方式)、
倒産確率を反映した株主資本コストと1株当たり価値の経路。

## §5 成熟年度(ターミナル)の扱い

- ターミナルの PER は §2 の理論式(成熟後の g・ROIC・r)と参照クラスで決める。
  ターミナル価値の比率が高い場合は、成長の持続年数(CAP)の根拠を示す。
- 事業別に ROIC が違う場合(例: 高 ROIC のソフト保守と、資本集約型の設備事業)は、
  事業別に PER(または EV/NOPAT)を置き、合算する(SOTP)。全社に1つの PER を当てない。
